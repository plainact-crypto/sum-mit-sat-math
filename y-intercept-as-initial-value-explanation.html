Y-Intercept as Initial Value
Algebra
01 · LESSON OBJECTIVE

Connect the y-intercept to a starting value.

By the end of this lesson, you should be able to identify the y-intercept from equations, points, tables, graphs, and real situations, then explain what it means as the value of the output when the input is zero.

y = 4x + 9→initial value = 9
02 · WHAT YOU NEED TO KNOW

The y-intercept happens when x = 0.

For a linear function, the y-intercept is the point where the graph crosses the y-axis. Every point on the y-axis has x-coordinate 0, so the y-intercept is found by evaluating the function at x = 0.

Equationy = mx + bThe y-intercept is b.
Point(0, b)The first coordinate must be 0.
Functionf(0) = bThe output at input 0.
Contextstarting valueThe amount before the input begins changing.
03 · KEY DEFINITIONS

Y-Intercept

The point where a graph crosses the y-axis.

(0, b)

Initial Value

The output value when the input equals zero.

f(0)

Constant Term

The term without x in slope-intercept form.

y = mx + b
04 · CORE RULE / FORMULA

Set x equal to zero.

y-intercept = output when x = 0

In y = mx + b, substituting x = 0 gives y = m(0) + b = b. That is why the constant term b is both the y-intercept value and the initial value.

06 · WORKED EXAMPLE 1 — EQUATION

Find the y-intercept of y = 3x + 7.

y = 3(0) + 7y = 7y-intercept: (0, 7)
Initial valueWhen x = 0, the output is 7.
07 · WORKED EXAMPLE 2 — NEGATIVE INITIAL VALUE

Find the initial value of f(x) = −2x − 5.

f(0) = −2(0) − 5f(0) = −5initial value = −5

Sign check: The y-intercept is (0, −5), not (−5, 0).

08 · WORKED EXAMPLE 3 — STANDARD FORM

Find the y-intercept of 4x + 2y = 10.

x = 04(0) + 2y = 102y = 10y = 5
AnswerThe y-intercept is (0, 5), so the initial value is 5.
09 · WORKED EXAMPLE 4 — TABLE

A linear function contains the points (−2, 8), (0, 2), and (3, −7). Find its initial value.

look for x = 0(0, 2)initial value = 2

You do not need to calculate the slope when the table already gives the output at x = 0.

10 · WORKED EXAMPLE 5 — CONTEXT

A bike rental costs C = 12 + 6h dollars for h hours. What does 12 represent?

h = 0C = 12 + 6(0)C = 12
Meaning$12 is the starting cost before any hourly charges are added.
11 · WORKED EXAMPLE 6 — EXAM STYLE

A container's volume is modeled by V = 48 − 3t, where t is time in minutes. What does the y-intercept represent?

t = 0V = 48 − 3(0)V = 48
Exam connectionThe y-intercept represents the container's initial volume: 48 volume units at time 0.
12 · COMMON MISTAKES
Using y = 0 instead of x = 0

Setting y = 0 finds the x-intercept. The y-intercept requires x = 0.

Reversing coordinates

A y-intercept of −4 is the point (0, −4), not (−4, 0).

Confusing slope with initial value

In y = mx + b, m is the rate of change and b is the initial value.

Ignoring units in context

State what the initial value measures, including dollars, liters, degrees, people, or other relevant units.

13 · EXAM STRATEGY

Translate “before anything happens” into input = 0.

Words such as initial, starting, fixed fee, or at time zero often point to the y-intercept. Confirm by substituting zero for the input and interpreting the resulting output in context.

input = 0→initial output

15 · LESSON RECAP

The y-intercept is the starting output.

  1. The y-intercept occurs where x = 0.
  2. In y = mx + b, the y-intercept value is b.
  3. In function notation, the initial value is f(0).
  4. In a table or graph, locate the point whose x-coordinate is 0.
  5. In context, explain what that starting amount means and include units.
