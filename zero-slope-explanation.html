Zero Slope
Algebra
01 · LESSON OBJECTIVE

Recognize, calculate, and interpret zero slope.

By the end of this lesson, you should be able to identify a horizontal line, calculate its slope from points, tables, graphs, or equations, and explain what a slope of zero means in context.

x changes→y stays constant
02 · WHAT YOU NEED TO KNOW

A horizontal line has slope zero.

For any two distinct points on a horizontal line, the y-values are equal. That makes the change in y equal to zero while the change in x is nonzero, so the slope is zero.

GraphhorizontalThe line neither rises nor falls.
Formulam = 0The vertical change is zero.
Tableconstant yDifferent x-values share the same y-value.
Equationy = bNo x-term is needed.
03 · KEY DEFINITIONS

Zero Slope

A slope equal to zero.

m = 0

Horizontal Line

A line whose y-coordinate is constant.

y = b

Constant Function

A function that gives the same output for every input in its domain.

f(x) = c
04 · CORE RULE / FORMULA

If y does not change, the slope is zero.

m = (y₂ − y₁) / (x₂ − x₁) = 0 / nonzero = 0

The denominator must be nonzero because the two chosen points must have different x-values. A zero numerator divided by any nonzero number equals zero.

05 · HOW IT WORKS

Check whether the output stays constant.

06 · WORKED EXAMPLE 1 — BASIC

Find the slope through (2, 7) and (8, 7).

Δy = 7 − 7 = 0Δx = 8 − 2 = 6m = 0/6 = 0
MeaningThe line is horizontal because y remains 7.
07 · WORKED EXAMPLE 2 — NEGATIVE COORDINATES

Find the slope through (−5, −3) and (4, −3).

Δy = −3 − (−3) = 0Δx = 4 − (−5) = 9m = 0/9 = 0

Key idea: The actual y-value can be positive, negative, or zero. If it stays constant, the slope is zero.

08 · WORKED EXAMPLE 3 — FROM AN EQUATION

What is the slope of y = 12?

y = 0x + 12m = 0
ConclusionThe graph is a horizontal line crossing the y-axis at 12.
09 · WORKED EXAMPLE 4 — FROM A TABLE

A table contains (−2, 5), (1, 5), and (6, 5). Find the slope.

Using (−2,5) and (1,5):Δy = 5 − 5 = 0Δx = 1 − (−2) = 3m = 0/3 = 0

The remaining point has the same y-value, confirming a constant linear relationship.

10 · WORKED EXAMPLE 5 — REVERSED POINT ORDER

Use (9, 4) and (−3, 4) to find the slope.

Δy = 4 − 4 = 0Δx = −3 − 9 = −12m = 0/(−12) = 0

Remember: Reversing the point order changes the sign of Δx, but zero divided by a nonzero number is still zero.

11 · WORKED EXAMPLE 6 — EXAM STYLE

A storage tank contains 450 liters at 2:00 p.m. and still contains 450 liters at 6:00 p.m. Assume the amount changes linearly during this interval. Find and interpret the slope.

Δvolume = 450 − 450 = 0 LΔtime = 6 − 2 = 4 hm = 0/4 = 0 L/h
InterpretationThe tank's volume does not change during the interval.
VISUAL GRAPH

See zero slope as a horizontal line.

The graph is generated from y = 4. The output stays 4 for every x-value, so the line has no vertical change.

Math cross-checkSubstitution verifies all three labeled points: x = −3 gives y = 4, x = 0 gives y = 4, and x = 5 gives y = 4. From (−3, 4) to (5, 4), Δy = 0 and Δx = 8, so m = 0/8 = 0.
DESMOS STRATEGY

Use a graphing tool to confirm zero slope.

Enter

y = 4

Look for

A horizontal line crossing the y-axis at 4 and passing through points such as (−3, 4), (0, 4), and (5, 4).

Use it to answer

Confirm that y stays constant while x changes, so the line's slope is zero.

Why it works

The equation fixes every output at 4. Any two distinct points therefore have Δy = 0 and a nonzero Δx.

Faster or not?

Recognizing the form y = b or equal y-values is faster by hand. Desmos is useful when you want a visual check.

Math cross-check: Using (−3, 4) and (5, 4), m = (4 − 4)/(5 − (−3)) = 0/8 = 0.

12 · COMMON MISTAKES
Confusing zero slope with undefined slope

Horizontal lines have slope 0. Vertical lines have undefined slope.

Using 0/0

Choose two distinct points with different x-values on a horizontal line, so the denominator is not zero.

Thinking y must equal zero

Any equation y = b is horizontal, not only y = 0.

Ignoring units

In context, a zero slope still has rate units, such as 0 liters per hour.

13 · EXAM STRATEGY

Spot constant output before calculating.

If a graph is horizontal or a table repeats the same y-value while x changes, you already know the slope is zero. Use the slope formula as a quick verification when needed.

same y-value→m = 0

15 · LESSON RECAP

Zero slope means no vertical change.

  1. A zero-slope line is horizontal.
  2. Its slope satisfies m = 0.
  3. Horizontal lines have equations of the form y = b.
  4. From points, equal y-values give Δy = 0 while Δx is nonzero.
  5. In context, zero slope means the output remains constant as the input changes.
