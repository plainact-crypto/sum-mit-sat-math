Combining Like Terms
Advanced Math
01 · LESSON OBJECTIVE

Simplify expressions without changing their value.

Like terms have exactly the same variable part, including the same exponents. To combine them, add or subtract their coefficients and keep the variable part unchanged.

3x + 5x - 2→8x - 2
02 · KEY DEFINITIONS

Term

A number, a variable, or a product of numbers and variables separated by + or − signs.

4x², -3x, 7

Coefficient

The numerical factor multiplying a variable part.

-5y → coefficient -5

Like Terms

Terms with identical variable factors and exponents.

2x² and -7x²
03 · CORE RULE

Combine coefficients only when the variable parts match exactly.

ax + bx = (a + b)x

Important: x and x² are not like terms. Constants combine only with constants.

04 · WORKED EXAMPLE 1 — BASIC

Simplify: 3x + 5x - 2

3x + 5x - 2(3 + 5)x - 28x - 2
Value checkAt x=2, the original gives 6+10−2=14 and 8x−2 gives 16−2=14.
05 · WORKED EXAMPLE 2 — VARIABLES AND CONSTANTS

Simplify: 7a - 3 + 2a + 5

(7a + 2a) + (-3 + 5)9a + 2

The variable terms combine with each other; the constants combine separately.

Value checkAt a=−1, both expressions equal −7.
06 · WORKED EXAMPLE 3 — NEGATIVE COEFFICIENTS

Simplify: 4y - 9y + 6 - 1

(4 - 9)y + (6 - 1)-5y + 5
Value checkAt y=2, both expressions equal −5.
07 · WORKED EXAMPLE 4 — DIFFERENT POWERS

Simplify: 2x² + 3x - 5 + 4x² - x + 8

(2x² + 4x²) + (3x - x) + (-5 + 8)6x² + 2x + 3

x²-terms combine with x²-terms, while x-terms form a separate group.

Value checkAt x=2, both expressions equal 31.
08 · WORKED EXAMPLE 5 — EXAM STYLE

An expression is 4p + 7 + 3p - 2. Write an equivalent simplified expression.

(4p + 3p) + (7 - 2)7p + 5
Math cross-checkAt p=4, the original and simplified expressions both equal 33.
09 · A FAST ORGANIZING METHOD

Group by variable part before doing arithmetic.

  1. Carry each sign with its term.
  2. Group terms with identical variable parts and exponents.
  3. Add or subtract only the coefficients inside each group.
  4. Combine constants separately.
  5. Read the simplified expression once more to make sure no unlike terms were merged.
10 · COMMON MISTAKES
Combining unlike terms

3x + 2x² cannot become 5x². The variable parts are different.

Changing the exponent

3x + 2x = 5x, not 5x². Adding terms does not multiply variables.

Losing a negative sign

In 6x - 9x, the second coefficient is −9, so the result is -3x.

Forgetting an implied coefficient

x means 1x and -x means -1x.

11 · EXAM STRATEGY

Match the variable part first; calculate second.

In an exam-style simplification question, scan the expression for matching variable parts before touching the numbers. This prevents the most common error: combining terms that look similar but have different variables or exponents.

13 · LESSON RECAP
  1. Like terms have identical variable parts and exponents.
  2. Combine their coefficients; keep the variable part unchanged.
  3. Combine constants with constants.
  4. Never merge unlike powers such as x and x².
  5. Use a quick substitution check when you want to verify equivalence.
