Shading Solution Regions
Algebra
01 · LESSON OBJECTIVE

Shade exactly the half-plane that satisfies a linear inequality.

By the end of this lesson, you should be able to graph the boundary, choose solid or dashed, test a point, and shade the correct side of the line.

y ≤ x + 1→solid boundary + shade below
02 · CORE IDEA

The line splits the plane. The inequality chooses one side.

A two-variable linear inequality has infinitely many ordered-pair solutions. On a graph, those solutions form a half-plane. The boundary line separates solutions from non-solutions.

Step 1Graph the boundaryReplace the inequality symbol with =.
Step 2Choose line style< or > is dashed; ≤ or ≥ is solid.
Step 3Test a pointUse a point not on the boundary, often (0,0).
Step 4Shade that sideIf the test point works, shade its side. If not, shade the opposite side.
03 · WORKED EXAMPLE 1

Graph and shade: y ≤ x + 1.

  1. Boundary.Use y = x + 1.
  2. Line style.The symbol ≤ includes equality, so draw a solid line.
  3. Test (0,0).0 ≤ 0 + 1 is true.
  4. Shade.Shade the side containing (0,0). In slope-intercept form, that is the region below the line.
Independent check(0,0) is a solution because 0≤1. A point above the line, such as (0,3), is not a solution because 3≤1 is false.
04 · WORKED EXAMPLE 2

Graph and shade: 2x + y > 4.

2x + y = 4y = −2x + 4

The strict symbol > makes the boundary dashed. Testing (0,0) gives 0 > 4, which is false, so do not shade the side containing the origin. Shade the opposite side, which is above y = −2x + 4.

Check another point(0,5) satisfies 2(0)+5>4, so it lies in the shaded solution region.
05 · VERTICAL REGIONS

For x ≥ −2, shade right of the vertical boundary.

The boundary is x = −2 and it is solid. Testing (0,0) gives 0 ≥ −2, which is true, so shade the side containing the origin: the region to the right of the line.

06 · WHEN (0,0) DOES NOT WORK AS A TEST POINT

Never test a point that lies on the boundary.

For y > 2x, the origin lies on the boundary because 0=2(0). Choose another easy point, such as (0,1). Since 1 > 0 is true, shade the side containing (0,1).

07 · COMMON MISTAKES
Shading before checking the boundary

First graph the equality and decide solid versus dashed.

Assuming “greater than” always means shade above

That shortcut is safe only after the inequality is solved for y with a positive y coefficient. A test point is more reliable.

Testing a point on the boundary

Choose a point not on the line, or the test will not tell you which side to shade.

Including a dashed boundary

A dashed line means points on the boundary are not solutions.

08 · EXAM STRATEGY

Use the four-step routine every time.

Boundary → line style → test point → shade. This prevents the two most common test-style errors: shading the wrong side and using the wrong boundary style.
