01 · LESSON OBJECTIVE

Cancel one variable to turn a system into one equation.

Use elimination to combine two linear equations, solve for one variable, then substitute back to find the second coordinate and verify the ordered pair.

2x + y = 7 and x − y = 2→(3, 1)
02 · WHAT YOU NEED TO KNOW

Adding equal equations preserves the common solution.

If the coefficients of one variable are opposites, adding the equations makes that variable disappear. If they are not opposites yet, multiply one or both equations by a nonzero number first.

Ready to eliminate+y and −yAdd the equations directly.
Same signs+2y and +2ySubtract, or multiply one equation by −1.
Different sizes2x and 3xScale equations to matching opposite coefficients.
Finishback-substituteFind the second coordinate and check both originals.
03 · KEY DEFINITIONS

Elimination

Combining equations so one variable cancels.

Equivalent Equation

An equation with the same solution set as the original after a valid operation.

System Solution

An ordered pair that satisfies every equation in the system.

04 · CORE RULE

Make opposite coefficients, combine, solve, and check.

ALIGN → CANCEL → SOLVE → RETURN → VERIFY
05 · HOW IT WORKS

Use this routine every time.

01
Line up like terms.Write x-terms, y-terms, and constants in matching columns.
02
Create opposite coefficients if needed.Multiply an entire equation, not just one term.
03
Add the equations.One variable should cancel completely.
04
Solve and back-substitute.Find the second coordinate, then verify both equations.
06 · WORKED EXAMPLE 1 — DIRECT ELIMINATION

Solve 2x + y = 7 and x − y = 2.

2x + y = 7 x − y = 23x = 9 → x = 33 − y = 2 → y = 1
Check2(3)+1=7 and 3−1=2, so (3, 1) satisfies both equations.
07 · WORKED EXAMPLE 2 — MULTIPLY ONE EQUATION

Solve x + 2y = 8 and 3x + y = 9.

2(3x + y = 9) → 6x + 2y = 18(6x + 2y) − (x + 2y) = 18 − 85x = 10 → x = 22 + 2y = 8 → y = 3
Check2+2(3)=8 and 3(2)+3=9.
08 · WORKED EXAMPLE 3 — MULTIPLY BOTH EQUATIONS

Solve 2x + 3y = 13 and 3x − 2y = 0.

2(2x + 3y = 13) → 4x + 6y = 263(3x − 2y = 0) → 9x − 6y = 013x = 26 → x = 23(2) − 2y = 0 → y = 3
Check2(2)+3(3)=13 and 3(2)−2(3)=0.
09 · WORKED EXAMPLE 4 — EXAM-STYLE

A system is 4x + 3y = 18 and 4x − y = 10. What is x + y?

(4x + 3y) − (4x − y) = 18 − 104y = 8 → y = 24x − 2 = 10 → x = 3x + y = 5

10 · WHY THE GRAPH MATCHES

The elimination result is the intersection.

For 2x + y = 7 and x − y = 2, elimination gives x = 3, then y = 1. Written as functions, the lines are y = −2x + 7 and y = x − 2, so their common point is exactly (3, 1).

11 · COMMON MISTAKES
Multiplying only one term

When scaling an equation, multiply every term on both sides.

Forgetting signs when subtracting

Subtracting an equation changes the sign of every term in that equation.

Stopping after one variable

Unless the question asks for only one value, find both coordinates.

Skipping verification

Substitute the ordered pair into both original equations.

12 · EXAM STRATEGY

Choose the cheapest variable to eliminate.

Look for equal, opposite, or easily matched coefficients before doing any algebra. Elimination is especially efficient when one variable already has opposite coefficients.

14 · LESSON RECAP

Elimination removes one variable without changing the common solution.

  1. Align like terms.
  2. Create opposite coefficients when needed.
  3. Add or subtract to eliminate one variable.
  4. Solve the resulting one-variable equation.
  5. Back-substitute and verify both original equations.
