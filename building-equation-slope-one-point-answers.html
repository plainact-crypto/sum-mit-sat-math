Building an Equation from Slope and One Point

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Slope 2 through (3, 5)

Answer: A) y = 2x − 1
Use y = mx + b. Substitute m = 2 and (x, y) = (3, 5): 5 = 2(3) + b, so b = −1. Therefore y = 2x − 1.

2. Slope −4 through (1, 7)

Answer: C) y = −4x + 11
7 = −4(1) + b, so b = 11. Therefore y = −4x + 11.

3. Slope 1/2 through (−2, 3)

Answer: A) y = (1/2)x + 4
3 = (1/2)(−2) + b = −1 + b, so b = 4. Therefore y = (1/2)x + 4.
02 · CORE PRACTICE

4. Slope 0 through (5, −6)

Answer: B) y = −6
A line with slope 0 is horizontal, so y is constant. Since the line passes through (5, −6), its equation is y = −6.

5. Slope 3 through (−1, 2)

Answer: A) y = 3x + 5
2 = 3(−1) + b = −3 + b, so b = 5. Thus y = 3x + 5.

6. Slope −2 through (4, −3)

Answer: C) y = −2x + 5
−3 = −2(4) + b = −8 + b, so b = 5. Thus y = −2x + 5.

7. Slope 2/3 through (6, 1)

Answer: A) y = (2/3)x − 3
1 = (2/3)(6) + b = 4 + b, so b = −3. Thus y = (2/3)x − 3.

8. Slope −1/4 through (−8, 5)

Answer: A) y = −(1/4)x + 3
5 = (−1/4)(−8) + b = 2 + b, so b = 3. Thus y = −(1/4)x + 3.

9. Slope 1.5 through (2, −1)

Answer: B) y = 1.5x − 4
−1 = 1.5(2) + b = 3 + b, so b = −4. Thus y = 1.5x − 4.

10. Increases by 5 units per hour; value 22 at 3 hours

Answer: A) y = 5x + 7
The rate is m = 5. Substitute the known point (3, 22): 22 = 5(3) + b, so b = 7. The model is y = 5x + 7.

11. Decreases by 7 per unit of x; value 30 when x = 4

Answer: A) y = −7x + 58
The slope is −7. Substitute (4, 30): 30 = −7(4) + b = −28 + b, so b = 58. Therefore y = −7x + 58.
03 · EXAM-STYLE PRACTICE

12. Slope 4 through (2, −5); find y when x = 6

Answer: C) 11
First find b: −5 = 4(2) + b, so b = −13. Then at x = 6, y = 4(6) − 13 = 24 − 13 = 11.

13. Temperature decreases 2.5°C per hour; 18°C at t = 3

Answer: A) T = −2.5t + 25.5
The slope is −2.5. Substitute (3, 18): 18 = −2.5(3) + b = −7.5 + b, so b = 25.5. Therefore T = −2.5t + 25.5.

14. Cost increases $12 per item; $95 for 5 items

Answer: A) C = 12x + 35
The slope is 12 dollars per item. Substitute (5, 95): 95 = 12(5) + b = 60 + b, so b = 35. Thus C = 12x + 35.

15. Slope −3/2 through (4, 7); find the y-intercept

Answer: C) 13
7 = (−3/2)(4) + b = −6 + b, so b = 13. The y-intercept is 13.

16. Slope 5/3 through (3, −2); write standard form

Answer: A) 5x − 3y = 21
Start with y = (5/3)x + b. Substituting (3, −2) gives −2 = 5 + b, so b = −7. Then y = (5/3)x − 7. Multiply by 3: 3y = 5x − 21, so 5x − 3y = 21.
04 · CHALLENGE PROBLEMS

17. Slope k + 1 through (2, 11) with y-intercept 3

Answer: B) 3
Using the point and intercept, the slope is (11 − 3)/(2 − 0) = 8/2 = 4. Since k + 1 = 4, k = 3.

18. Through (6, −1); y decreases 10 when x increases 4

Answer: A) y = −(5/2)x + 14
The slope is Δy/Δx = −10/4 = −5/2. Substitute (6, −1): −1 = (−5/2)(6) + b = −15 + b, so b = 14. Therefore y = −(5/2)x + 14.
