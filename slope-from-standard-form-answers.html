Slope from Standard Form

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. What is the slope of 3x + 4y = 20?

Answer: B) −3/4
For Ax + By = C, the slope is m = −A/B. Here A = 3 and B = 4, so m = −3/4.

2. What is the slope of −5x + 2y = 8?

Answer: D) 5/2
Using m = −A/B gives m = −(−5)/2 = 5/2.

3. What is the slope of 7x − y = 9?

Answer: D) 7
Here A = 7 and B = −1, so m = −7/(−1) = 7.
02 · CORE PRACTICE

4. What is the slope of 8x + 4y = 12?

Answer: A) −2
m = −8/4 = −2.

5. What is the slope of −6x − 3y = 15?

Answer: A) −2
m = −(−6)/(−3) = 6/(−3) = −2.

6. What is the slope of x + 5y = 30?

Answer: B) −1/5
A = 1 and B = 5, so m = −1/5.

7. What is the slope of 9x − 12y = 24?

Answer: C) 3/4
m = −9/(−12) = 9/12 = 3/4.

8. What is the slope of 2y = 18?

Answer: A) 0
There is no x-term, so A = 0. Therefore m = −0/2 = 0. This is the horizontal line y = 9.

9. What is the slope of 5x = 25?

Answer: D) undefined
There is no y-term, so B = 0. The equation is x = 5, a vertical line, whose slope is undefined.

10. What is the slope of 0.6x + 0.3y = 4.2?

Answer: A) −2
m = −0.6/0.3 = −2.

11. What is the slope of (3/2)x − (9/4)y = 6?

Answer: C) 2/3
m = −(3/2)/(−9/4) = (3/2)(4/9) = 12/18 = 2/3.
03 · EXAM-STYLE PRACTICE

12. A relationship between x and y is modeled by 4x + 2y = 100. If x increases by 1, how does y change?

Answer: B) y decreases by 2
The slope is m = −4/2 = −2. A 1-unit increase in x changes y by −2, so y decreases by 2.

13. A temperature model is 5t + 2T = 60, where t is time in hours and T is temperature in degrees. What is the slope of T with respect to t?

Answer: A) −5/2 degrees per hour
Treat t as the horizontal variable and T as the vertical variable. Solving for T gives T = −(5/2)t + 30, so the slope is −5/2 degrees per hour.

14. Which equation represents a line with slope 3/4?

Answer: C) 3x − 4y = 8
For 3x − 4y = 8, m = −3/(−4) = 3/4. The other options have different slopes.

15. The line ax + 6y = 18 has slope −2/3. What is a?

Answer: D) 4
Its slope is −a/6. Set −a/6 = −2/3. Multiplying by −6 gives a = 4.

16. The line 2x + ky = 14 has slope 1/4. What is k?

Answer: A) −8
Its slope is −2/k. Set −2/k = 1/4. Cross-multiplying gives −8 = k.
04 · CHALLENGE PROBLEMS

17. The line (2p − 1)x + (p + 3)y = 10 has slope −1. What is p?

Answer: D) 4
The slope is −(2p − 1)/(p + 3). Set it equal to −1: (2p − 1)/(p + 3) = 1. Then 2p − 1 = p + 3, so p = 4.

18. The line (q + 2)x − (q − 1)y = 8 has undefined slope. What is q?

Answer: C) 1
A standard-form line has undefined slope when the y-coefficient B is 0. Here B = −(q − 1). Set −(q − 1) = 0 to get q = 1.
