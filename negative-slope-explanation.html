Negative Slope
Algebra
01 · LESSON OBJECTIVE

Recognize, calculate, and interpret negative slope.

By the end of this lesson, you should be able to identify a line with negative slope, calculate its slope from points, tables, graphs, or equations, and explain what a negative slope means in context.

x increases→y decreases
02 · WHAT YOU NEED TO KNOW

A negative slope falls from left to right.

For a line with negative slope, larger x-values correspond to smaller y-values. In the slope formula, the changes in x and y have opposite signs, so their quotient is negative.

Graphfalls rightThe line goes downward as x increases.
Formulam < 0The slope value is negative.
Tabley decreasesAs x increases, y decreases at a constant rate.
Equationy = mx + bThe coefficient m is negative.
03 · KEY DEFINITIONS

Negative Slope

A slope less than zero.

m < 0

Rate of Change

The change in y for each unit change in x.

Δy / Δx

Decreasing Linear Function

A linear function whose output decreases as its input increases.

f(x₂) < f(x₁) when x₂ > x₁
04 · CORE RULE / FORMULA

Negative slope means the numerator and denominator have opposite signs.

m = (y₂ − y₁) / (x₂ − x₁) < 0

If you move from a left point to a right point, Δx is positive while Δy is negative. If you reverse both points, Δx is negative while Δy is positive. Either way, the quotient stays negative.

06 · WORKED EXAMPLE 1 — BASIC

Find the slope through (1, 9) and (5, 1).

Δy = 1 − 9 = −8Δx = 5 − 1 = 4m = −8/4 = −2
MeaningFor every 1-unit increase in x, y decreases by 2 units.
07 · WORKED EXAMPLE 2 — FRACTIONAL SLOPE

Find the slope through (−2, 6) and (4, 3).

Δy = 3 − 6 = −3Δx = 4 − (−2) = 6m = −3/6 = −1/2

Visual meaning: A slope of −1/2 falls 1 unit for every 2 units moved to the right.

08 · WORKED EXAMPLE 3 — FROM AN EQUATION

What is the slope of y = −3.5x + 8?

y = mx + bm = −3.5
ConclusionBecause −3.5 < 0, the line has negative slope.
09 · WORKED EXAMPLE 4 — FROM A TABLE

A table contains (0, 14), (2, 8), and (4, 2). Find the slope.

Δy = 8 − 14 = −6Δx = 2 − 0 = 2m = −6/2 = −3

The next interval gives the same rate: (2 − 8)/(4 − 2) = −6/2 = −3.

10 · WORKED EXAMPLE 5 — REVERSED POINT ORDER

Use (6, 2) and (2, 10) to find the slope.

Δy = 10 − 2 = 8Δx = 2 − 6 = −4m = 8/(−4) = −2

Key idea: Reversing both subtraction orders does not change the slope.

11 · WORKED EXAMPLE 6 — EXAM STYLE

A phone battery is at 92% after 1 hour and 68% after 5 hours. The charge level changes linearly. Find and interpret the slope.

Δcharge = 68 − 92 = −24 percentage pointsΔtime = 5 − 1 = 4 hm = −24/4 = −6 percentage points per hour
InterpretationThe battery level decreases by 6 percentage points each hour.
12 · COMMON MISTAKES
Thinking a negative slope must be steep

The sign tells direction, while the absolute value tells steepness.

Reversing only one subtraction

Use the same point order for both y and x differences.

Dropping the negative sign

If y decreases while x increases, the slope must be negative.

Ignoring units

In context, slope units are output units per input unit.

13 · EXAM STRATEGY

Predict the sign before doing arithmetic.

First decide whether the relationship rises or falls as x increases. If it falls, your computed slope should be negative. This fast check helps catch sign and subtraction errors.

fall right→m < 0

15 · LESSON RECAP

Negative slope describes a decreasing linear relationship.

  1. A negative-slope line falls from left to right.
  2. Its slope satisfies m < 0.
  3. In y = mx + b, a negative coefficient of x gives negative slope.
  4. From points, compute m = Δy/Δx using a consistent subtraction order.
  5. In context, interpret the negative rate with correct units.
