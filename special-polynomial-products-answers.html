Special Polynomial Products

Solutions correspond exactly to Practice Questions 1–18.

1. Expand: (x + 6)²

Use (a+b)²=a²+2ab+b²: x²+2(x)(6)+36=x²+12x+36.
Answer: A) x² + 12x + 36

2. Expand: (y - 5)²

Use (a-b)²=a²-2ab+b²: y²-2(y)(5)+25=y²-10y+25.
Answer: A) y² - 10y + 25

3. Multiply: (a + 4)(a - 4)

Conjugates use (u+v)(u-v)=u²-v², so a²-4²=a²-16.
Answer: A) a² - 16

4. Expand: (2x + 3)²

(2x)²+2(2x)(3)+3²=4x²+12x+9.
Answer: A) 4x² + 12x + 9

5. Expand: (3m - 2)²

(3m)²-2(3m)(2)+2²=9m²-12m+4.
Answer: A) 9m² - 12m + 4

6. Multiply: (5p + 1)(5p - 1)

This is a difference of squares: (5p)²-1²=25p²-1.
Answer: A) 25p² - 1

7. Multiply: (4r - 7)(4r + 7)

Conjugates cancel the middle terms: (4r)²-7²=16r²-49.
Answer: A) 16r² - 49

8. Expand: (2x - 5)²

(2x)²-2(2x)(5)+5²=4x²-20x+25.
Answer: A) 4x² - 20x + 25

9. Expand: (3y + 4)²

(3y)²+2(3y)(4)+4²=9y²+24y+16.
Answer: A) 9y² + 24y + 16

10. Multiply: (6a - b)(6a + b)

Use the conjugate identity: (6a)²-b²=36a²-b².
Answer: A) 36a² - b²

11. Expand: ((1/2)x + 3)²

[(1/2)x]²+2[(1/2)x](3)+3²=(1/4)x²+3x+9.
Answer: A) (1/4)x² + 3x + 9

12. Which expression is equivalent to (t + 9)²?

t²+2(t)(9)+9²=t²+18t+81.
Answer: A) t² + 18t + 81

13. A square has side length (x + 7) meters. Which polynomial represents its area?

Area=(x+7)²=x²+14x+49, and area units are square meters.
Answer: A) x² + 14x + 49 m²

14. If (2n + k)² has a middle term of 20n, what is k?

The middle term is 2(2n)(k)=4kn. Set 4kn=20n, so k=5.
Answer: A) 5

15. Which factorization is equivalent to 81x² - 16?

81x²-16=(9x)²-4², so it factors as (9x-4)(9x+4).
Answer: A) (9x - 4)(9x + 4)

16. Simplify: (x + 5)² - (x - 5)²

Treat the squares as A²-B²: [(x+5)-(x-5)][(x+5)+(x-5)]=(10)(2x)=20x.
Answer: A) 20x

17. If (x + a)² = x² + 14x + 49 for all x, what is a?

Expanding gives x²+2ax+a². Matching coefficients gives 2a=14, so a=7; then a²=49 confirms it.
Answer: A) 7

18. Simplify without fully expanding both squares: (3x + 2)² - (3x - 2)²

Use A²-B² with A=3x+2 and B=3x-2: (A-B)(A+B)=(4)(6x)=24x.
Answer: A) 24x
