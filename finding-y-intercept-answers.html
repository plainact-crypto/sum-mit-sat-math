Finding Y-Intercept

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. What is the y-intercept of 2x + 3y = 18?

Answer: A) (0, 6)
At the y-intercept, x = 0. Then 3y = 18, so y = 6.

2. What is the y-intercept of y = −4x + 12?

Answer: D) (0, 12)
Set x = 0: y = 12.

3. What is the y-coordinate of the y-intercept of x − 2y = −7?

Answer: C) 7/2
Set x = 0: −2y = −7, so y = 7/2.
02 · CORE PRACTICE

4. Find the y-intercept of 5x + 2y = 30.

Answer: B) (0, 15)
Set x = 0: 2y = 30, so y = 15.

5. Find the y-intercept of 3x − y = −15.

Answer: B) (0, 15)
Set x = 0: −y = −15, so y = 15.

6. Find the y-intercept of y = (1/2)x − 4.

Answer: A) (0, −4)
Set x = 0: y = −4.

7. Find the y-intercept of y = −3x − 9.

Answer: C) (0, −9)
Set x = 0: y = −9.

8. Find the y-intercept of 8x + 6y = 7.

Answer: C) (0, 7/6)
Set x = 0: 6y = 7, so y = 7/6.

9. What is the y-intercept of the horizontal line y = 4?

Answer: B) (0, 4)
The line y = 4 crosses the y-axis when x = 0, at (0, 4).

10. How many y-intercepts does the vertical line x = 4 have?

Answer: A) 0
Every point on x = 4 has x-coordinate 4, so it never reaches the y-axis x = 0.

11. How many points does the line x = 0 share with the y-axis?

Answer: D) Infinitely many
The line x = 0 is the y-axis itself, so every point on it lies on the y-axis.
03 · SAT-STYLE PRACTICE

12. The line 4x + 5y = 60 crosses the y-axis at (0, b). What is b?

Answer: A) 12
Set x = 0: 5b = 60, so b = 12.

13. A quantity is modeled by y = −2x + 18. What is its value when x = 0?

Answer: D) 18
Substitute x = 0: y = 18.

14. The equation 3y = 12 − 6x represents a line. What is its y-intercept?

Answer: B) (0, 4)
Set x = 0: 3y = 12, so y = 4.

15. A tank contains y = 120 − 8x liters after x minutes. According to the model, how many liters are in the tank at x = 0?

Answer: C) 120
Substitute x = 0: y = 120 liters.

16. For the line Ax + 7y = −21, where A is a constant, what is the y-coordinate of the y-intercept?

Answer: B) −3
Set x = 0: 7y = −21, so y = −3. The value of A does not affect the y-intercept.
04 · CHALLENGE PROBLEMS

17. The line 4x + ky = 24 has y-intercept (0, 6). What is k?

Answer: B) 4
Substitute (0, 6): 4(0) + 6k = 24, so k = 4.

18. A line has y-intercept (0, 6) and x-intercept (−2, 0). If its equation is y = mx + 6, what is m?

Answer: D) 3
Use (−2, 0): 0 = −2m + 6, so m = 3.
