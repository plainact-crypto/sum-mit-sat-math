01 · LESSON OBJECTIVE

Recognize and solve a linear system with exactly one solution.

By the end of this lesson, you should be able to identify when two linear equations have one common ordered pair, solve for that pair using a suitable method, and verify the result in both equations.

two distinct nonparallel lines→one intersection → one solution
02 · WHAT YOU NEED TO KNOW

A system solution must satisfy every equation at the same time.

For two linear equations in two variables, each equation represents a line. A point that lies on both lines satisfies both equations. If the lines meet at exactly one point, the system has exactly one solution.

Graph viewone intersectionThe shared point is the solution.
Algebra viewone ordered pairSubstitution or elimination produces unique values of x and y.
Slope cluedifferent slopesTwo nonvertical lines with different slopes intersect exactly once.
Final checkverify both equationsThe same ordered pair must make both equations true.
03 · KEY DEFINITIONS

System of Linear Equations

Two or more linear equations considered together.

Equation 1 + Equation 2

Solution

An ordered pair that satisfies every equation in the system.

(x, y)

One Solution

A system with exactly one common ordered pair.

exactly one intersection
04 · CORE RULE / FORMULA

One shared point means one solution.

different slopes → one intersection → one solution

When two nonvertical lines have different slopes, they cannot stay parallel, so they meet once. A vertical line and a nonvertical line also meet once. Algebraically, a one-solution system reduces to one definite value for one variable and then one definite value for the other.

06 · WORKED EXAMPLE 1 — INTERSECTION

Solve y = 2x + 1 and y = −x + 7.

2x + 1 = −x + 73x = 6x = 2y = 2(2) + 1 = 5
Check2(2) + 1 = 5 and −(2) + 7 = 5, so (2, 5) lies on both lines.
07 · WORKED EXAMPLE 2 — SUBSTITUTION

Solve y = 3x − 4 and 2x + y = 11.

2x + (3x − 4) = 115x − 4 = 115x = 15 → x = 3y = 3(3) − 4 = 5
Verify2(3) + 5 = 11 and 5 = 3(3) − 4, so the solution is (3, 5).
08 · WORKED EXAMPLE 3 — ELIMINATION

Solve 2x + y = 9 and x − y = 0.

(2x + y) + (x − y) = 9 + 03x = 9 → x = 33 − y = 0 → y = 3
Verify2(3) + 3 = 9 and 3 − 3 = 0, so the solution is (3, 3).
09 · WORKED EXAMPLE 4 — STANDARD FORM

Solve 3x + 2y = 12 and x + y = 5.

x = 5 − y3(5 − y) + 2y = 1215 − y = 12 → y = 3x = 5 − 3 = 2
Verify3(2) + 2(3) = 12 and 2 + 3 = 5, so the solution is (2, 3).
10 · WORKED EXAMPLE 5 — CLASSIFY BY SLOPE

Does 4x − 2y = 6 and 3x + y = 7 have one solution?

4x − 2y = 6 → y = 2x − 33x + y = 7 → y = −3x + 7slopes: 2 and −3different slopes → exactly one solution

Solving 2x − 3 = −3x + 7 gives x = 2 and y = 1, confirming the unique intersection (2, 1).

11 · WORKED EXAMPLE 6 — EXAM STYLE

Plan A costs 4h + 18 dollars and Plan B costs 7h + 6 dollars after h hours. When are the costs equal?

4h + 18 = 7h + 612 = 3hh = 4cost = 4(4) + 18 = 34
InterpretThe models have different rates, so they meet once. At 4 hours, both costs are $34.
12 · COMMON MISTAKES
Stopping after finding one variable

A system solution is an ordered pair. Find both x and y.

Checking only one equation

The pair must satisfy both original equations, not just the equation used last.

Trusting a rough graph too much

A sketch may suggest an intersection, but exact coordinates should come from algebra or a precise graph.

Mixing up slope cases

Different slopes give one solution. Equal slopes require a separate check for no solution or infinitely many solutions.

13 · EXAM STRATEGY

Choose the fastest exact method, then verify.

If one equation already isolates a variable, substitution is often efficient. If coefficients cancel easily, elimination may be faster. If the question asks about the number of solutions, compare slopes or line relationships before doing full algebra.

choose method→solve → ordered pair → verify both

15 · LESSON RECAP

A one-solution system has one common ordered pair.

  1. The solution must satisfy both equations.
  2. Graphically, one solution means exactly one intersection.
  3. Different slopes guarantee one intersection for two nonvertical lines.
  4. Substitution and elimination can find the exact ordered pair.
  5. Always verify the final pair in both original equations.
