Solving from Tables

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Shared ordered pair

Answer: B) (1, 3)
The ordered pair (1, 3) appears in both tables, so it satisfies both relationships and is the system solution.

2. Matching row

Answer: B) (1, 3)
At x = 1, both tables give y = 3. No other listed x-value gives the same output in both tables.

3. Meaning of a common row

Answer: C) A solution (4, −2) to both equations
A row shared by both tables gives an x-value and y-value that make both equations true, so (4, −2) is a system solution.
02 · CORE PRACTICE

4. Compare table outputs

Answer: C) (2, 5)
For x = 2, the first relationship gives 2(2)+1 = 5 and the second gives −2+7 = 5. Thus both tables share (2, 5).

5. Equal rates, different values

Answer: A) No solutions
Table A increases by 2 for every increase of 1 in x, and Table B also increases by 2. Their outputs differ by 5 at each listed x, so the corresponding lines are distinct and parallel.

6. Identical linear tables

Answer: D) Infinitely many solutions
The tables have the same listed points and both relationships are linear. Therefore they represent the same line, so every point on that line is a solution.

7. Common listed point

Answer: C) (1, 5)
At x = 1, both tables give y = 5. The other listed rows do not match.

8. Equal outputs at x = 4

Answer: C) (4, 3)
When x = 4, both tables show y = 3, so the shared row is (4, 3).

9. Exact y-value

Answer: B) 10/3
From x − y = −1, y = x + 1. At x = 7/3, y = 7/3 + 1 = 10/3. Check: 2(7/3)+10/3 = 24/3 = 8.

10. Different rates through one point

Answer: B) (3, 8) is their unique solution
Both lines pass through (3, 8), but their slopes are 2 and −1. Different slopes mean they can intersect only once, so the shared point is the unique solution.

11. Infer an intersection between rows

Answer: C) (3, 3)
Table A follows y = 6 − x and Table B follows y = x. Set them equal: 6 − x = x, so 2x = 6, x = 3, and y = 3.

12. Read a system solution from a row

Answer: A) (−2, 9)
Equal outputs of 9 at x = −2 give the common ordered pair (−2, 9).
03 · EXAM-STYLE PRACTICE

13. Printing-plan comparison

Answer: C) 30 posters
At 30 posters, both plans cost $34. That common table value identifies the quantity where the two models are equal.

14. Runner distances

Answer: B) 6 minutes
At t = 6 minutes, both tables show 13 km. Therefore their recorded distances are equal at 6 minutes.

15. Parameter from a common point

Answer: C) 4
Substitute (3, 14) into y = kx + 2: 14 = 3k + 2. Then 12 = 3k, so k = 4.

16. Intersection from two linear tables

Answer: D) They meet at (8/3, 28/3)
Equation A has slope 2 and y-intercept 4, so y = 2x + 4. Equation B has slope −1 and y-intercept 12, so y = −x + 12. Set them equal: 2x + 4 = −x + 12, giving x = 8/3 and y = 28/3.

17. Same output, different rates

Answer: A) Their unique solution has x = 5
The lines share a point when x = 5. Because their rates of change are different, they are distinct nonparallel lines and can intersect only once.
04 · CHALLENGE PROBLEMS

18. Exact fractional intersection

Answer: C) (3/2, 2)
Set (2/3)x + 1 = −(2/3)x + 3. Then (4/3)x = 2, so x = 3/2. Substitution gives y = 2.

19. Parameter from a shared point

Answer: B) 3
Use (2, 5) in y = ax − 1: 5 = 2a − 1, so 6 = 2a and a = 3. The second equation checks: −2 + 7 = 5.
