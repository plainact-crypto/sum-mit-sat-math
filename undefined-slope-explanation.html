Undefined Slope
Algebra
01 · LESSON OBJECTIVE

Recognize, calculate, and interpret undefined slope.

By the end of this lesson, you should be able to identify a vertical line, explain why its slope is undefined, and recognize undefined slope from points, tables, graphs, and equations.

x stays constant→slope is undefined
02 · WHAT YOU NEED TO KNOW

A vertical line has undefined slope.

Slope is the change in y divided by the change in x. On a vertical line, two distinct points have the same x-coordinate, so the change in x is zero. Division by zero is undefined.

GraphverticalThe line goes straight up and down.
FormulaΔx = 0The slope denominator is zero.
Tableconstant xDifferent y-values share the same x-value.
Equationx = aA vertical line fixes x at one value.
03 · KEY DEFINITIONS

Undefined Slope

A slope that would require division by zero.

m = nonzero / 0

Vertical Line

A line whose x-coordinate is constant.

x = a

Change in x

The horizontal change between two points.

Δx = x₂ − x₁
04 · CORE RULE / FORMULA

If x does not change between two distinct points, the slope is undefined.

m = (y₂ − y₁) / (x₂ − x₁) = nonzero / 0 → undefined

Do not replace an undefined slope with zero. Zero slope and undefined slope describe different kinds of lines.

05 · HOW IT WORKS

Check the horizontal change first.

03

06 · WORKED EXAMPLE 1 — BASIC

Find the slope through (3, −2) and (3, 7).

Δy = 7 − (−2) = 9Δx = 3 − 3 = 0m = 9/0 → undefined
MeaningBoth points have x = 3, so the line is vertical.
07 · WORKED EXAMPLE 2 — NEGATIVE COORDINATES

Find the slope through (−5, 4) and (−5, −8).

Δy = −8 − 4 = −12Δx = −5 − (−5) = 0m = −12/0 → undefined

Key idea: The sign of the y-values does not matter. Equal x-values for distinct points create a zero denominator.

08 · WORKED EXAMPLE 3 — FROM AN EQUATION

What is the slope of x = 6?

x is always 6Δx = 0 between any two distinct pointsslope → undefined
ConclusionThe graph is a vertical line crossing the x-axis at 6.
09 · WORKED EXAMPLE 4 — FROM A TABLE

A table contains (2, −4), (2, 1), and (2, 9). What is the slope?

Using (2,−4) and (2,1):Δy = 1 − (−4) = 5Δx = 2 − 2 = 0m = 5/0 → undefined

The repeated x-value shows that all listed points lie on the vertical line x = 2.

10 · WORKED EXAMPLE 5 — COMPARE WITH ZERO SLOPE

Compare the lines through A(1, 5), B(7, 5) and C(4, −1), D(4, 8).

AB: Δy = 0, Δx = 6 → m = 0CD: Δy = 9, Δx = 0 → m is undefined

Remember: Horizontal means zero slope. Vertical means undefined slope.

12 · COMMON MISTAKES
Calling the slope zero

A zero denominator makes slope undefined, not zero.

Writing y = a for a vertical line

Vertical lines have equations x = a. Equations y = b are horizontal.

Dividing by zero anyway

Division by zero is not a real-number operation, so the slope has no numerical value.

Using identical points

Slope compares two distinct points. Repeating the exact same point gives 0/0 and does not determine a line.

13 · EXAM STRATEGY

Spot equal x-values before calculating.

If two distinct points have the same x-coordinate, or a graph is vertical, the slope is undefined. Recognizing that structure is faster and safer than trying to force a numerical slope.

same x-value→undefined slope

15 · LESSON RECAP

Undefined slope means no horizontal change.

  1. An undefined-slope line is vertical.
  2. Its equation has the form x = a.
  3. Two distinct points on it share the same x-coordinate.
  4. The slope formula produces a zero denominator.
  5. Undefined slope is different from zero slope.
