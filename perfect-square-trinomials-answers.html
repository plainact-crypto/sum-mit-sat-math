Perfect-Square Trinomials

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Factor completely: x² + 10x + 25

Answer: A) (x + 5)²
A perfect-square trinomial has the form a² + 2ab + b². Here x² + 10x + 25 = x² + 2(x)(5) + 5², so the factorization is (x + 5)².

2. Factor completely: x² − 14x + 49

Answer: A) (x − 7)²
Since 49 = 7² and −14x = 2(x)(−7), the trinomial is x² + 2(x)(−7) + (−7)² = (x − 7)².

3. Factor completely: 4x² + 12x + 9

Answer: A) (2x + 3)²
The first and last terms are (2x)² and 3², and the middle term is 2(2x)(3) = 12x. Therefore 4x² + 12x + 9 = (2x + 3)².
02 · CORE PRACTICE

4. Factor: 9x² − 24x + 16

Answer: A) (3x − 4)²
9x² = (3x)², 16 = 4², and −24x = 2(3x)(−4). Thus the trinomial is (3x − 4)².

5. Factor: 25y² + 30y + 9

Answer: A) (5y + 3)²
25y² = (5y)², 9 = 3², and 30y = 2(5y)(3), so the factorization is (5y + 3)².

6. Factor: x² + 18x + 81

Answer: A) (x + 9)²
Because 81 = 9² and 18x = 2(x)(9), x² + 18x + 81 = (x + 9)².

7. Factor: 16m² − 40m + 25

Answer: A) (4m − 5)²
16m² = (4m)², 25 = 5², and −40m = 2(4m)(−5). Therefore the expression factors as (4m − 5)².

8. Factor: 36a² + 60ab + 25b²

Answer: A) (6a + 5b)²
The outer terms are (6a)² and (5b)², while the middle term is 2(6a)(5b) = 60ab. Hence the trinomial is (6a + 5b)².

9. Which statement about x² + 12x + 35 is correct?

Answer: A) It is not a perfect-square trinomial; it factors as (x + 5)(x + 7).
A perfect square with middle term 12x would need constant 36 because (x + 6)² = x² + 12x + 36. Here 35 = 5·7 and 5 + 7 = 12, so x² + 12x + 35 = (x + 5)(x + 7).

10. If x² + kx + 64 = (x + 8)², what is k?

Answer: A) 16
Expand (x + 8)² = x² + 16x + 64. Matching coefficients gives k = 16.

11. If 9x² − 42x + c = (3x − 7)², what is c?

Answer: A) 49
Expanding (3x − 7)² gives 9x² − 42x + 49, so c = 49.
03 · EXAM-STYLE PRACTICE

12. A square has area 4x² + 20x + 25 square units. Which expression represents its side length?

Answer: A) 2x + 5
The area factors as 4x² + 20x + 25 = (2x + 5)², so the positive side length is 2x + 5.

13. If x² − 2kx + 36 = (x − 6)², what is k?

Answer: A) 6
Expand (x − 6)² = x² − 12x + 36. Matching −2k with −12 gives −2k = −12, so k = 6.

14. Which trinomial is a perfect-square trinomial?

Answer: A) 49x² + 56x + 16
49x² = (7x)² and 16 = 4². The required middle term is 2(7x)(4) = 56x, so 49x² + 56x + 16 = (7x + 4)².

15. Factor completely: 64p² − 80pq + 25q²

Answer: A) (8p − 5q)²
64p² = (8p)² and 25q² = (5q)². Since −80pq = 2(8p)(−5q), the factorization is (8p − 5q)².

16. For positive constants a and b, (ax + b)² = 9x² + 24x + 16. What is a + b?

Answer: A) 7
Matching squares gives a² = 9 and b² = 16. Since a and b are positive, a = 3 and b = 4. The middle term also checks: 2abx = 2(3)(4)x = 24x. Therefore a + b = 7.
04 · CHALLENGE PROBLEMS

17. Factor completely: 4x⁴ + 20x² + 25

Answer: A) (2x² + 5)²
Treat x² as the variable unit. The first term is (2x²)², the last is 5², and the middle term is 2(2x²)(5) = 20x². Thus 4x⁴ + 20x² + 25 = (2x² + 5)².

18. Factor completely: 81x⁶ − 126x³y² + 49y⁴

Answer: A) (9x³ − 7y²)²
81x⁶ = (9x³)² and 49y⁴ = (7y²)². The middle term is 2(9x³)(−7y²) = −126x³y², so the trinomial equals (9x³ − 7y²)².
