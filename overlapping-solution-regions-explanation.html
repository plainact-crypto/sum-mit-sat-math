Overlapping Solution Regions
Algebra
01 · LESSON OBJECTIVE

Find the points that satisfy every constraint at the same time.

An overlapping solution region is the common part of two or more inequality regions. By the end of this lesson, you should be able to identify the overlap, locate important boundary intersections, test candidate points, and use the feasible region to answer school and exam-style questions.

condition 1 AND condition 2→keep only the common region
02 · CORE IDEA

Overlap means every inequality is true.

Each inequality produces its own solution region. A system uses the word AND, so a point belongs to the system only when it lies in every required region. A point in just one shaded half-plane is not enough.

1Graph each boundaryReplace the inequality sign with =.
2Choose each sideShade the half-plane that satisfies that inequality.
3Locate intersectionsBoundary intersections often create corners or limits.
4Keep the overlapThe common region is the system solution.
03 · WORKED EXAMPLE

Find the overlap of y ≥ x + 1 and y ≤ −x + 7.

  1. Use the boundaries.Graph y = x + 1 and y = −x + 7. Both inequalities include equality, so both boundaries are solid.
  2. Shade the correct sides.The first inequality keeps points on or above y=x+1. The second keeps points on or below y=−x+7.
  3. Find where the boundaries meet.Set x+1=−x+7. Then 2x=6, so x=3 and y=4.
  4. Describe the overlap.The solution region lies between the two lines for x-values up to the meeting point. The corner (3,4) is included because both inequalities are inclusive.
Point checkAt (0,3): 3≥1 and 3≤7, so (0,3) is inside the overlap. At (4,4): 4≥5 is false, so (4,4) is outside.
04 · WHY THE INTERSECTION MATTERS

The boundary intersection can mark where overlap begins or ends.

For the example above, overlap requires x+1 ≤ −x+7. Solving gives x≤3. That agrees with the graph: once x moves past 3, the lower requirement y≥x+1 sits above the upper requirement y≤−x+7, so no y-value can satisfy both.

x + 1 ≤ −x + 7→x ≤ 3
05 · STRICT VS INCLUSIVE BOUNDARIES

Line style decides whether an edge belongs to the overlap.

≤ or ≥

The boundary is included.

solid

< or >

The boundary is excluded.

dashed

Mixed system

Judge each boundary separately.

one may be solid, one dashed

If the system were y > x+1 and y < −x+7, the same geometric area would lie between the boundaries for x<3, but neither boundary—and therefore not the meeting point—would be included.

06 · FEASIBLE REGIONS

Real constraints turn overlap into a set of allowed choices.

Suppose x and y represent quantities that cannot be negative, with constraints x≥0, y≥0, and 2x+y≤6. The overlap is the triangular feasible region in the first quadrant on or below the line 2x+y=6. Its corner points are (0,0), (0,6), and (3,0).

Context check(2,2) is feasible because 2≥0, 2≥0, and 2(2)+2=6. The point (3,2) is not feasible because 2(3)+2=8>6.
07 · TESTING A CANDIDATE POINT

Substitution is the safest final check.

When a graph is crowded, substitute the candidate point into every inequality. Stop as soon as one condition fails. For x≥−1, y≤3, and x+y≥1, the point (0,2) works because 0≥−1, 2≤3, and 0+2≥1.

08 · WHEN THERE IS NO OVERLAP

Contradictory constraints create an empty solution set.

Consider y > x+4 and y < x+1. The first requires y to be above a line that is always 3 units higher than the second, while the second requires y to be below the lower line. No ordered pair can satisfy both, so the system has no overlapping solution region.

09 · COMMON MISTAKES
Counting singly shaded areas

Only the common shading solves an AND system.

Ignoring the boundary symbol

A correct region can still be wrong if a strict edge is drawn solid or an inclusive edge is dashed.

Guessing a corner

Calculate a boundary intersection algebraically before labeling it.

Checking only one constraint

A feasible point must pass every inequality in the system.

10 · EXAM STRATEGY

Use intersections to narrow the search, then verify.

On an exam-style question asking for a greatest or least possible x-value, first identify which boundaries limit the overlap. Solve their intersection exactly, check whether strict or inclusive symbols affect the endpoint, and then test any required integer or contextual restriction. This is usually faster than testing many random points.

11 · QUICK CHECK

Reason about the common region.

2Does (2,4) satisfy y≥x+1 and y≤−x+7?
3If both inequalities are strict, is their boundary intersection included?
4x≥0, y≥0, 2x+y≤6: what is the greatest possible x?
5y>x+4, y<x+1: overlap or no overlap?
Show quick-check answers

1) (3,3), because x=−x+6 gives x=3. 2) Yes: 4≥3 and 4≤5. 3) No. 4) x=3, reached at (3,0). 5) No overlap.

12 · LESSON RECAP

Overlap is the set that survives every constraint.

  1. Graph or identify every boundary.
  2. Choose the valid half-plane for each inequality.
  3. Find important intersections exactly.
  4. Keep only the common region.
  5. Respect strict versus inclusive boundaries.
  6. Substitute key points to verify the result.
