Solving by Factoring

Solutions correspond exactly to Practice Questions 1–18.

SKILL CHECK

1. x²−5x+6=(x−2)(x−3)=0, so x=2 or x=3.
2. x²+7x+10=(x+5)(x+2)=0, so x=−5 or x=−2.
3. 3x²−12x=3x(x−4)=0, so x=0 or x=4.

CORE PRACTICE

4. x²−x−12=(x−4)(x+3)=0, so x=−3 or x=4.
5. 2x²+7x+3=(2x+1)(x+3)=0, so x=−3 or x=−1/2.
6. 3x²−11x−4=(3x+1)(x−4)=0, so x=−1/3 or x=4.
7. x²−16x+63=(x−7)(x−9)=0, so x=7 or x=9.
8. 5x²−45x=5x(x−9)=0, so x=0 or x=9.
9. 4x²−36=4(x−3)(x+3)=0, so x=−3 or x=3.
10. 6x²−13x+6=(3x−2)(2x−3)=0, so x=2/3 or x=3/2.
11. 2x²−18x+40=2(x−4)(x−5)=0, so x=4 or x=5.

EXAM-STYLE PRACTICE

12. x²+2x−15=(x+5)(x−3)=0, so the solution set is {−5,3}.
13. (x+2)(x+5)=54 ⇒ x²+7x−44=0=(x+11)(x−4). Since x>0, x=4.
14. n(n+5)=36 ⇒ n²+5n−36=(n+9)(n−4)=0. The positive integer is n=4.
15. (x−6)(2x+5)=0 gives x=6 or x=−5/2, so {6,−5/2}.
16. (x+3)²=49 ⇒ x+3=±7, so x=4 or −10. With x nonnegative, x=4.

CHALLENGE PROBLEMS

17. Let u=x². u²−13u+36=(u−4)(u−9)=0, so x²=4 or 9 and x=±2, ±3.
18. Let u=x². 6u²−13u+6=(3u−2)(2u−3)=0, so x²=2/3 or 3/2 and x=±√(2/3), ±√(3/2).
