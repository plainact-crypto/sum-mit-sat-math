Linear Function Word Problems
Algebra
01 · LESSON OBJECTIVE

Turn a real situation into a linear model.

By the end of this lesson, you should be able to identify the starting value and constant rate in a word problem, write a linear equation, use it to answer a question, and interpret the result with correct units.

starting value + constant rate→linear model
02 · WHAT YOU NEED TO KNOW

Linear situations have a constant rate of change.

A quantity is modeled linearly when it changes by the same amount for each equal change in the input. In the form y = mx + b, m is the rate of change and b is the value when x = 0.

InputxThe independent quantity, often time or number of items.
OutputyThe quantity that depends on x.
RatemHow much y changes for each 1-unit increase in x.
Initial valuebThe output when x = 0.
03 · KEY DEFINITIONS

Linear Model

An equation representing a relationship with a constant rate of change.

y = mx + b

Rate of Change

The change in output divided by the corresponding change in input.

m = Δy/Δx

Initial Value

The output at input zero; in slope-intercept form it is the constant term.

b = y when x = 0
04 · CORE RULE / FORMULA

Translate the words into slope-intercept form.

output = (rate)(input) + initial value

Match the units before writing the equation. If the rate is dollars per ticket, for example, the input should count tickets and the output should be dollars.

05 · HOW IT WORKS

Use a five-step process.

01
Define the variablesDecide what the input and output represent.
02
Find the constant rateLook for “per,” “each,” a repeated change, or two data points.
03
Find the initial valueIdentify the amount present when the input is zero, or solve for it from a known point.
04
Write the modelSubstitute the rate and initial value into y = mx + b.
05
Answer what was askedSubstitute the requested input or solve for the requested variable, then include units.
06 · WORKED EXAMPLE 1 — DIRECT RATE AND STARTING VALUE

A bike rental costs a $12 setup fee plus $7 per hour. Write a model for the total cost C after h hours, then find the cost for 4 hours.

rate = 7 dollars per hour → m = 7initial fee = 12 dollars → b = 12C = 7h + 12C(4) = 7(4) + 12 = 40

The 4-hour rental costs $40.

07 · WORKED EXAMPLE 2 — DECREASING QUANTITY

A container begins with 90 liters of water and drains at 6 liters per minute. Write a model for the amount A after t minutes and find A after 8 minutes.

rate = −6 liters per minuteinitial amount = 90 litersA = −6t + 90A(8) = −6(8) + 90 = 42

After 8 minutes, 42 liters remain.

08 · WORKED EXAMPLE 3 — FIND THE MODEL FROM TWO OBSERVATIONS

A plant is 26 cm tall on day 3 and 38 cm tall on day 7. Its height changes linearly. Find the model H = md + b.

m = (38 − 26)/(7 − 3) = 12/4 = 3 cm per day26 = 3(3) + b26 = 9 + b → b = 17H = 3d + 17
CheckAt d = 7, H = 3(7) + 17 = 38 cm.
09 · WORKED EXAMPLE 4 — SOLVE FOR THE INPUT

A savings account model is S = 25w + 140, where w is the number of weeks and S is the balance in dollars. After how many weeks will the balance be $365?

365 = 25w + 140225 = 25ww = 9

The balance reaches $365 after 9 weeks.

10 · WORKED EXAMPLE 5 — INTERPRET THE COEFFICIENTS

The temperature of a cooling sample is modeled by T = 72 − 4.5t, where t is measured in minutes and T in degrees Celsius. Interpret 72 and −4.5.

T(0) = 72 → initial temperature = 72°Cm = −4.5 → temperature decreases 4.5°C per minute

The sign of the rate matters: a negative rate indicates a decrease.

11 · WORKED EXAMPLE 6 — EXAM STYLE

A delivery service charges a fixed fee and a constant amount per kilometer. A 6-km trip costs $23 and a 14-km trip costs $39. What is the fixed fee?

m = (39 − 23)/(14 − 6) = 16/8 = 2 dollars per kilometerC = 2d + b23 = 2(6) + b23 = 12 + b → b = 11
Exam connectionThe fixed fee is the output at zero distance, so it is the y-intercept: $11.
VISUAL GRAPH

See a starting fee and constant rate on one model.

Suppose a service charges a $5 starting fee plus $2.50 per kilometer. The model is y = 2.5x + 5: the y-intercept is the starting fee and the slope is the cost per kilometer.

Math cross-checkSubstitution verifies three points: x = 0 gives y = 5, x = 2 gives y = 10, and x = 4 gives y = 15. From (0,5) to (2,10), the slope is (10−5)/(2−0) = 5/2 = 2.5, and the y-intercept is 5.
DESMOS STRATEGY

Use a graphing tool to check a model after translating the words.

Enter

y = 2.5x + 5

Look for

A y-intercept of 5 and a line that increases by $2.50 for every 1-unit increase in x; for example, it passes through (2,10).

Use it to answer

Check that the intercept matches the starting fee and that the slope matches the constant cost per unit before using the model for predictions.

Why it works

In y = mx + b, b is the output when x = 0 and m is the constant rate of change, exactly matching the two quantities identified in a linear word problem.

Faster or not?

Build the model from the words first; that is usually faster and is the main skill. Desmos is useful afterward for checking the model and interpreting its graph.

Math cross-check: At x = 2, y = 2.5(2) + 5 = 10. At x = 4, y = 2.5(4) + 5 = 15, so the graph has the claimed intercept and constant rate.

12 · COMMON MISTAKES
Swapping the rate and initial value

The rate multiplies the input. The initial value is added as the constant term.

Ignoring the sign of the rate

Words such as decreases, drains, or loses usually indicate a negative rate.

Using mismatched units

Make sure the rate units match the chosen input and output variables.

Answering the wrong quantity

A problem may give an equation but ask for the input, the output, the rate, or the initial value. Identify the request before calculating.

13 · EXAM STRATEGY

Label the meaning and units before doing algebra.

Write a short note for the input, output, rate, and starting value. This prevents coefficient swaps and makes it easier to decide whether to substitute an input or solve an equation for the input.

identify quantities→model → solve → interpret

15 · LESSON RECAP

A word problem becomes manageable when each number has a role.

  1. Define the input and output.
  2. Identify or calculate the constant rate of change.
  3. Identify or calculate the initial value.
  4. Write the model in the form y = mx + b.
  5. Solve for the requested quantity and report meaningful units.
y = mx + bm = Δy/Δxb = y − mx
