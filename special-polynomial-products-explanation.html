01 · LESSON OBJECTIVE

Recognize special products and expand them without multiplying every term from scratch.

By the end of this lesson, you should be able to identify perfect-square binomials and conjugates, apply the matching identity, and check the middle term and signs before finalizing an expansion.

(x + 5)²→x² + 10x + 25
02 · CORE PATTERNS

Three identities cover the most common special products.

(a + b)² = a² + 2ab + b²(a − b)² = a² − 2ab + b²(a + b)(a − b) = a² − b²

The first two patterns are perfect-square trinomials. The third is a difference of squares. In a squared binomial, the middle term is twice the product of the two original terms.

03 · WORKED EXAMPLE — SUM SQUARED

Expand: (x + 5)²

a = x, b = 5a² + 2ab + b²x² + 2(x)(5) + 5²x² + 10x + 25
Multiplication cross-check(x + 5)(x + 5) = x² + 5x + 5x + 25 = x² + 10x + 25.
04 · WORKED EXAMPLE — DIFFERENCE SQUARED

Expand: (3y − 2)²

a = 3y, b = 2a² − 2ab + b²(3y)² − 2(3y)(2) + 2²9y² − 12y + 4

Only the middle term is negative. The last term is positive because b² is always nonnegative for real b.

05 · WORKED EXAMPLE — CONJUGATES

Expand: (2m + 7)(2m − 7)

a = 2m, b = 7(a + b)(a − b) = a² − b²(2m)² − 7²4m² − 49
Why the middle terms vanish−14m + 14m = 0, so only the two squares remain.
06 · EXAM-STYLE EXAMPLE

Simplify: (x + 4)² − (x − 4)²

(x + 4)² = x² + 8x + 16(x − 4)² = x² − 8x + 16(x² + 8x + 16) − (x² − 8x + 16)16x

Writing the subtraction with parentheses prevents the sign on −8x from being lost.

07 · HOW TO CHOOSE THE PATTERN
01
Same binomial multiplied by itself(a + b)(a + b) → (a + b)²
02
Same terms, both minus signs inside(a − b)(a − b) → (a − b)²
03
Same terms with opposite middle signs(a + b)(a − b) → a² − b²
08 · COMMON MISTAKES
Forgetting the middle term

(a + b)² is not a² + b². The full expansion includes 2ab.

Making the last term negative

In (a − b)², the final term is +b², not −b².

Using difference of squares on a square

(a − b)² and (a + b)(a − b) are different structures and produce different results.

Squaring only the coefficient

(3x)² = 9x², because both 3 and x are squared.

09 · EXAM STRATEGY

Pattern first, arithmetic second.

Before distributing, inspect the two factors. If they match one of the three identities, using the pattern is usually faster and reduces sign errors. If you are unsure, ordinary multiplication is a reliable cross-check.

11 · RECAP
  1. For (a + b)², use a² + 2ab + b².
  2. For (a − b)², use a² − 2ab + b².
  3. For conjugates, use (a + b)(a − b) = a² − b².
  4. Square every part of each term, including coefficients and variables.
  5. Use ordinary multiplication when you want an independent check.
