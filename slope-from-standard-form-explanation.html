Slope from Standard Form
Algebra
01 · LESSON OBJECTIVE

Find the slope of a line written in standard form.

By the end of this lesson, you should be able to find the slope from an equation written as Ax + By = C by either using the shortcut m = −A/B or rewriting the equation in slope-intercept form.

2x + 3y = 12→slope = −2/3
02 · WHAT YOU NEED TO KNOW

Standard form hides the slope, but the coefficients reveal it.

A linear equation in standard form is written as Ax + By = C. When B is not zero, solving for y gives y = (−A/B)x + C/B, so the slope is −A/B.

Standard formAx + By = CA, B, and C are constants.
Slopem = −A/BValid when B ≠ 0.
Horizontal lineA = 0Slope = 0.
Vertical lineB = 0Slope is undefined.
03 · KEY DEFINITIONS

Standard Form

A common form for a linear equation.

Ax + By = C

Slope

The rate of change of y with respect to x.

m = Δy / Δx

Undefined Slope

The slope of a vertical line, where the horizontal change is zero.

x = constant
04 · CORE RULE / FORMULA

For Ax + By = C, the slope is −A/B.

Ax + By = C → m = −A/B
05 · HOW IT WORKS

Use either the coefficient shortcut or solve for y.

01
Identify A and BUse the coefficients of x and y, including their signs.
02
Apply m = −A/BPlace a negative sign in front of A/B and simplify.
03
Check special casesIf A = 0, the slope is 0. If B = 0, the line is vertical and the slope is undefined.
04

06 · WORKED EXAMPLE 1 — BASIC

Find the slope of 2x + 3y = 12.

  1. Identify the coefficients.A = 2 and B = 3.
  2. Use the standard-form slope rule.m = −A/B = −2/3
  3. State the slope.slope = −2/3
Check by solving for y3y = −2x + 12 → y = −(2/3)x + 4 ✓
07 · WORKED EXAMPLE 2 — NEGATIVE A

Find the slope of −4x + 2y = 10.

A = −4, B = 2m = −(−4)/2m = 2

Sign check: A negative x-coefficient can produce a positive slope because the formula already includes a negative sign.

08 · WORKED EXAMPLE 3 — Y COEFFICIENT IS NEGATIVE

Find the slope of 5x − y = 7.

A = 5, B = −1m = −5/(−1)m = 5
Check−y = −5x + 7 → y = 5x − 7 ✓
09 · WORKED EXAMPLE 4 — SIMPLIFY THE FRACTION

Find the slope of 3x + 6y = −18.

m = −3/6m = −1/2

Always simplify the slope fraction when possible.

10 · WORKED EXAMPLE 5 — SAT STYLE

A linear relationship between x and y is modeled by 12x + 4y = 80. What is the slope, and what does its sign tell you?

m = −12/4m = −3
SAT connection

The slope is −3, so for each increase of 1 in x, y decreases by 3 units. In context, a negative slope signals an inverse linear relationship between the variables.

11 · WORKED EXAMPLE 6 — SPECIAL CASES

Compare 2y = 14 and 7x = 21.

2y = 14 → y = 7 → slope = 07x = 21 → x = 3 → vertical line → slope undefined

Remember: Horizontal lines have slope 0. Vertical lines have undefined slope.

12 · COMMON MISTAKES
Using A/B instead of −A/B

The negative sign is part of the rule. For 2x + 5y = 10, the slope is −2/5.

Ignoring the sign of B

In 3x − 2y = 8, B = −2, so the slope is 3/2.

Using C in the slope

The constant C affects the intercept, not the slope.

Calling a vertical slope zero

A vertical line has undefined slope, not zero.

13 · SAT STRATEGY

Use −A/B when the equation is already in standard form.

This is usually faster than solving for y. If signs look tricky, rewrite the equation as y = mx + b to verify your answer. For a vertical line, stop: the slope is undefined.

6x − 3y = 9→m = 2

15 · LESSON RECAP

Standard-form coefficients give the slope directly.

  1. Standard form is Ax + By = C.
  2. When B ≠ 0, slope = −A/B.
  3. Keep the signs of A and B exactly as written.
  4. Simplify fractional slopes.
  5. Horizontal lines have slope 0; vertical lines have undefined slope.
