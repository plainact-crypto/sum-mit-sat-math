01 · SKILL CHECK

1. Solve by setting the equations equal

Answer: B) (3, 5)
Set x + 2 = −x + 8. Then 2x = 6, so x = 3 and y = 5. Both equations give 5.

2. Identify a system with one solution

Answer: C) y = x + 2 and y = −2x + 5
The slopes are 1 and −2. Different slopes mean the two lines intersect exactly once.

3. Solve by elimination

Answer: C) (6, 3)
Add x + y = 9 and x − y = 3 to get 2x = 12, so x = 6. Then y = 3.
02 · CORE PRACTICE

4. Intersection of two slope-intercept equations

Answer: B) (2, 5)
Set 2x + 1 = −x + 7. Then 3x = 6, so x = 2 and y = 5.

5. Solve a standard-form system

Answer: B) (4, 3)
From x − y = 1, y = x − 1. Substitute into 2x + y = 11: 3x − 1 = 11, so x = 4 and y = 3.

6. Eliminate y

Answer: C) (4, 2)
Subtract x + 2y = 8 from 3x + 2y = 16. Then 2x = 8, so x = 4. Substitution gives y = 2.

7. Find the line intersection

Answer: B) (4, 7)
Set 4x − 9 = x + 3. Then 3x = 12, so x = 4 and y = 7.

8. Solve by substitution

Answer: C) (4, 3)
From 2x − y = 5, y = 2x − 5. Then x + 3(2x − 5) = 13, so 7x = 28 and x = 4; y = 3.

9. Find x

Answer: B) 3
Add 5x − y = 13 and 2x + y = 8. This gives 7x = 21, so x = 3.

10. Condition for one solution

Answer: B) They have different slopes.
Two nonvertical lines with different slopes cannot be parallel or identical, so they intersect at exactly one point.

11. Solve a decimal-coefficient system

Answer: C) (6, 3)
Add 0.5x + y = 6 and x − y = 3. Then 1.5x = 9, so x = 6 and y = 3.
03 · EXAM-STYLE PRACTICE

12. Equal notebook costs

Answer: C) 5 notebooks
Set 4n + 6 = 2n + 16. Then 2n = 10, so n = 5 notebooks. Both totals are $26.

13. Equal savings balances

Answer: C) 4
Set 15w + 40 = 25w. Then 40 = 10w, so w = 4. Each balance is 100.

14. Coefficient ratios and uniqueness

Answer: B) k = 4
The y-coefficients have ratio 6/3 = 2. Matching the x-coefficient ratio requires k/2 = 2, so k = 4. Then the left side of the second equation is twice the first, while 30 is not twice 18; the lines are parallel and there is no unique solution.

15. X-coordinate of an intersection

Answer: B) 5/3
The line through (0,7) and (4,15) has slope (15−7)/4 = 2, so y = 2x + 7. Set 2x + 7 = −x + 12: 3x = 5, so x = 5/3.

16. Interpret a unique solution

Answer: B) Both plans cost the same when 4 tickets are purchased.
A solution to the two cost equations is the input where their outputs are equal. At n = 4, each plan costs $66.
04 · CHALLENGE PROBLEMS

17. Determine the parameter

Answer: D) 8
At x = 2, the second equation gives y = 5(2) + 6 = 16. Put x = 2 and y = 16 into the first equation: 16 = 2(a + 1) − 2 = 2a. Therefore a = 8. The resulting slopes 9 and 5 are different, so the solution is unique.

18. Solve a fractional system

Answer: A) (45/8, 13/4)
From (2/3)x + y = 7, y = 7 − (2/3)x. Substitute into x − (1/2)y = 4: x − 7/2 + x/3 = 4, so (4/3)x = 15/2 and x = 45/8. Then y = 7 − (2/3)(45/8) = 7 − 15/4 = 13/4. Substitution in the second equation gives 45/8 − 13/8 = 4.
