No Real Solutions
Advanced Math
01 · LESSON OBJECTIVE

Recognize when a quadratic has no real solutions.

A quadratic has no real solutions when the quadratic formula would require the square root of a negative number.

02 · CORE RULE

No real solutions mean the discriminant is negative.

D=b²−4acD<0 ⇔ no real solutions

When D<0, √D is not a real number, so the equation has no real x-values that make the quadratic equal zero.

03 · WORKED EXAMPLE 1

Determine the number of real solutions of x²+4x+8=0.

D=4²−4(1)(8)=16−32=−16D<0No real solutions
Math cross-checkComplete the square: x²+4x+8=(x+2)²+4. Since (x+2)²≥0, the expression is always at least 4, so it can never equal 0 for real x.
04 · WORKED EXAMPLE 2

Find c so x²−6x+c=0 has no real solutions.

D=(−6)²−4(1)(c)=36−4c36−4c<0c>9

The inequality is strict. At c=9, the discriminant is zero and the quadratic has one repeated real solution.

05 · WORKED EXAMPLE 3

For what k does 2x²+kx+5=0 have no real solutions?

D=k²−4(2)(5)=k²−40k²−40<0k²<40−2√10<k<2√10
Boundary checkAt k=±2√10, D=0, so those boundary values give one real solution and must be excluded.

06 · COMMON MISTAKES
Using D≤0

D≤0 includes the repeated-root case. No real solutions require D<0.

Mishandling k²<A

For positive A, k²<A means −√A<k<√A, an interval between two bounds.

Forgetting standard form

First write the equation as ax²+bx+c=0 before identifying a, b, and c.

07 · EXAM STRATEGY

Translate “no real solutions” into D<0 immediately.

Identify a, b, and c, form b²−4ac<0, and solve the resulting inequality carefully. Check excluded boundary values when the question asks for a parameter range.

09 · LESSON RECAP
  1. Write the quadratic in standard form.
  2. No real solutions mean D<0.
  3. Solve the resulting inequality exactly.
  4. Exclude equality because D=0 gives one real solution.
  5. A graph with no x-intercepts provides a useful visual check.
