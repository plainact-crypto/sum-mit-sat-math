Collinear Points

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Point on the line through (1, 2) and (3, 6)

Answer: A) (5, 10)
The slope through the given points is (6 − 2)/(3 − 1) = 4/2 = 2. Starting at (3, 6), increasing x by 2 increases y by 4, giving (5, 10).

2. Points (−2, 1), (0, 5), and (3, 11)

Answer: A) Yes, all three are collinear.
From (−2, 1) to (0, 5), the slope is 4/2 = 2. From (0, 5) to (3, 11), the slope is 6/3 = 2. Equal slopes show the three points lie on one line.

3. Line through (0, −3) and (4, 5)

Answer: A) (7, 11)
The slope is (5 − (−3))/(4 − 0) = 8/4 = 2, so the line is y = 2x − 3. At x = 7, y = 14 − 3 = 11.
02 · CORE PRACTICE

4. Which set is collinear?

Answer: A) (1, 4), (3, 8), (6, 14)
The first slope is (8 − 4)/(3 − 1) = 2. The second is (14 − 8)/(6 − 3) = 2, so all three points are collinear.

5. (2, 5), (5, 11), and (8, k)

Answer: C) 17
The slope from the first point to the second is (11 − 5)/(5 − 2) = 2. Moving from x = 5 to x = 8 adds 3 to x, so y must increase by 2(3) = 6. Thus k = 11 + 6 = 17.

6. A(−4, 7), B(2, −5), C(5, −11)

Answer: A) Yes, because both relevant slopes are −2.
Slope AB = (−5 − 7)/(2 − (−4)) = −12/6 = −2. Slope BC = (−11 − (−5))/(5 − 2) = −6/3 = −2.

7. Point on y = −3x + 4

Answer: A) (−2, 10)
Substitute x = −2: y = −3(−2) + 4 = 6 + 4 = 10, so (−2, 10) lies on the line.

8. (1, 3), (4, 9), and (x, 13)

Answer: B) 6
The slope through (1, 3) and (4, 9) is 6/3 = 2. The line is y = 2x + 1. Set 13 = 2x + 1, giving x = 6.

9. (−1, −5), (3, 7), and (7, y)

Answer: C) 19
The slope is (7 − (−5))/(3 − (−1)) = 12/4 = 3. From x = 3 to x = 7 is a change of 4, so y increases by 3(4) = 12. Therefore y = 7 + 12 = 19.

10. Point NOT collinear with (2, 1) and (6, 9)

Answer: D) (8, 12)
The slope is (9 − 1)/(6 − 2) = 2, so the line is y = 2x − 3. At x = 8 the line requires y = 13, not 12.

11. A, B(2, 5), and C(8, 13)

Answer: A) (−1, 1)
Slope BC = (13 − 5)/(8 − 2) = 8/6 = 4/3. From B to (−1, 1), the changes are Δx = −3 and Δy = −4, so the slope is (−4)/(−3) = 4/3.
03 · EXAM-STYLE PRACTICE

12. Straight path through (0, 2), (3, 8), and (6, 14)

Answer: C) 22
The constant slope is 2, and the line is y = 2x + 2. At x = 10, y = 20 + 2 = 22.

13. Survey line through A(−4, −1) and B(2, 8)

Answer: A) (6, 14)
The slope is (8 − (−1))/(2 − (−4)) = 9/6 = 3/2. The line is y = (3/2)x + 5. At x = 6, y = 9 + 5 = 14.

14. Equation verifying (−2, 7), (1, 1), and (5, −7)

Answer: A) y = −2x + 3
For x = −2, 1, and 5, the rule y = −2x + 3 gives y = 7, 1, and −7 respectively. All three points satisfy the same linear equation.

15. (k, −4), (2, 2), and (5, 8)

Answer: B) −1
The slope from (2, 2) to (5, 8) is 6/3 = 2, so the line is y = 2x − 2. Set −4 = 2k − 2. Then 2k = −2 and k = −1.

16. Table points (−3, 11), (0, 5), and (4, −3)

Answer: A) y = −2x + 5
From (−3, 11) to (0, 5), the slope is −6/3 = −2. Since (0, 5) is the y-intercept, the rule is y = −2x + 5; substituting x = 4 gives y = −3.
04 · CHALLENGE PROBLEMS

17. (a, 2), (4, 8), and (10, 20)

Answer: B) 1
The slope from (4, 8) to (10, 20) is 12/6 = 2, giving the line y = 2x. Since (a, 2) lies on it, 2 = 2a, so a = 1.

18. P(−2, 7), Q(4, −5), and R(r, −15)

Answer: C) 9
Slope PQ = (−5 − 7)/(4 − (−2)) = −12/6 = −2. The line through Q is y + 5 = −2(x − 4), or y = −2x + 3. Set −15 = −2r + 3, so r = 9.
