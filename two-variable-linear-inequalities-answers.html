ANSWERS & SOLUTIONS

Two-Variable Linear Inequalities

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Which ordered pair satisfies y > 2x − 1?

Answer: C) (2, 4)
Substitute each point. For (2,4), 4>2(2)−1=3, so it satisfies the inequality. The other choices do not.

2. Boundary for y < −x + 3

Answer: B) Dashed
A strict inequality (< or >) does not include the boundary line, so the boundary is dashed.

3. Which inequality includes its boundary?

Answer: C) y ≥ −2x + 5
The symbol ≥ includes equality, so points on y=−2x+5 are part of the solution set.
02 · CORE PRACTICE

4. Does (2,1) satisfy y ≤ x + 1?

Answer: A) Yes
1≤2+1=3, so the point satisfies the inequality.

5. Which point does NOT satisfy y ≥ −x?

Answer: D) (1, −2)
For x=1 the condition is y≥−1, but −2≥−1 is false. The other three points satisfy the inequality.

6. Rewrite 2x + y > 6.

Answer: A) y > −2x + 6
Subtract 2x from both sides: y>6−2x=−2x+6.

7. Rewrite 3x − 2y ≤ 8.

Answer: B) y ≥ (3/2)x − 4
−2y≤8−3x. Divide by −2 and reverse the inequality: y≥(3/2)x−4.

8. y-intercept of the boundary y = 3x − 2

Answer: B) (0, −2)
Set x=0: y=−2, so the y-axis crossing is (0,−2).

9. Which point lies on y = −2x + 4?

Answer: B) (1, 2)
Substitute x=1: y=−2(1)+4=2, so (1,2) lies on the boundary.

10. Which side should be shaded for y > x + 2 if (0,0) is not a solution?

Answer: B) The side not containing (0,0)
A test point tells which half-plane works. Since (0,0) fails, shade the opposite side of the boundary.

11. Which inequality has a horizontal boundary?

Answer: A) y < 5
Its boundary is y=5, a horizontal line.
03 · EXAM-STYLE PRACTICE

12. Club budget

Answer: A) 4x + 6y ≤ 120
Each notebook costs $4 and each folder $6. “At most $120” means the total cost cannot exceed 120.

13. Van load requirement

Answer: B) 20x + 50y ≥ 500
The total mass is 20x+50y kilograms. “At least 500 kg” means ≥500.

14. Practice-minute requirement

Answer: C) x + y > 180
Total minutes are x+y, and “more than 180” is a strict greater-than condition.

15. Ticket-revenue requirement

Answer: A) 8s + 12a ≥ 240
Revenue is 8s+12a dollars. “At least $240” means the total must be 240 or greater.

16. Workshop capacity

Answer: D) (17, 14)
17+14=31, which violates x+y≤30. The other choices total 30, 29, and 29.
04 · CHALLENGE PROBLEMS

17. Which point satisfies both y > −2x + 1 and 2x + y < 7?

Answer: B) (1, 2)
For (1,2): 2>−2(1)+1=−1 and 2(1)+2=4<7, so both inequalities are true. The other choices fail at least one condition.

18. Graph 2x − 3y ≥ 12.

Answer: B) Solid boundary y = (2/3)x − 4; shade below
−3y≥12−2x. Divide by −3 and reverse the sign: y≤(2/3)x−4. Equality is included, so the boundary is solid, and y≤ means shade below.
