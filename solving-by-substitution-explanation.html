Solving by Substitution
Algebra
01 · LESSON OBJECTIVE

Replace one variable with an equivalent expression.

Use substitution to turn a two-variable system into a one-variable equation, solve it, and then find the second coordinate.

y = x + 1 and x + y = 7→(3, 4)
02 · WHAT YOU NEED TO KNOW

Equal expressions can replace each other.

If one equation says y = x + 1, then every y in the other equation can be replaced by x + 1. The system then becomes a single equation in x.

Best starting pointisolated variableLook for x = ... or y = ...

03 · KEY DEFINITIONS

Substitution

Replacing a variable with an expression known to be equal to it.

System Solution

An ordered pair that makes every equation in the system true.

Back-Substitution

Using the solved value in an original equation to find the remaining variable.

04 · CORE RULE

Substitute, solve, back-substitute, verify.

REPLACE → SOLVE → RETURN → CHECK
05 · HOW IT WORKS

Use a four-step routine.

01
Isolate a variable if needed.Choose the equation that makes this easiest.
02
Substitute into the other equation.This removes one variable.
03
Solve the one-variable equation.Keep exact values whenever possible.
04
Back-substitute and check.The final ordered pair must satisfy both originals.
06 · WORKED EXAMPLE 1 — DIRECT SUBSTITUTION

Solve y = x + 1 and x + y = 7.

x + (x + 1) = 72x + 1 = 72x = 6 → x = 3y = 3 + 1 = 4
Check4 = 3 + 1 and 3 + 4 = 7, so (3, 4) satisfies both equations.
07 · WORKED EXAMPLE 2 — ISOLATE FIRST

Solve 2x + y = 9 and x − y = 3.

x − y = 3 → y = x − 32x + (x − 3) = 93x = 12 → x = 4y = 4 − 3 = 1
Check2(4)+1=9 and 4−1=3.
08 · WORKED EXAMPLE 3 — NEGATIVE EXPRESSION

Solve x = 5 − 2y and 3x + y = 8.

3(5 − 2y) + y = 815 − 6y + y = 8−5y = −7 → y = 7/5x = 5 − 14/5 = 11/5
Exact solution(11/5, 7/5)
09 · WORKED EXAMPLE 4 — WORD MODEL

Two numbers have a sum of 19. The second number is 5 more than the first. Find both numbers.

x + y = 19y = x + 5x + (x + 5) = 192x = 14 → x = 7, y = 12

The substitution step uses the relationship already given in the words.

10 · WORKED EXAMPLE 5 — EXAM-STYLE

A system is y = 3x − 2 and 2x + y = 18. What is x + y?

2x + (3x − 2) = 185x = 20 → x = 4y = 3(4) − 2 = 10x + y = 14
Answer the requested quantity14
11 · WHY THE GRAPH MATCHES

The algebraic solution is the intersection.

For y = x + 1 and x + y = 7, the second equation is y = −x + 7. Setting the two y-expressions equal gives x + 1 = −x + 7, so x = 3 and y = 4. The graph must therefore intersect at (3, 4).

12 · COMMON MISTAKES
Substituting into the same equation

Use the isolated expression in the other equation so one variable disappears.

Dropping parentheses

For 3x + y with x = 5 − 2y, write 3(5 − 2y) + y.

Stopping after one variable

A system solution needs both coordinates unless the question asks for something else.

Checking only one equation

Verify the ordered pair in both original equations.

13 · EXAM STRATEGY

Choose substitution when isolation is cheap.

If one variable is already isolated or has coefficient 1 or −1, substitution is often efficient. If both equations would require awkward fractions, elimination may be faster.

15 · LESSON RECAP

Turn two variables into one.

  1. Isolate a variable when needed.
  2. Replace that variable in the other equation.
  3. Solve the resulting one-variable equation.
  4. Back-substitute to find the second coordinate.
  5. Check the ordered pair in both original equations.
