Linear Function Word Problems

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Setup fee plus per-item cost

Answer: B) C = 4n + 6
The $6 setup fee is the initial value and $4 per item is the rate, so C = 4n + 6.

2. Tank amount after 7 hours

Answer: A) 40 liters
Start with 75 liters and subtract 5 liters for each of 7 hours: 75 − 5(7) = 75 − 35 = 40 liters.

3. Interpret 18 in y = 2.5x + 18

Answer: C) The initial value when x = 0
In y = mx + b, b is the output when x = 0. Here b = 18.
02 · CORE PRACTICE

4. Taxi fixed starting fee

Answer: B) $7
The rate is (37 − 19)/(10 − 4) = 18/6 = $3 per km. Using 19 = 3(4) + b gives b = 7.

5. Workshops attended

Answer: C) 7
91 = 28 + 9w, so 63 = 9w and w = 7 workshops.

6. Cooling time

Answer: C) 10 minutes
Set T = 34: 34 = 64 − 3t. Then 3t = 30, so t = 10 minutes.

7. Plant height on day 9

Answer: C) 42 cm
The rate is (30 − 14)/(6 − 2) = 16/4 = 4 cm per day. From day 6 to day 9 is 3 days, so the height is 30 + 4(3) = 42 cm.

8. Savings reaches $330

Answer: B) 6 weeks
330 = 35w + 120, so 210 = 35w and w = 6.

9. Gallons remaining after 11 minutes

Answer: B) 62
The amount is 150 − 8(11) = 150 − 88 = 62 gallons.

10. Messaging-plan total

Answer: C) $35
The total is 15 + 0.08(250) = 15 + 20 = $35.

11. Reservoir model

Answer: B) A = 220 − 12d
The initial amount is 220 cubic meters and it decreases by 12 cubic meters per day, giving A = 220 − 12d.
03 · EXAM-STYLE PRACTICE

12. Ride-service cost for 8 miles

Answer: C) $25.25
The rate is (32.00 − 18.50)/(11 − 5) = 13.50/6 = $2.25 per mile. Eight miles is 3 miles beyond 5, so the cost is 18.50 + 2.25(3) = $25.25.

13. Time until 40 liters remain

Answer: C) 9 minutes
The rate is (72 − 96)/(5 − 2) = −24/3 = −8 liters per minute. Using 96 at t = 2 gives A = 112 − 8t. Set 40 = 112 − 8t, so 8t = 72 and t = 9 minutes.

14. Break-even ticket count

Answer: B) 25
Set P = 0: 0 = 6n − 150. Then 6n = 150, so n = 25 tickets.

15. Rental cost for 10 hours

Answer: C) $97
The hourly rate is (73 − 41)/(7 − 3) = 32/4 = $8. From 7 to 10 hours adds 3 hours, so the cost is 73 + 8(3) = $97.

16. Equal plan costs

Answer: C) 12
Set the costs equal: 12 + 3x = 30 + 1.5x. Then 1.5x = 18, so x = 12.
04 · CHALLENGE PROBLEMS

17. Input that gives output 76

Answer: C) 13
The slope is (51 − 26)/(8 − 3) = 25/5 = 5. Using (3, 26), y = 5x + 11. Set 76 = 5x + 11, so 65 = 5x and x = 13. Check: 5(13) + 11 = 76.

18. Time until 20 liters remain

Answer: C) 15 minutes
The rate is (50 − 86)/(10 − 4) = −36/6 = −6 liters per minute. Using 86 at t = 4 gives A = 110 − 6t. Set 20 = 110 − 6t, so 6t = 90 and t = 15 minutes. Check: 110 − 6(15) = 20.
