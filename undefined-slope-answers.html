Undefined Slope

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. A line passes through (4, −3) and (4, 8). What is its slope?

Answer: C) Undefined
m = (8 − (−3))/(4 − 4) = 11/0. Division by zero is undefined, so the slope is undefined.

2. What is the slope of the line x = −6?

Answer: D) Undefined
The equation x = −6 represents a vertical line. Every vertical line has undefined slope.

3. Which pair of points lies on a line with undefined slope?

Answer: B) (−3,4) and (−3,9)
The points have the same x-coordinate and different y-coordinates. Their slope is (9 − 4)/(−3 − (−3)) = 5/0, which is undefined.
02 · CORE PRACTICE

4. Find the slope through (7, 5) and (7, −4).

Answer: D) Undefined
m = (−4 − 5)/(7 − 7) = −9/0, so the slope is undefined.

5. For a line, Δy = 12 and Δx = 0. What is the slope?

Answer: D) Undefined
m = Δy/Δx = 12/0. Because division by zero is undefined, the slope is undefined.

6. Which equation represents the vertical line through (−2, 7)?

Answer: A) x = −2
A vertical line keeps its x-coordinate constant. Since the point has x = −2, the line is x = −2.

7. A table lists the points (5, −1), (5, 3), and (5, 10). What is the slope of the line through them?

Answer: D) Undefined
Using (5,−1) and (5,3), m = (3 − (−1))/(5 − 5) = 4/0, so the slope is undefined.

8. Which statement is true for every vertical line?

Answer: B) Its x-coordinate is constant.
A vertical line has equation x = c for some constant c, so every point on it has the same x-coordinate.

9. The points (k, 2) and (k, 11) are distinct. What is the slope of the line through them?

Answer: D) Undefined
m = (11 − 2)/(k − k) = 9/0. The denominator is zero, so the slope is undefined.

10. Which equation has undefined slope?

Answer: C) 2x = 14
2x = 14 simplifies to x = 7, which is a vertical line. Therefore its slope is undefined.

11. A line crosses the x-axis at x = 9 and is vertical. Which equation represents the line?

Answer: B) x = 9
A vertical line through the x-axis point (9,0) keeps x fixed at 9, so its equation is x = 9.
03 · EXAM-STYLE PRACTICE

12. A map boundary is modeled by a vertical line through points (15, 4) and (15, 19). What is the equation of the boundary?

Answer: B) x = 15
Both points have x = 15. A vertical line through them therefore has equation x = 15.

13. The line through (p, −6) and (p, 10) has undefined slope. Which statement must be true?

Answer: A) The x-coordinates are equal.
Both points have x-coordinate p. Equal x-coordinates make Δx = 0, which produces an undefined slope.

14. Which description matches a graph with undefined slope?

Answer: B) A vertical line
Only a vertical line has zero horizontal change between distinct points, making the slope denominator zero.

15. A vertical fence is represented on a coordinate grid by x = −4. Which point must lie on the fence?

Answer: B) (−4,8)
Every point on x = −4 must have x-coordinate −4. The point (−4,8) satisfies that condition.

16. The line through (6, a) and (6, b) is defined by two distinct points. Which condition must hold?

Answer: B) a ≠ b
The points already share x = 6. To be distinct, their y-coordinates must be different, so a ≠ b.
04 · CHALLENGE PROBLEMS

17. The line through (2r − 1, 5) and (11, −3) has undefined slope. What is r?

Answer: B) 6
Undefined slope requires equal x-coordinates: 2r − 1 = 11. Then 2r = 12, so r = 6. Check: 2(6) − 1 = 11.

18. The line through (3k + 2, −7) and (20, 9) is vertical. What is k?

Answer: B) 6
A vertical line requires equal x-coordinates: 3k + 2 = 20. Then 3k = 18, so k = 6. Check: 3(6) + 2 = 20.
