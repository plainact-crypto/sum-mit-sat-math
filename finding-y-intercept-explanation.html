Finding Y-Intercept
Algebra
01 · LESSON OBJECTIVE

Find where a line crosses the y-axis.

By the end of this lesson, you should be able to find the y-intercept from standard form, slope-intercept form, a table, or a linear context.

2x + 3y = 12→ x = 0 →y = 4
02 · WHAT YOU NEED TO KNOW

The y-intercept happens when x = 0.

Every point on the y-axis has x-coordinate 0. So to find the y-intercept algebraically, substitute x = 0 into the equation and solve for y.

At the y-axisx = 0This is always true.
Intercept point(0, b)The y-coordinate is the intercept value.
Slope-intercept formy = mx + bb is the y-intercept.
Standard formAx + By = CSet x = 0, then solve By = C.
03 · KEY DEFINITIONS

Y-Intercept

The point where a graph crosses the y-axis.

(0, b)

Initial Value

In many contexts, the y-intercept represents the amount present when x = 0.

y(0) = b

Slope-Intercept Form

A linear form that displays both slope and y-intercept directly.

y = mx + b
04 · CORE RULE / FORMULA

Set x = 0 to find the y-intercept.

x = 0 → solve for y → write (0, y)
05 · HOW IT WORKS

Use the form of the equation to choose the fastest method.

01
If y = mx + bRead b directly. The y-intercept is (0, b).
02
If Ax + By = CSet x = 0 and solve for y.
03
If you have a tableLook for the row where x = 0.
04
If you have a contextInterpret the value when the input is zero.
06 · WORKED EXAMPLE 1 — STANDARD FORM

Find the y-intercept of 2x + 3y = 12.

  1. Set x = 0.2(0) + 3y = 12
  2. Solve for y.3y = 12 → y = 4
  3. Write the intercept as a point.(0, 4)
Check2(0) + 3(4) = 12 ✓
07 · WORKED EXAMPLE 2 — SLOPE-INTERCEPT FORM

Find the y-intercept of y = −3x + 7.

y = mx + bb = 7y-intercept = (0, 7)

Fast route: In slope-intercept form, the constant term is the y-intercept.

08 · WORKED EXAMPLE 3 — NEGATIVE INTERCEPT

Find the y-intercept of 5x − 2y = 8.

5(0) − 2y = 8−2y = 8y = −4y-intercept = (0, −4)

11 · COMMON MISTAKES
Setting y = 0

That finds the x-intercept, not the y-intercept.

Giving only the number

If the question asks for the intercept as a point, write (0, b).

Reading the wrong term

In y = mx + b, b is the y-intercept. m is the slope.

Forgetting context

In a word problem, explain what the intercept means using units.

12 · EXAM STRATEGY

Look at the equation form before doing any algebra.

If the equation is already y = mx + b, read b directly. If it is in another form, setting x = 0 is the safest method. For tables, locate x = 0.

y = 4x − 9→y-intercept = −9

14 · LESSON RECAP

The y-intercept is the output when x = 0.

  1. Every point on the y-axis has x = 0.
  2. Set x = 0 and solve for y.
  3. In y = mx + b, the y-intercept is b.
  4. Write the intercept as (0, b) when a point is requested.
  5. In context, the y-intercept often represents an initial value.
