Finding Y-Intercept
Algebra
01 · LESSON OBJECTIVE

Find where a line crosses the y-axis.

By the end of this lesson, you should be able to find the y-intercept from standard form, slope-intercept form, a table, or a linear context.

2x + 3y = 12→ x = 0 →y = 4
02 · WHAT YOU NEED TO KNOW

Every point on the y-axis has x = 0.

The y-intercept is the point where a graph crosses the y-axis. Because the point lies on the y-axis, its x-coordinate is always zero.

Y-intercept conditionx = 0Substitute zero for x.
Coordinate form(0, b)The y-intercept is a point.
Standard formAx + By = CSet x = 0, then solve By = C.
Slope-intercepty = mx + bThe y-intercept is already b.
03 · KEY DEFINITIONS

Y-Intercept

The point where a graph crosses the y-axis.

(0, y)

Intercept

A point where a graph crosses an axis.

Y-Axis

The vertical coordinate axis.

x = 0
04 · CORE RULE

To find the y-intercept, set x equal to zero and solve for y.

Y-INTERCEPT → SET x = 0

06 · WORKED EXAMPLE 1 — STANDARD FORM

Find the y-intercept of 3x + 2y = 18.

  1. Set x = 0.3(0) + 2y = 18
  2. Solve for y.2y = 18y = 9
  3. Write the point.(0, 9)
Check3(0) + 2(9) = 18 ✓
07 · WORKED EXAMPLE 2 — NEGATIVE INTERCEPT

Find the y-intercept of 4x − 5y = 20.

4(0) − 5y = 20−5y = 20y = −4y-intercept = (0, −4)

Remember: A negative y-intercept means the graph crosses the y-axis below the origin.

08 · WORKED EXAMPLE 3 — SLOPE-INTERCEPT FORM

Find the y-intercept of y = −3x + 7.

y = mx + bb = 7y-intercept = (0, 7)
Checky = −3(0) + 7 = 7 ✓
09 · WORKED EXAMPLE 4 — FRACTION INTERCEPT

Find the y-intercept of 6x + 4y = 9.

6(0) + 4y = 94y = 9y = 9/4y-intercept = (0, 9/4)
10 · WORKED EXAMPLE 5 — SAT STYLE

A taxi fare is modeled by y = 2.5x + 6, where x is miles traveled and y is the total cost in dollars. What does the y-intercept represent?

x = 0y = 2.5(0) + 6 = 6
SAT connection

The y-intercept represents the starting charge: $6 before any miles are traveled.

11 · SPECIAL CASES

Check what kind of line you have.

Horizontal liney = cY-intercept is (0, c).
Vertical line away from axisx = a, a ≠ 0No y-intercept.
The y-axis itselfx = 0Every point on the line lies on the y-axis.
12 · COMMON MISTAKES
Setting y = 0

That finds the x-intercept. For the y-intercept, set x = 0.

Giving only y when a point is requested

If y = 5, the y-intercept is (0, 5).

Misreading y = mx + b

The y-intercept is b, not m. The value m is the slope.

Ignoring context

In a word problem, explain what the value means when the input is zero.

13 · SAT STRATEGY

Use x = 0 unless the intercept is already visible.

In standard form, substitute x = 0 immediately. In slope-intercept form, simply read b. Do not add algebra when the equation already shows the answer.

5x + 2y = 14→ x = 0 →y = 7

15 · LESSON RECAP

One input value reveals the y-intercept.

  1. The y-intercept lies on the y-axis.
  2. Every point on the y-axis has x = 0.
  3. Set x = 0 and solve for y when needed.
  4. In y = mx + b, the y-intercept is (0, b).
  5. In a table, look for x = 0.
  6. In context, interpret the output when the input is zero.
