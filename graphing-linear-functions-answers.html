Graphing Linear Functions

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Identify the y-intercept of y = 2x − 3

Answer: A) (0, −3)
A y-intercept occurs where x = 0. Substituting gives y = 2(0) − 3 = −3, so the point is (0, −3).

2. Use slope −3 from the y-intercept

Answer: A) (0, 4) and (1, 1)
The y-intercept is (0, 4). A slope of −3 means that when x increases by 1, y decreases by 3, giving the second point (1, 1).

3. Find the intercepts of 2x + y = 6

Answer: A) (3, 0) and (0, 6)
Set y = 0: 2x = 6, so x = 3. Set x = 0: y = 6. Therefore the intercepts are (3, 0) and (0, 6).
02 · CORE PRACTICE

4. Evaluate y = (1/2)x + 1 at x = 4

Answer: A) (4, 3)
Substitute x = 4: y = (1/2)(4) + 1 = 2 + 1 = 3, so the point is (4, 3).

5. Move one unit right with slope 3

Answer: A) (−1, 8)
Starting at (−2, 5), increasing x by 1 changes x to −1. With slope 3, y increases by 3, from 5 to 8.

6. Equation through (0, −2) and (3, 4)

Answer: A) y = 2x − 2
The slope is (4 − (−2))/(3 − 0) = 6/3 = 2. Since (0, −2) is the y-intercept, the equation is y = 2x − 2.

7. Find the point not on y = −x + 5

Answer: D) (3, 1)
For x = 3, the equation gives y = −3 + 5 = 2, not 1. The other three points satisfy the equation exactly.

8. Build the equation from the table

Answer: A) y = −2x + 2
Each increase of 1 in x lowers y by 2, so the slope is −2. The table includes (0, 2), so the y-intercept is 2.

9. Horizontal line through (4, −3)

Answer: A) y = −3
Every point on a horizontal line has the same y-coordinate. Because the line passes through y = −3, its equation is y = −3.

10. Vertical line through (−2, 5)

Answer: A) x = −2
Every point on a vertical line has the same x-coordinate. Because the line passes through x = −2, its equation is x = −2.

11. Rewrite 3y = 6x − 9 and plot two points

Answer: A) (0, −3) and (2, 1)
Divide by 3 to get y = 2x − 3. At x = 0, y = −3; at x = 2, y = 1. Both listed points lie on the line.
03 · EXAM-STYLE PRACTICE

12. Service-charge graph at m = 8

Answer: A) (8, 16)
Substitute m = 8 into C = 1.5m + 4: C = 1.5(8) + 4 = 12 + 4 = 16. The graph contains (8, 16).

13. Equation from both intercepts

Answer: A) y = −2x + 6
The slope from (0, 6) to (3, 0) is (0 − 6)/(3 − 0) = −2. With y-intercept 6, the equation is y = −2x + 6.

14. Decreasing quantity after 5 hours

Answer: A) 5
The model is y = 25 − 4x. At x = 5, y = 25 − 4(5) = 25 − 20 = 5.

15. Compare Line A with y = 2x − 5

Answer: A) They are parallel.
Line A has slope (9 − 1)/(3 − (−1)) = 8/4 = 2. Line B also has slope 2. Their y-intercepts are different, so the lines are parallel rather than the same line.

16. Find the x-intercept of y = (3/4)x − 6

Answer: A) (8, 0)
At the x-intercept, y = 0. Solve 0 = (3/4)x − 6, so (3/4)x = 6 and x = 8.
04 · CHALLENGE PROBLEMS

17. Hidden x-coordinate a with slope 2

Answer: A) 1
Using (a, −1) and (4, 5), the slope is (5 − (−1))/(4 − a) = 6/(4 − a). Set 6/(4 − a) = 2. Then 6 = 8 − 2a, so a = 1.

18. Find p, then the x-intercept

Answer: A) (4, 0)
Because (6, −2) lies on px + 3y = 12, 6p + 3(−2) = 12, so 6p = 18 and p = 3. The line is 3x + 3y = 12. Setting y = 0 gives 3x = 12, so x = 4.
