Polynomial Addition
Advanced Math
01 · LESSON OBJECTIVE

Add polynomials by combining only like terms.

When polynomials are added, terms with the same variable part and the same exponent can be combined. The variable part stays unchanged; only the coefficients are added.

(3x² - 2x + 5) + (x² + 7x - 9)→4x² + 5x - 4
02 · CORE RULE

Match like terms, then add their coefficients.

axⁿ + bxⁿ = (a+b)xⁿ

Like terms must match completely: 3x² can combine with -5x², but not with 4x or 2x³.

03 · ORGANIZE BEFORE YOU ADD

Same exponent

x³ ↔ x³

Match terms with identical variable powers.

Add coefficients

6x² + (-2x²) = 4x²

The variable and exponent stay the same.

Keep missing powers

2x³ + 0x² + 5

A missing term has coefficient zero; writing the zero mentally helps align terms.

04 · WORKED EXAMPLE 1

Add (3x² - 2x + 5) + (x² + 7x - 9).

(3x² + x²) + (-2x + 7x) + (5 - 9)4x² + 5x - 4

Group by exponent: quadratic terms, linear terms, then constants.

Math cross-checkAt x=2, the original polynomials give 13 and 9, for a total of 22. The result gives 4(4)+5(2)-4=22.
05 · WORKED EXAMPLE 2 — MISSING TERMS

Add (2a³ - a + 6) + (-5a³ + 4a² + 3a - 2).

(2a³ - 5a³) + 4a² + (-a + 3a) + (6 - 2)-3a³ + 4a² + 2a + 4

The first polynomial has no a² term, so its a² coefficient is zero. That does not stop the polynomials from being added.

Math cross-checkAt a=1, the two original polynomials total 7, and -3+4+2+4=7.
06 · WORKED EXAMPLE 3 — APPLICATION

Two regions have areas 2x² + 3x + 4 and x² - 5x + 7 square units. Find their combined area.

(2x² + 3x + 4) + (x² - 5x + 7)3x² - 2x + 11

Because the regions are combined, add the area expressions and keep the unit as square units.

Math cross-checkAt x=2, the separate areas are 18 and 1 square units, totaling 19. The result gives 3(4)-2(2)+11=19.
07 · HORIZONTAL OR VERTICAL?

Both methods use the same mathematics.

For short polynomials, grouping like terms horizontally is efficient. For longer expressions, lining up equal powers vertically can reduce missed terms.

4x³ + 0x² - 2x + 7+ x³ + 3x² + 5x - 4= 5x³ + 3x² + 3x + 3
08 · COMMON MISTAKES
Adding exponents

2x² + 5x² = 7x², not 7x⁴. Exponents stay unchanged when like terms are added.

Combining unlike terms

3x² + 4x cannot be reduced to one term.

Dropping a negative coefficient

Read -6x as a coefficient of -6 before adding it to another x-term.

Forgetting a missing power

Use a zero coefficient as a placeholder when aligning longer polynomials.

09 · EXAM STRATEGY

Sort by exponent before doing arithmetic.

On a test-style question, first identify the x³ terms, then x² terms, then x terms, then constants. This makes sign errors easier to catch and helps you compare your final expression with answer choices.

11 · LESSON RECAP
  1. Like terms have exactly the same variable part and exponents.
  2. Add the coefficients of like terms; do not change their exponents.
  3. Terms with different powers remain separate.
  4. A missing power can be treated as having coefficient zero.
  5. Write the final polynomial in descending powers when practical.
