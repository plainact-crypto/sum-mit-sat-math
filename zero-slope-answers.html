Zero Slope

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. A line passes through (2, 5) and (8, 5). What is its slope?

Answer: B) 0
m = (5 − 5)/(8 − 2) = 0/6 = 0.

2. What is the slope of the line y = 4?

Answer: C) 0
The equation y = 4 represents a horizontal line. Every horizontal line has slope 0.

3. A table contains the points (−2, 7), (1, 7), and (6, 7). What is the slope?

Answer: B) 0
Using (−2,7) and (1,7), m = (7 − 7)/(1 − (−2)) = 0/3 = 0. The other pair gives the same result.
02 · CORE PRACTICE

4. Find the slope through (−3, −2) and (5, −2).

Answer: C) 0
m = (−2 − (−2))/(5 − (−3)) = 0/8 = 0.

5. What is the slope of y = 12?

Answer: A) 0
The graph of y = 12 is horizontal, so its slope is 0.

6. For a line, Δx = 7 and Δy = 0. What is the slope?

Answer: B) 0
m = Δy/Δx = 0/7 = 0.

7. Two distinct points on a horizontal line are (1, k) and (9, k). What is the slope?

Answer: B) 0
m = (k − k)/(9 − 1) = 0/8 = 0.

8. Which equation is the horizontal line passing through (4, −6)?

Answer: C) y = −6
A horizontal line keeps the same y-coordinate at every point. Since the point has y = −6, the equation is y = −6.

9. A linear function has f(−2) = 13, f(3) = 13, and f(10) = 13. What is its rate of change?

Answer: B) 0
The output remains 13 while the input changes, so Δy = 0 and the rate of change is 0.

10. A room stays at 68°F from 2 p.m. to 7 p.m. If temperature is modeled linearly over that interval, what is the rate of change?

Answer: A) 0°F per hour
Rate = (68 − 68)/(7 − 2) = 0/5 = 0°F per hour.

11. Which equation represents a line with zero slope?

Answer: B) 2y = 14
2y = 14 simplifies to y = 7, a horizontal line. Therefore its slope is 0.
03 · EXAM-STYLE PRACTICE

12. An account balance is $240 at the start of week 3 and still $240 at the start of week 8. If the balance is modeled linearly between those times, what is the slope?

Answer: B) 0 dollars/week
Slope = (240 − 240)/(8 − 3) = 0/5 = 0 dollars per week.

13. The line through (3, 7) and (11, p) has slope 0. What is p?

Answer: C) 7
For zero slope, the y-values must be equal. Therefore p = 7. Equivalently, 0 = (p − 7)/(11 − 3), so p − 7 = 0.

14. Which description matches a graph with zero slope?

Answer: C) A horizontal line
Zero slope means the vertical change is 0 for any nonzero horizontal change, so the graph is horizontal.

15. Which equation represents the line through (−5, 4) and (6, 4)?

Answer: B) y = 4
Both points have y = 4, so the line is horizontal and its equation is y = 4.

16. A horizontal line passes through (−2, 11). If its equation is y = c, what is c?

Answer: D) 11
A horizontal line through (−2,11) keeps y fixed at 11, so c = 11.
04 · CHALLENGE PROBLEMS

17. A line through (a, −3) and (a + 12, b) has slope 0. What is b?

Answer: B) −3
0 = (b − (−3))/((a + 12) − a) = (b + 3)/12. Thus b + 3 = 0, so b = −3.

18. The line through (−8, k) and (5, 2k − 6) has slope 0. What is k?

Answer: D) 6
For zero slope, the y-values are equal: k = 2k − 6. Subtract k from both sides to get k = 6.
