Graphing One-Variable Inequalities
Algebra
01 · LESSON OBJECTIVE

Turn a one-variable inequality into a precise number-line graph.

By the end of this lesson, you should be able to choose an open or closed endpoint, shade in the correct direction, solve an inequality before graphing it, and translate common school and exam wording into a graph.

boundary+endpoint type + direction
02 · THE FOUR SYMBOLS

The symbol tells you both inclusion and direction.

x < aOpen at aShade left.
x ≤ aClosed at aShade left.
x > aOpen at aShade right.
x ≥ aClosed at aShade right.

A strict inequality, < or >, does not include the boundary. An inclusive inequality, ≤ or ≥, does include it.

03 · ENDPOINT RULE

Ask one question: is equality allowed?

If the boundary value makes the statement true, use a closed endpoint. If the boundary value is excluded, use an open endpoint.

Open endpoint

The boundary is not part of the solution set.

x < 4 or x > 4

Closed endpoint

The boundary is included in the solution set.

x ≤ 4 or x ≥ 4
04 · WORKED EXAMPLE 1

Graph x ≤ 3.

Boundary: x = 3Equality is allowed → closed endpoint at 3Values less than 3 are solutions → shade left
Boundary checkx = 3 satisfies 3 ≤ 3, so 3 must be included.
VISUAL GRAPH

Use verified solution points to read the direction from the boundary.

The x-axis acts as the number line for x ≤ 3. The labeled boundary is x=3; the sample values x=-1 and x=1 are both on the solution side. The endpoint at 3 is included because equality is allowed.

Math cross-check−1 ≤ 3, 1 ≤ 3, and 3 ≤ 3 are all true. The point x=4 is not on the solution side because 4 ≤ 3 is false.
05 · WORKED EXAMPLE 2

Graph x > −5.

Boundary: x = −5Strict inequality → open endpoint at −5Greater values are solutions → shade right
Testx = 0 works because 0 > −5. The boundary itself does not work because −5 > −5 is false.
06 · WORKED EXAMPLE 3 — SOLVE FIRST

Solve 2x + 3 ≤ 11, then graph the solution.

2x + 3 ≤ 112x ≤ 8x ≤ 4Closed endpoint at 4; shade left

Key habit: finish the algebra before deciding where the endpoint goes.

07 · WORKED EXAMPLE 4 — NEGATIVE DIVISOR

Solve −3x > 12, then graph the solution.

−3x > 12x < −4Open endpoint at −4; shade left
Why the sign changedDividing both sides by −3 reverses the inequality. Check x = −5: 15 > 12 is true.
08 · WORDING TO SYMBOL

Translate the phrase before graphing.

at most≤Boundary included; left.
no more than≤Boundary included; left.
at least≥Boundary included; right.
exceeds / more than>Boundary excluded; right.

Example: “a load is no more than 600 kg” becomes w ≤ 600, so use a closed endpoint at 600 and shade left.

09 · COMMON MISTAKES
Using a closed endpoint for < or >

Strict inequalities exclude the boundary.

Shading by where the symbol points

Instead, think about actual solution values: smaller values are left; larger values are right.

Forgetting to reverse the sign

Multiplying or dividing by a negative reverses the inequality before you graph.

Graphing before isolating x

Solve first so the final boundary and direction are clear.

10 · EXAM STRATEGY

Use a boundary test when you are unsure.

After isolating the variable, test the boundary to decide open versus closed, then test one easy value on either side to confirm the shading direction. This takes only a few seconds and catches most graphing mistakes.

11 · QUICK CHECK

Describe each number-line graph.

1x < 4
2x ≥ −2
32x + 3 ≤ 11
4−3x > 12
5−2(3x − 1) ≥ 10
Show quick-check answers

1) Open at 4, shade left. 2) Closed at −2, shade right. 3) x ≤ 4: closed at 4, shade left. 4) x < −4: open at −4, shade left. 5) x ≤ −4/3: closed at −4/3, shade left.

12 · RECAP
  1. Solve until the variable is isolated.
  2. Use open endpoints for < and >.
  3. Use closed endpoints for ≤ and ≥.
  4. Shade left for values less than the boundary and right for values greater than it.
  5. Reverse the inequality when multiplying or dividing by a negative.
