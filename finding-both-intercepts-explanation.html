Finding Both Intercepts
Algebra
01 · LESSON OBJECTIVE

Find where a line crosses both coordinate axes.

By the end of this lesson, you should be able to find both the x-intercept and y-intercept of a linear equation quickly, write each as a coordinate point, and interpret intercepts in SAT-style contexts.

3x + 2y = 12→(4, 0) and (0, 6)
02 · WHAT YOU NEED TO KNOW

Each axis forces one coordinate to equal zero.

A point on the x-axis has y = 0. A point on the y-axis has x = 0. That gives you two simple substitutions for finding both intercepts.

X-intercept conditiony = 0Set y to zero and solve for x.
Y-intercept conditionx = 0Set x to zero and solve for y.
X-intercept point(a, 0)The second coordinate is zero.
Y-intercept point(0, b)The first coordinate is zero.
03 · KEY DEFINITIONS

X-Intercept

The point where a graph crosses the x-axis.

(x, 0)

Y-Intercept

The point where a graph crosses the y-axis.

(0, y)

Intercept

A point where a graph meets a coordinate axis.

04 · CORE RULE

Find the x-intercept with y = 0. Find the y-intercept with x = 0.

X-INT → y = 0   |   Y-INT → x = 0
05 · HOW IT WORKS

Use the same equation twice

01
Find the x-interceptSubstitute y = 0 and solve for x.
02
Write the x-interceptPut the value in the point (x, 0).
03
Find the y-interceptSubstitute x = 0 and solve for y.
04
Write the y-interceptPut the value in the point (0, y).
06 · WORKED EXAMPLE 1 — STANDARD FORM

Find both intercepts of 3x + 2y = 12.

  1. Find the x-intercept.Set y = 0.3x + 2(0) = 123x = 12 → x = 4x-intercept = (4, 0)
  2. Find the y-intercept.Set x = 0.3(0) + 2y = 122y = 12 → y = 6y-intercept = (0, 6)
Check3(4) + 2(0) = 12 and 3(0) + 2(6) = 12 ✓
07 · WORKED EXAMPLE 2 — NEGATIVE INTERCEPT

Find both intercepts of −4x + 5y = 20.

y = 0: −4x = 20 → x = −5 → (−5, 0)x = 0: 5y = 20 → y = 4 → (0, 4)

Remember: A negative intercept simply means the graph crosses that axis on its negative side.

08 · WORKED EXAMPLE 3 — SLOPE-INTERCEPT FORM

Find both intercepts of y = −2x + 10.

x-intercept: 0 = −2x + 102x = 10 → x = 5 → (5, 0)y-intercept: x = 0 → y = 10 → (0, 10)
ShortcutIn y = mx + b, the y-intercept is already (0, b).
09 · WORKED EXAMPLE 4 — FRACTION INTERCEPTS

Find both intercepts of 6x + 8y = 15.

y = 0: 6x = 15 → x = 15/6 = 5/2x-intercept = (5/2, 0)x = 0: 8y = 15 → y = 15/8y-intercept = (0, 15/8)

SAT note: Intercepts do not have to be integers. Keep exact fractions unless a decimal is specifically requested.

10 · WORKED EXAMPLE 5 — SAT STYLE

A school club has $30 to spend on notebooks costing $3 each and folders costing $5 each. The budget equation is 3x + 5y = 30. What do the intercepts mean?

y = 0: 3x = 30 → x = 10 → (10, 0)x = 0: 5y = 30 → y = 6 → (0, 6)
SAT connection

The intercepts are boundary cases. The club can buy 10 notebooks and no folders, or 6 folders and no notebooks, while spending exactly $30.

11 · STANDARD-FORM SHORTCUT

For Ax + By = C, the intercepts come directly from division.

If A ≠ 0x = C/Ax-intercept = (C/A, 0)
If B ≠ 0y = C/By-intercept = (0, C/B)

This shortcut is just the zero-substitution rule written compactly. Use it only when the needed coefficient is nonzero.

12 · SPECIAL CASES

Some lines do not have two distinct intercepts.

Horizontal liney = c, c ≠ 0Has a y-intercept (0, c), but no x-intercept.
Vertical linex = a, a ≠ 0Has an x-intercept (a, 0), but no y-intercept.
Line through originy = mxBoth intercepts are the same point: (0, 0).
13 · COMMON MISTAKES
Setting the wrong variable to zero

For the x-intercept set y = 0. For the y-intercept set x = 0.

Swapping coordinate order

The x-coordinate always comes first. Write (x, y), not (y, x).

Reporting only numbers

If a problem asks for intercept points, write ordered pairs such as (4, 0) and (0, 6).

Forcing two intercepts in a special case

A non-axis horizontal or vertical line has only one intercept.

14 · SAT STRATEGY

Think “zero one variable, solve the other.”

When both intercepts are requested, you do not need to graph the whole line. Use the equation twice. This is usually faster and more reliable than estimating from a graph.

4x + 3y = 24→(6, 0) and (0, 8)

16 · LESSON RECAP

Two intercepts, two zero substitutions.

  1. The x-intercept lies on the x-axis, so y = 0.
  2. The y-intercept lies on the y-axis, so x = 0.
  3. Solve the same equation once for each intercept.
  4. Write intercepts as ordered pairs when points are requested.
  5. In Ax + By = C, the intercepts are (C/A, 0) and (0, C/B) when A and B are nonzero.
  6. Always check horizontal, vertical, and origin cases.
x-int → y = 0y-int → x = 0Ax + By = C → (C/A, 0), (0, C/B)
