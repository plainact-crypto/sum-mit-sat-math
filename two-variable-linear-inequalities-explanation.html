Two-Variable Linear Inequalities
Algebra
01 · LESSON OBJECTIVE

Graph every ordered pair that makes an inequality true.

By the end of this lesson, you should be able to graph a two-variable linear inequality, choose a solid or dashed boundary, determine which half-plane is the solution region, and test points to verify the graph.

y ≤ 2x + 1→solid boundary · shade below
02 · CORE IDEA

The boundary line separates solutions from non-solutions.

≤ or ≥Solid lineBoundary points are included.
< or >Dashed lineBoundary points are excluded.
y < or y ≤Shade belowChoose points with smaller y-values.
y > or y ≥Shade aboveChoose points with larger y-values.
03 · WORKED EXAMPLE

Graph y ≤ 2x + 1.

  1. Graph the boundary.Use y = 2x + 1.
  2. Choose the line style.The symbol ≤ includes equality, so the boundary is solid.
  3. Test a point.(0,0) gives 0 ≤ 1, which is true.
  4. Shade the correct side.Shade the half-plane containing (0,0), below the boundary.
VISUAL GRAPH

The shaded half-plane is the solution set.

The graph below is generated directly from y ≤ 2x + 1. The solid boundary is y = 2x + 1; the shaded side contains every point whose y-value is less than or equal to the boundary value.

Math cross-checkBoundary verification: x = −1, 0, 2 gives y = −1, 1, 5 in y = 2x + 1. Test point (0,0): 0 ≤ 1 is true. Test point (0,3): 3 ≤ 1 is false. Therefore the shaded side containing (0,0) is correct.
04 · STANDARD-FORM INEQUALITIES

Rearrange carefully before deciding the shading direction.

For 2x + y > 4, solve for y: y > −2x + 4. The boundary is dashed because equality is not included, and the solution region is above the line.

Quick verification(0,5) satisfies 2(0)+5>4, while (0,0) does not.
DESMOS STRATEGY

Use Desmos to check the boundary and shaded region.

Enter

y <= 2x + 1

Look for

A solid line y = 2x + 1 with the region below it shaded.

Use it to answer

Confirm the line style, shading direction, and whether a proposed point lies in the solution region.

Why it works

Desmos shades exactly the ordered pairs that make the inequality true and includes the boundary when equality is allowed.

Faster or not?

Desmos is fast for visual checking; on simple exam-style questions, slope-intercept form plus one test point is often faster by hand.

Math cross-checkAt x=0 the boundary is y=1. Values y≤1 are solutions, so (0,0) must be shaded and (0,3) must not be shaded.
05 · COMMON MISTAKES
Wrong boundary style

Use solid only when equality is included: ≤ or ≥.

Shading from memory

If the inequality is not already solved for y, rearrange it or use a test point.

Forgetting to reverse the sign

If you divide by a negative while solving for y, reverse the inequality symbol.

Testing a boundary point

Choose a point not on the boundary so the test actually distinguishes the two sides.

06 · EXAM STRATEGY

Boundary first, test point second.

Convert the inequality to a line, decide solid versus dashed, then test an easy point such as (0,0) when it is not on the boundary. This prevents most shading errors.
