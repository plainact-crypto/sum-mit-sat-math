Greatest Common Factor
Advanced Math
01 · LESSON OBJECTIVE

Factor out the largest factor shared by every term.

The greatest common factor, or GCF, is the largest numerical and variable factor that divides every term of an expression. Factoring out the GCF rewrites a sum or difference as a product without changing its value.

18x³y² + 24x²y³→6x²y²(3x + 4y)
02 · CORE RULE

Use the greatest common coefficient and the smallest shared exponent.

GCF of terms = GCF of coefficients × shared variables with minimum exponents

Then divide every term by that GCF. The quotients become the terms inside the parentheses.

03 · HOW TO FIND THE GCF

Coefficients

Find the greatest positive integer that divides all numerical coefficients.

GCF(18, 24) = 6

Variables

Keep only variables present in every term, using the smallest exponent that appears.

x³ and x² → x²

Complete factor

Multiply the numerical and variable parts together.

6 · x² · y² = 6x²y²
04 · WORKED EXAMPLE 1 — TWO TERMS

Factor completely: 18x³y² + 24x²y³

  1. Find the coefficient GCF.GCF(18,24)=6.
  2. Find shared variable factors.Both terms contain x and y. Use x² and y² because those are the smaller exponents.
  3. Divide each term by 6x²y².18x³y² ÷ 6x²y² = 3x24x²y³ ÷ 6x²y² = 4y
  4. Write the product.6x²y²(3x + 4y)
Math cross-checkDistributing gives 18x³y² + 24x²y³, exactly the original expression.
05 · WORKED EXAMPLE 2 — THREE TERMS

Factor completely: 20a³b − 30a²b² + 10ab

GCF(20,30,10) = 10shared variable factor = ab20a³b − 30a²b² + 10ab = 10ab(2a² − 3ab + 1)
Math cross-check10ab·2a²=20a³b, 10ab·(−3ab)=−30a²b², and 10ab·1=10ab.
06 · WORKED EXAMPLE 3 — A MISSING VARIABLE

Factor completely: 14m²n + 21mn² + 35m

coefficient GCF = 7m appears in every term → keep m¹n does not appear in 35m → n is not part of the GCF7m(2mn + 3n² + 5)

Important: a variable can be included in the GCF only if every term contains it.

07 · WORKED EXAMPLE 4 — NEGATIVE LEADING TERM

Factor using a positive GCF: −15a²b + 25ab²

GCF = 5ab−15a²b ÷ 5ab = −3a25ab² ÷ 5ab = 5b5ab(−3a + 5b)
Math cross-check5ab(−3a + 5b)=−15a²b+25ab².
08 · A RELIABLE GCF METHOD
  1. List the numerical coefficients and find their greatest common factor.
  2. Check each variable separately.
  3. Keep a variable only if it appears in every term.
  4. For each shared variable, use the smallest exponent.
  5. Divide every original term by the complete GCF.
  6. Write the quotients inside parentheses.
  7. Distribute once to verify the factorization.
09 · COMMON MISTAKES
Using a common factor that is not greatest

12x + 18 can be written as 2(6x+9), but it is not factored completely. The GCF is 6, so the complete factorization is 6(2x+3).

Taking the largest exponent

For x⁵ and x², the shared factor is x², not x⁵.

Including a variable missing from one term

In 8x²y + 12x, y is not shared by both terms.

Forgetting the 1 inside parentheses

If one term equals the GCF itself, its quotient is 1. Example: 6x²+12x = 6x(x+2).

10 · EXAM STRATEGY

Check “greatest” and “every term” before you choose an answer.

In an exam-style multiple-choice question, answer choices often include a factor that is common but not greatest, or a variable power that does not divide every term. Find the coefficient GCF first, then scan variable exponents column by column.

24x⁴y² − 36x³y⁵→12x³y²(2x − 3y³)

12 · LESSON RECAP
  1. The GCF must divide every term.
  2. Use the greatest common numerical coefficient.
  3. For shared variables, use the smallest exponent.
  4. Divide each term by the GCF to build the expression inside parentheses.
  5. Factoring is complete only when no larger common factor remains.
  6. Distribute to verify the result.
