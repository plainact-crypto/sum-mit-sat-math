Systems with Parameters

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Infinitely many solutions

Answer: B) 4
Doubling 2x + y = 7 gives 4x + 2y = 14, so k = 4 makes the equations identical.

2. No solution

Answer: A) 10
The coefficients 4 and 2 are twice 2 and 1. The constant would need to be 14 for the same line; c = 10 instead gives distinct parallel lines.

3. One solution

Answer: B) 6
Only k = 4 makes the coefficient pairs proportional. With k = 6 the slopes differ, so the lines meet once.
02 · CORE PRACTICE

4. Match all coefficients

Answer: C) 4
Doubling 3x + 2y = 8 gives 6x + 4y = 16, so a = 4.

5. Match the constant

Answer: C) 16
The second equation is twice the first exactly when m = 2(8) = 16.

6. Force parallel distinct lines

Answer: A) 18
Tripling 5x − y = 9 gives 15x − 3y = 27. The coefficients already match that multiple, so any constant other than 27 gives no solution; among the choices, 18 works.

7. Recover a coefficient

Answer: B) 2
Doubling ax + 3y = 12 must produce 4x + 6y = 24. Thus 2a = 4, so a = 2.

8. Equivalent forms

Answer: B) 2
Dividing 4x + 2y = 10 by 2 gives 2x + y = 5. Therefore p = 2.

9. Identical equations

Answer: C) 6
Doubling x + 3y = 5 gives 2x + 6y = 10, so k = 6.

10. Same slope, different line

Answer: B) 8
Doubling the first equation gives 2x + 6y = 10. To have no solution, c must differ from 10; c = 8 does.

11. Parameter for no solution

Answer: B) 3
For proportional coefficients, doubling ax + 2y gives 2ax + 4y, so 2a = 6 and a = 3. The doubled constant would be 14, not 20, so the lines are parallel and distinct.
03 · EXAM-STYLE PRACTICE

12. Make the equations identical

Answer: B) 4
Doubling 4x − 2y = 6 gives 8x − 4y = 12. Therefore 2k = 8, so k = 4.

13. Infinite-solution parameter

Answer: C) 4
Tripling 2x + by = 9 gives 6x + 3by = 27. Matching 6x + 12y = 27 requires 3b = 12, hence b = 4.

14. Interpret q

Answer: A) q = 33 gives infinitely many solutions
Tripling 7x + 2y = 11 gives 21x + 6y = 33. Thus q = 33 makes the equations identical.

15. No-solution parameter

Answer: B) 5
Doubling 3x + ky = 8 gives 6x + 2ky = 16. Matching the second equation's coefficients requires 2k = 10, so k = 5; because 16 ≠ 19, the lines are distinct and parallel.

16. Pricing models

Answer: B) 6
Equal slopes make the models parallel. With p = 6, the models are C = 6n + 15 and C = 6n + 25, so they can never have the same price.
04 · CHALLENGE PROBLEMS

17. Recover a from identical equations

Answer: B) 2
Half of 6x + 8y = 24 is 3x + 4y = 12. Therefore a + 1 = 3, so a = 2.

18. Force no solution

Answer: B) 6
Tripling 2x + 3y = 7 gives 6x + 9y = 21. Setting k = 6 matches the x- and y-coefficient ratio, while 25 ≠ 21, so the equations are distinct parallel lines.
