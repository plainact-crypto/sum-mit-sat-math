One Real Solution

01 · LESSON OBJECTIVE

Recognize when a quadratic has exactly one real solution.

A quadratic has one real solution when its two roots coincide. This is called a repeated or double root.

02 · CORE RULE

One real solution means the discriminant is zero.

D=b²−4acD=0 ⇔ one repeated real solutionx=−b/(2a)

When D=0, the ±√D part of the quadratic formula becomes zero, so both branches give the same value.

03 · WORKED EXAMPLE 1

Solve x²−8x+16=0.

D=(−8)²−4(1)(16)=64−64=0x=−(−8)/(2·1)=4
Math cross-checkx²−8x+16=(x−4)², so x=4 is the only real solution and it occurs twice.
04 · WORKED EXAMPLE 2

Find k so x²+kx+16=0 has exactly one real solution.

D=k²−4(1)(16)0=k²−64k=8 or k=−8
Math cross-checkk=8 gives (x+4)²=0 and k=−8 gives (x−4)²=0. Each equation has exactly one real solution.
05 · WORKED EXAMPLE 3

Find c so 2x²−12x+c=0 has one real solution.

D=(−12)²−4(2)c=144−8c144−8c=0c=18
Math cross-check2x²−12x+18=2(x−3)², so x=3 is the repeated root.

06 · COMMON MISTAKES
Confusing one real solution with D>0

D>0 gives two distinct real solutions. Exactly one real solution requires D=0.

Dropping a parameter branch

If you reach k²=64, both k=8 and k=−8 must be checked.

Forgetting standard form

Move every term to one side before identifying a, b, and c.

07 · EXAM STRATEGY

Translate “exactly one real solution” immediately into D=0.

For coefficient or parameter questions, write b²−4ac=0 first. Solve that simpler equation for the unknown coefficient, then verify each resulting value.

09 · LESSON RECAP
  1. Write the quadratic in standard form.
  2. Exactly one real solution means D=0.
  3. Solve b²−4ac=0 for any unknown coefficient.
  4. The repeated root is x=−b/(2a).
  5. Verify parameter values by substitution or factoring when possible.
