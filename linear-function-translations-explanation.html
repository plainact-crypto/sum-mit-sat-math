Linear Function Translations
Algebra
01 · LESSON OBJECTIVE

Translate a linear graph without changing its shape.

By the end of this lesson, you should be able to identify vertical and horizontal translations, write the translated function, and explain what stays the same when a line shifts.

original function→same slope, shifted position
02 · WHAT YOU NEED TO KNOW

A translation moves every point by the same amount.

A translation slides a graph up, down, left, or right without rotating or stretching it. For a linear function, the translated graph stays parallel to the original because its slope does not change.

Up by kg(x) = f(x) + kAdd k outside the function.
Down by kg(x) = f(x) − kSubtract k outside the function.
Right by hg(x) = f(x − h)Subtract h inside the input.
Left by hg(x) = f(x + h)Add h inside the input.
03 · KEY DEFINITIONS

Translation

A shift that moves every point of a graph the same distance in the same direction.

(x, y) → shifted point

Vertical Translation

A shift that changes every output by the same amount.

f(x) ± k

Horizontal Translation

A shift that changes each input position by the same amount.

f(x ∓ h)
04 · CORE RULE / FORMULA

Outside changes vertical position; inside changes horizontal position.

g(x) = f(x − h) + k

This translates the graph of f right by h units and up by k units. A negative h moves left, and a negative k moves down. The horizontal sign can feel reversed because the change occurs inside the input.

05 · HOW IT WORKS

Use a four-step process.

01
Identify the original functionWrite f(x) clearly before making any change.
02
Read the directionDecide whether the shift is vertical, horizontal, or both.
03
Apply the translation ruleUse f(x) ± k for vertical shifts and f(x ∓ h) for horizontal shifts.
04
Simplify and checkFor a line, verify that the slope is unchanged and a known point moves as expected.
06 · WORKED EXAMPLE 1 — VERTICAL SHIFT

Let f(x) = 2x + 1. Translate the graph up 4 units.

g(x) = f(x) + 4g(x) = (2x + 1) + 4g(x) = 2x + 5

The slope remains 2. The y-intercept changes from 1 to 5, so the entire line moves up 4 units.

07 · WORKED EXAMPLE 2 — SHIFT RIGHT

Let f(x) = −3x + 7. Translate the graph right 2 units.

g(x) = f(x − 2)g(x) = −3(x − 2) + 7g(x) = −3x + 6 + 7g(x) = −3x + 13
CheckThe point (0, 7) on f moves to (2, 7) on g, and g(2) = 7.
08 · WORKED EXAMPLE 3 — SHIFT LEFT

Let p(x) = (1/2)x − 4. Translate the graph left 6 units.

q(x) = p(x + 6)q(x) = (1/2)(x + 6) − 4q(x) = (1/2)x + 3 − 4q(x) = (1/2)x − 1

The horizontal shift changes the intercept after simplification, but the slope remains 1/2.

09 · WORKED EXAMPLE 4 — TWO DIRECTIONS

Let f(x) = 4x + 1. Translate the graph right 3 units and down 2 units.

g(x) = f(x − 3) − 2g(x) = 4(x − 3) + 1 − 2g(x) = 4x − 12 + 1 − 2g(x) = 4x − 13

The line has moved right 3 and down 2 while keeping slope 4.

10 · WORKED EXAMPLE 5 — FROM EQUATIONS

Compare f(x) = −2x + 9 and g(x) = −2x + 3. Describe the translation from f to g.

g(x) − f(x) = (−2x + 3) − (−2x + 9)g(x) − f(x) = −6g(x) = f(x) − 6

The graph of g is the graph of f shifted down 6 units.

11 · WORKED EXAMPLE 6 — EXAM STYLE

A linear model is f(x) = 5x + 12. A revised model lowers every output by 8. Write the revised function.

g(x) = f(x) − 8g(x) = 5x + 12 − 8g(x) = 5x + 4
Exam connection“Every output is 8 less” describes a vertical translation. The rate of change stays 5.
12 · COMMON MISTAKES
Reversing the horizontal rule

Right by h uses f(x − h), while left by h uses f(x + h).

Changing the slope for a translation

A translation does not rotate or stretch a line, so its slope must stay the same.

Adding a vertical shift inside x

Up or down changes the output, so add or subtract outside the function.

Stopping before simplifying

When the original function is linear, substitute the shifted input and distribute carefully before combining constants.

13 · EXAM STRATEGY

Translate the words before translating the equation.

Underline the direction and the number of units. Decide whether the change acts on outputs or inputs, write the transformation in function notation, and only then simplify.

direction + distance→function rule → simplify → check slope

15 · LESSON RECAP

Translations move a line while preserving its slope.

  1. Add outside f(x) to move up; subtract outside to move down.
  2. Use f(x − h) to move right and f(x + h) to move left.
  3. Combine horizontal and vertical shifts with g(x) = f(x − h) + k.
  4. Simplify carefully after substituting the shifted input.
  5. Check that the translated line has the same slope as the original.
f(x) + k: upf(x − h): rightg(x) = f(x − h) + k
