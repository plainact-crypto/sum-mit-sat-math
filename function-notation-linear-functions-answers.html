Function Notation for Linear Functions

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. If f(x) = 3x + 4, what is f(2)?

Answer: B) 10
Substitute x = 2: f(2) = 3(2) + 4 = 6 + 4 = 10.

2. If g(x) = −2x + 7, what is g(−3)?

Answer: C) 13
Substitute x = −3: g(−3) = −2(−3) + 7 = 6 + 7 = 13.

3. If h(x) = 0.5x − 6, what is h(10)?

Answer: A) −1
h(10) = 0.5(10) − 6 = 5 − 6 = −1.
02 · CORE PRACTICE

4. Let p(x) = 5 − 4x. What is p(2)?

Answer: A) −3
p(2) = 5 − 4(2) = 5 − 8 = −3.

5. Let q(x) = (3/4)x + 2. What is q(8)?

Answer: B) 8
q(8) = (3/4)(8) + 2 = 6 + 2 = 8.

6. Let r(x) = −1.5x + 9. What is r(4)?

Answer: B) 3
r(4) = −1.5(4) + 9 = −6 + 9 = 3.

7. For f(x) = 3x + 2, which input a makes f(a) = 17?

Answer: B) 5
Set 3a + 2 = 17. Then 3a = 15, so a = 5.

8. For g(x) = −5x − 1, which value of k satisfies g(k) = 14?

Answer: B) −3
Set −5k − 1 = 14. Then −5k = 15, so k = −3.

9. If f(x) = 7x + 6, what is f(−2)?

Answer: B) −8
f(−2) = 7(−2) + 6 = −14 + 6 = −8.

10. If m(t) = 12 − 2.5t, what is m(4)?

Answer: A) 2
m(4) = 12 − 2.5(4) = 12 − 10 = 2.

11. Let f(x) = (2/3)x − 5. What is f(6)?

Answer: A) −1
f(6) = (2/3)(6) − 5 = 4 − 5 = −1.
03 · SAT-STYLE PRACTICE

12. A ride service models the cost C, in dollars, of an m-mile trip by C(m) = 1.8m + 6. What is C(10)?

Answer: B) $24
C(10) = 1.8(10) + 6 = 18 + 6 = 24, so the trip costs $24.

13. The function T(h) = 72 − 3h gives the temperature, in degrees Fahrenheit, h hours after noon. What does T(8) = 48 mean?

Answer: A) At 8:00 p.m., the temperature is 48°F.
An input of h = 8 means 8 hours after noon, which is 8:00 p.m. The output 48 is the temperature in degrees Fahrenheit.

14. If f(4) = 19, which point must lie on the graph of y = f(x)?

Answer: B) (4, 19)
Function notation f(4) = 19 means that when x = 4, y = 19. Therefore the graph contains the point (4, 19).

15. A gym models a member’s total charge P, in dollars, after m months by P(m) = 35 + 12m. What is P(6)?

Answer: C) $107
P(6) = 35 + 12(6) = 35 + 72 = 107, so the total charge is $107.

16. A tank contains h(t) = 150 − 8t liters after t minutes. After how many minutes will the tank contain 94 liters?

Answer: C) 7
Set h(t) = 94: 150 − 8t = 94. Then 8t = 56, so t = 7 minutes.
04 · CHALLENGE PROBLEMS

17. The linear function f(x) = ax + 5 satisfies f(4) = 29. What is a?

Answer: C) 6
Use f(4) = 29: 4a + 5 = 29. Then 4a = 24, so a = 6.

18. A linear function g satisfies g(2) = 7 and g(5) = 16. What is g(−1)?

Answer: B) −2
The slope is (16 − 7)/(5 − 2) = 9/3 = 3. Using g(2) = 7 gives 7 = 3(2) + b, so b = 1. Thus g(x) = 3x + 1 and g(−1) = −3 + 1 = −2.
