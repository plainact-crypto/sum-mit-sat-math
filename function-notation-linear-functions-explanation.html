Function Notation for Linear Functions
Algebra
01 · LESSON OBJECTIVE

Read and evaluate linear functions written with function notation.

By the end of this lesson, you should be able to understand what f(x) means, substitute a given input correctly, calculate the corresponding output, and interpret statements such as f(3) = 11 in school, test-style, and exam-style contexts.

f(x) = 2x + 5→f(3) = 11
02 · WHAT YOU NEED TO KNOW

Function notation names the output produced by an input.

In f(x), the letter f is the name of the function and x is the input. The expression on the right tells you how to turn that input into an output.

Functionf(x) = 2x + 5A rule connecting input x to output f(x).
Inputf(3)Replace every x in the rule with 3.
Outputf(3) = 11The function produces 11 when the input is 3.
Graph meaning(3, 11)If f(3) = 11, then (3, 11) lies on y = f(x).
03 · KEY DEFINITIONS

Function

A rule that assigns exactly one output to each allowed input.

f(x) = 3x − 1

Input

The value substituted for the independent variable.

x = 4

Output

The value produced after applying the function rule.

f(4) = 11
04 · CORE RULE

To evaluate f(a), replace every x with a and simplify.

f(x) = mx + b → f(a) = ma + b
05 · HOW IT WORKS

Use a simple substitution routine

01
Identify the inputIn f(4), the input is 4.
02
Replace the variableSubstitute 4 everywhere x appears in the rule.
03
Simplify carefullyUse order of operations and keep negative signs with their values.
04
State the outputWrite the result as f(4) = value.
06 · WORKED EXAMPLE 1 — BASIC

Let f(x) = 2x + 5. Find f(3).

  1. Use the given input.Replace x with 3.f(3) = 2(3) + 5
  2. Multiply.f(3) = 6 + 5
  3. Simplify.f(3) = 11
Graph connectionThe point (3, 11) lies on the graph of y = 2x + 5.
07 · WORKED EXAMPLE 2 — NEGATIVE INPUT

Let f(x) = 2x + 5. Find f(−4).

f(−4) = 2(−4) + 5f(−4) = −8 + 5f(−4) = −3

Remember: Put a negative input in parentheses. This makes sign errors much less likely.

08 · WORKED EXAMPLE 3 — DIFFERENT VARIABLE NAME

Let g(t) = −3t + 7. Find g(5).

g(5) = −3(5) + 7g(5) = −15 + 7g(5) = −8

The input variable does not have to be x, and the function does not have to be named f. The evaluation process is unchanged.

09 · WORKED EXAMPLE 4 — FRACTIONAL RATE

Let h(x) = (1/2)x − 6. Find h(8).

h(8) = (1/2)(8) − 6h(8) = 4 − 6h(8) = −2
Exact arithmetic(1/2) · 8 = 4, so h(8) = −2.
10 · WORKED EXAMPLE 5 — EXAM STYLE

A ride service models the cost C, in dollars, of a trip of m miles by C(m) = 2.5m + 4. What is C(6), and what does it mean?

C(6) = 2.5(6) + 4C(6) = 15 + 4C(6) = 19
Exam connectionC(6) = 19 means the model predicts a cost of $19 for a 6-mile trip. The number inside the parentheses is the input; the function value is the output in context.

11 · READING FUNCTION STATEMENTS

Translate notation into ordinary language.

Statementf(2) = 9When the input is 2, the output is 9.
Point on graph(2, 9)The graph y = f(x) contains this point.
Table rowx = 2, f(x) = 9The same input-output relationship written in a table.
12 · INTERPRETING A FUNCTION IN CONTEXT

The notation carries units and meaning.

Suppose P(t) = 120 − 8t gives the number of items remaining after t hours. Then:

P(5) = 120 − 8(5)P(5) = 120 − 40 = 80

So P(5) = 80 means 80 items remain after 5 hours. A school or exam question may ask for either the numerical value or the meaning of that value.

13 · COMMON MISTAKES
Treating f(x) as multiplication

f(x) does not mean f times x. It means the output of function f at input x.

Substituting into only one occurrence

If x appears more than once, replace every x with the given input.

Dropping parentheses around a negative input

Write f(−3) by substituting (−3), especially when multiplication is involved.

Confusing input and output

In f(4) = 13, 4 is the input and 13 is the output.

14 · EXAM STRATEGY

Translate the notation before doing arithmetic.

When you see f(a), say to yourself: “Use a as the input.” Then substitute directly into the rule. If the question is in context, finish by attaching the correct meaning and units to the output.

f(x) = 4x − 1→f(6) = 23

16 · LESSON RECAP

Function notation is an input-output language.

  1. f(x) names the output of function f for input x.
  2. To evaluate f(a), substitute a for every x in the rule.
  3. Simplify carefully, especially with negative inputs and fractions.
  4. If f(a) = b, then (a, b) is a point on the graph y = f(x).
  5. In context, explain what both the input and output represent.
f(x) = mx + bf(a) = ma + bf(a) = b → point (a, b)
