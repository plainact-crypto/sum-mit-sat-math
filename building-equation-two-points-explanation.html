Building an Equation from Two Points
Algebra
01 · LESSON OBJECTIVE

Write a linear equation when two points are known.

By the end of this lesson, you should be able to find the slope from two points, use one point to determine the equation, and verify that both original points satisfy the final equation.

(2, 5), (6, 13)→y = 2x + 1
02 · WHAT YOU NEED TO KNOW

Two distinct points determine one line.

First calculate the slope using the change in y divided by the change in x. Then use either point in point-slope form or substitute into slope-intercept form to find the constant term.

Slopem = (y₂ − y₁)/(x₂ − x₁)Use the same point order in numerator and denominator.
Point-slope formy − y₁ = m(x − x₁)Works immediately after finding m.
Slope-intercept formy = mx + bUseful when the final answer should show the intercept.
CheckBoth pointsEach ordered pair must make the equation true.
03 · KEY DEFINITIONS

Ordered Pair

A point written as an x-value and a y-value.

(x, y)

Slope

The rate of change between two points on a line.

Δy / Δx

Linear Equation

An equation whose graph is a straight line.

y = mx + b
04 · CORE RULE / FORMULA

Find the slope first, then build the equation.

m = (y₂ − y₁)/(x₂ − x₁)

Once m is known, substitute one point into y = mx + b to solve for b, or place the point directly into point-slope form.

05 · HOW IT WORKS

Use a four-step process.

01
Label the pointsChoose one as (x₁, y₁) and the other as (x₂, y₂).
02
Find the slopeCompute (y₂ − y₁)/(x₂ − x₁).
03
Find the equationUse y = mx + b or point-slope form.
04
VerifySubstitute both original points.
06 · WORKED EXAMPLE 1 — BASIC

Find the equation through (1, 4) and (3, 10).

m = (10 − 4)/(3 − 1) = 6/2 = 34 = 3(1) + bb = 1y = 3x + 1
CheckAt x = 3, y = 3(3) + 1 = 10.
07 · WORKED EXAMPLE 2 — NEGATIVE SLOPE

Find the equation through (−1, 7) and (3, −1).

m = (−1 − 7)/(3 − (−1)) = −8/4 = −27 = −2(−1) + b7 = 2 + b → b = 5y = −2x + 5

Sign check: As x increases from −1 to 3, y decreases, so a negative slope makes sense.

08 · WORKED EXAMPLE 3 — FRACTIONAL SLOPE

Find the equation through (2, 1) and (8, 4).

m = (4 − 1)/(8 − 2) = 3/6 = 1/21 = (1/2)(2) + b1 = 1 + b → b = 0y = (1/2)x
09 · WORKED EXAMPLE 4 — POINT-SLOPE FORM

Write an equation through (4, −2) and (7, 4).

m = (4 − (−2))/(7 − 4) = 6/3 = 2y − (−2) = 2(x − 4)y + 2 = 2(x − 4)y = 2x − 10

Either point can be used in point-slope form and will produce the same line.

10 · WORKED EXAMPLE 5 — FROM A CONTEXT

A quantity is 18 when x = 2 and 42 when x = 6. Assume a linear relationship. Write the equation.

m = (42 − 18)/(6 − 2) = 24/4 = 618 = 6(2) + bb = 6y = 6x + 6
CheckAt x = 6, y = 36 + 6 = 42.
11 · WORKED EXAMPLE 6 — EXAM STYLE

A linear function passes through (5, 11) and (9, 23). Which equation represents the function?

m = (23 − 11)/(9 − 5) = 12/4 = 311 = 3(5) + bb = −4y = 3x − 4

VISUAL GRAPH

The two given points determine the same verified line.

For (2, 5) and (6, 13), the slope is (13 − 5)/(6 − 2) = 2. Substituting either point gives b = 1, so the line is y = 2x + 1.

Math cross-checkAt x = 0, 2, 6, y = 2x + 1 gives y = 1, 5, 13. All three points satisfy the equation, including both original points.

Look for

Use it to answer

Why it works

Two distinct points determine one line, and every point on that line satisfies its equation.

12 · COMMON MISTAKES
Reversing only one subtraction

If you compute y₂ − y₁, also compute x₂ − x₁. Keep the point order consistent.

Using x-change over y-change

Slope is change in y divided by change in x, not the other way around.

Stopping after finding the slope

The slope alone is not the full equation. You still need a point or intercept to locate the line.

Checking only one point

A correct final equation must satisfy both original ordered pairs.

13 · EXAM STRATEGY

Keep the subtraction order consistent.

Write the points vertically if signs are complicated. Subtract second minus first in both coordinates, simplify the slope exactly, then use the easier point to solve for b.

same order top and bottom→correct slope sign

15 · LESSON RECAP

Two points give the slope and the location of the line.

  1. Label the two ordered pairs.
  2. Find the slope with Δy/Δx.
  3. Use one point to solve for b or write point-slope form.
  4. Simplify the equation.
  5. Verify both original points.
