01 · SKILL CHECK

1. Adult tickets

Answer: C) 9
Let a be adult tickets and s be student tickets. Then a + s = 18 and 9a + 5s = 126. Substitute s = 18 − a: 9a + 5(18 − a) = 126, so 4a = 36 and a = 9. Check: 9(9) + 5(9) = 126.

2. Notebooks

Answer: A) 3
Let n be notebooks and p be pens. Then n + p = 14 and 4n + 2p = 34. Substitute p = 14 − n: 4n + 2(14 − n) = 34, so 2n = 6 and n = 3. Check: 4(3) + 2(11) = 34.

3. Calculators

Answer: C) 18
Let c be calculators and r be rulers. Then c + r = 30 and 7c + 4r = 174. Substitute r = 30 − c: 7c + 4(30 − c) = 174, so 3c = 54 and c = 18. Check: 7(18) + 4(12) = 174.
02 · CORE PRACTICE

4. Fundraiser adult tickets

Answer: C) 22
Let a be adult tickets and c be child tickets. From a + c = 42 and 9a + 6c = 318, substitute c = 42 − a: 9a + 6(42 − a) = 318. Thus 3a = 66, so a = 22. Check: 9(22) + 6(20) = 318.

5. Quarters

Answer: B) 10
Let q be quarters and d be dimes. Then q + d = 20 and 0.25q + 0.10d = 3.50. Substituting d = 20 − q gives 0.15q = 1.50, so q = 10. The value check is $2.50 + $1.00 = $3.50.

6. Mixture

Answer: C) 18 liters
Let x be liters of 20% solution and y be liters of 50% solution. Then x + y = 30 and 0.20x + 0.50y = 0.38(30) = 11.4. With x = 30 − y, 6 − 0.20y + 0.50y = 11.4, so 0.30y = 5.4 and y = 18 liters.

7. Rectangle length

Answer: C) 16 cm
Perimeter 54 cm gives 2L + 2W = 54, or L + W = 27. Also L = W + 5. Then 2W + 5 = 27, so W = 11 and L = 16 cm. Check: 2(16) + 2(11) = 54.

8. Premium sandwiches

Answer: C) 39
Let r be regular sandwiches and p be premium sandwiches. Then r + p = 64 and 5r + 8p = 437. Substitute r = 64 − p: 5(64 − p) + 8p = 437, so 3p = 117 and p = 39. Check: 5(25) + 8(39) = 437.

9. Gym plans

Answer: B) 8 months
Set the total costs equal: 20 + 6m = 44 + 3m. Then 3m = 24, so m = 8 months. Both plans cost $68 at that time.

10. Machine B time

Answer: C) 8 hours
The system is x + y = 13 and 30x + 45y = 510. Substitute x = 13 − y: 30(13 − y) + 45y = 510. Thus 15y = 120, so y = 8 hours. Check: 30(5) + 45(8) = 510.

11. Larger number

Answer: C) 33
Let L be the larger number and S the smaller. The equations are L + S = 52 and L − S = 14. Add them: 2L = 66, so L = 33. The other number is 19, and 33 − 19 = 14.
03 · EXAM-STYLE PRACTICE

12. Delivery services

Answer: C) 9 miles
Set the charges equal: 18 + 4d = 36 + 2d. Then 2d = 18, so d = 9 miles. Both services charge $54.

13. Theater adult tickets

Answer: C) 190
Let a be adult tickets and c be child tickets. Then a + c = 260 and 10a + 6c = 2320. Substitute c = 260 − a: 10a + 6(260 − a) = 2320, so 4a = 760 and a = 190. Check: 10(190) + 6(70) = 2320.

14. Metal mixture

Answer: C) 15 kg
Let x be kilograms of 10% alloy and y be kilograms of 40% alloy. Then x + y = 25 and 0.10x + 0.40y = 0.28(25) = 7. Substitute x = 25 − y: 2.5 + 0.30y = 7, so y = 15 kg.

15. Burgers

Answer: C) 60
Let b be burgers and s be side orders. Then b + s = 120 and 9b + 6s = 900. Substitute s = 120 − b: 9b + 6(120 − b) = 900, so 3b = 180 and b = 60. Check: 9(60) + 6(60) = 900.

16. Ride plans

Answer: C) 12 miles
Set the costs equal: 15 + 4d = 33 + 2.5d. Then 1.5d = 18, so d = 12 miles. Both plans cost $63.
04 · CHALLENGE PROBLEMS

17. Large crates

Answer: B) 14
Let s be small crates and l be large crates. Then s + l = 34 and 12s + 20l = 520. Substitute s = 34 − l: 12(34 − l) + 20l = 520, so 8l = 112 and l = 14. Check: 12(20) + 20(14) = 520.

18. VIP tickets

Answer: C) 160
Because the event kept $10,920 after a $600 fee, gross ticket revenue was $11,520. Let v be VIP tickets and s be standard tickets. Then v + s = 240 and 54v + 36s = 11520. Substitute s = 240 − v: 54v + 36(240 − v) = 11520, so 18v = 2880 and v = 160. Check: 54(160) + 36(80) − 600 = 10920.
