Solving by Substitution

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Substitute x = y + 2

Answer: A) (6, 4)
Replace x in x + y = 10: (y + 2) + y = 10, so 2y = 8 and y = 4. Then x = 4 + 2 = 6. Check: 6 + 4 = 10.

2. Substitute y = 2x − 1

Answer: B) (4, 7)
Use x + y = 11: x + (2x − 1) = 11, so 3x = 12 and x = 4. Then y = 2(4) − 1 = 7. Check: 4 + 7 = 11.

3. Substitute x = 3y

Answer: C) (6, 2)
Use 2x + y = 14: 2(3y) + y = 14, so 7y = 14 and y = 2. Then x = 3(2) = 6. Check: 2(6) + 2 = 14.
02 · CORE PRACTICE

4. Substitute y = x − 1

Answer: B) (5, 4)
x + (x − 1) = 9 gives 2x = 10, so x = 5 and y = 4. Check: 5 + 4 = 9.

5. Substitute the known y-value

Answer: C) (5, 3)
With y = 3, 2x + 3 = 13, so 2x = 10 and x = 5. The solution is (5, 3).

6. Substitute y = 4 − x

Answer: A) (4, 0)
3x + 2(4 − x) = 12 gives x + 8 = 12, so x = 4. Then y = 4 − 4 = 0. Check: 3(4) + 2(0) = 12.

7. Substitute x = 2y + 1

Answer: B) (5, 2)
3(2y + 1) − y = 13 gives 5y + 3 = 13, so y = 2. Then x = 2(2) + 1 = 5.

8. Substitute y = 0.5x + 2

Answer: C) (12, 8)
x − (0.5x + 2) = 4 gives 0.5x = 6, so x = 12. Then y = 0.5(12) + 2 = 8.

9. Substitute y = x + 1

Answer: B) (2, 3)
4x − (x + 1) = 5 gives 3x = 6, so x = 2. Then y = 3. Check: 4(2) − 3 = 5.

10. Substitute y = −2x + 7

Answer: B) (3, 1)
5x + (−2x + 7) = 16 gives 3x = 9, so x = 3. Then y = −6 + 7 = 1.

11. Substitute x = y − 4

Answer: A) (−3, 1)
(y − 4) + 2y = −1 gives 3y = 3, so y = 1. Then x = 1 − 4 = −3. Check: −3 + 2(1) = −1.
03 · EXAM-STYLE PRACTICE

12. Adult and child tickets

Answer: C) 13
Because a + c = 18 and a = 2c + 3, substitute: 2c + 3 + c = 18. Then 3c = 15, so c = 5 and a = 13 adult tickets.

13. Repair-service formula

Answer: B) 3
Set C = 22 in C = 6h + 4: 22 = 6h + 4. Then 18 = 6h, so h = 3 hours.

14. Find the parameter k

Answer: C) 5
With x = 3 and y = 11, substitute into y = 2x + k: 11 = 2(3) + k, so k = 5.

15. Rectangle length

Answer: C) 11 units
Perimeter 34 gives 2L + 2W = 34, so L + W = 17. Substitute L = W + 5: 2W + 5 = 17, so W = 6 and L = 11 units.

16. Two-number system

Answer: C) 19
Substitute x = 3y − 2 into x + y = 26: 3y − 2 + y = 26. Then 4y = 28, so y = 7 and x = 19.
04 · CHALLENGE PROBLEMS

17. Fractional substitution

Answer: A) (34/5, 18/5)
Substitute y = (x + 4)/3 into 2x − y = 10: 2x − (x + 4)/3 = 10. Multiply by 3: 6x − x − 4 = 30, so 5x = 34 and x = 34/5. Then y = (34/5 + 4)/3 = 18/5.

18. Parameter after substitution

Answer: C) 4
The given solution has y = 4, so x = 2 − 4 = −2. Substitute into 3x + ky = 10: 3(−2) + 4k = 10. Thus 4k = 16 and k = 4.
