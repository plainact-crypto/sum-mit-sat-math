Polynomial Multiplication

Practice Questions 1–18 · exact 1-to-1 solutions

1. 3x(2x + 5)

3x·2x + 3x·5 = 6x² + 15x.
Answer: A) 6x² + 15x

2. -2y(4y - 3)

-2y·4y + (-2y)(-3) = -8y² + 6y.
Answer: A) -8y² + 6y

3. (x + 4)(x + 2)

x² + 2x + 4x + 8 = x² + 6x + 8.
Answer: A) x² + 6x + 8

4. (x + 7)(x - 3)

x² - 3x + 7x - 21 = x² + 4x - 21.
Answer: A) x² + 4x - 21

5. (2x + 5)(x + 3)

2x² + 6x + 5x + 15 = 2x² + 11x + 15.
Answer: A) 2x² + 11x + 15

6. (3m - 2)(2m + 5)

6m² + 15m - 4m - 10 = 6m² + 11m - 10.
Answer: A) 6m² + 11m - 10

7. (x - 6)²

(x - 6)(x - 6) = x² - 12x + 36.
Answer: A) x² - 12x + 36

8. 4a²(3a³ - 2a + 5)

12a⁵ - 8a³ + 20a².
Answer: A) 12a⁵ - 8a³ + 20a²

9. (2p - 3)(2p + 3)

This is a difference of squares: (2p)² - 3² = 4p² - 9.
Answer: A) 4p² - 9

10. (x + 2)(x² - 3x + 4)

x³ - 3x² + 4x + 2x² - 6x + 8 = x³ - x² - 2x + 8.
Answer: A) x³ - x² - 2x + 8

11. (1/2)x(6x² - 4x + 10)

3x³ - 2x² + 5x.
Answer: A) 3x³ - 2x² + 5x

12. (x - 5)(x + 8)

x² + 8x - 5x - 40 = x² + 3x - 40.
Answer: A) x² + 3x - 40

13. Rectangle: (x + 6) m by (x + 2) m

Area = (x + 6)(x + 2) = x² + 8x + 12 square meters.
Answer: A) x² + 8x + 12 m²

14. P(x)=2x+1, Q(x)=x²-4x+3

(2x+1)(x²-4x+3) = 2x³ - 8x² + 6x + x² - 4x + 3 = 2x³ - 7x² + 2x + 3.
Answer: A) 2x³ - 7x² + 2x + 3

15. Display: (3n - 1) cm by (n + 4) cm

Area = 3n² + 12n - n - 4 = 3n² + 11n - 4 square centimeters.
Answer: A) 3n² + 11n - 4 cm²

16. (x + k)(x + 3) has x-term 10x

Expansion gives x² + (k+3)x + 3k. So k + 3 = 10, hence k = 7.
Answer: A) 7

17. (2x² - x + 3)(x - 4)

2x³ - 8x² - x² + 4x + 3x - 12 = 2x³ - 9x² + 7x - 12.
Answer: A) 2x³ - 9x² + 7x - 12

18. (x+a)(x+b)=x²+9x+20, a>b

a+b=9 and ab=20. The pair is 5 and 4. Since a>b, a=5 and b=4, so a-b=1.
Answer: A) 1
