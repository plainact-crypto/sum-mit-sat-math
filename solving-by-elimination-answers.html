Solving by Elimination

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Eliminate y by adding

Answer: A) (4, 3)
Add x + y = 7 and x − y = 1: 2x = 8, so x = 4. Then y = 3. Check: 4 + 3 = 7 and 4 − 3 = 1.

2. Eliminate y by adding

Answer: B) (4, 3)
Add the equations: 4x = 16, so x = 4. Substitute into 2x + y = 11: 8 + y = 11, so y = 3.

3. Eliminate y by adding

Answer: C) (4, 2)
Add the equations: 6x = 24, so x = 4. Then 12 + 2y = 16, giving y = 2.
02 · CORE PRACTICE

4. Opposite y-terms

Answer: A) (3, 2)
Add the equations: 3x = 9, so x = 3. Then 3 + y = 5 gives y = 2.

5. Subtract to eliminate x

Answer: B) (3, 2)
Subtract 4x − y = 10 from 4x + 3y = 18: 4y = 8, so y = 2. Then 4x − 2 = 10, so x = 3.

6. Opposite 5y-terms

Answer: B) (5, 2)
Add the equations: 5x = 25, so x = 5. Then 10 + 5y = 20 gives y = 2.

7. Opposite 2y-terms

Answer: B) (2, 3)
Add the equations: 8x = 16, so x = 2. Then 6 + 2y = 12, so y = 3.

8. Decimal coefficients

Answer: B) (8, 2)
Add the equations: x = 8. Substitute into 0.5x + y = 6: 4 + y = 6, so y = 2.

9. Opposite 2y-terms

Answer: B) (3, 1)
Add the equations: 10x = 30, so x = 3. Then 21 − 2y = 19, so y = 1.

10. Opposite x-terms

Answer: A) (−3, 2)
Add the equations: 5y = 10, so y = 2. Then x + 4 = 1, so x = −3.

11. Opposite 5x-terms

Answer: A) (−1, 2)
Add the equations: 6y = 12, so y = 2. Then −5x + 4 = 9 gives −5x = 5, so x = −1.
03 · EXAM-STYLE PRACTICE

12. Ticket sales

Answer: C) 11
Let a be adult tickets and s student tickets. From a + s = 23 and 12a + 8s = 228, multiply the first equation by 8: 8a + 8s = 184. Subtract to get 4a = 44, so a = 11 adult tickets.

13. Equipment rentals

Answer: C) $90
Let s and L be the small and large rental costs. Subtract 3s + 2L = 420 from 3s + 5L = 690: 3L = 270, so L = $90.

14. Parameter k

Answer: B) −1
With x = 2, the first equation gives 4 + 3y = 13, so y = 3. Then k = 4x − 3y = 8 − 9 = −1.

15. Notebook price

Answer: C) $6
Subtract 2n + 3p = 27 from 4n + 3p = 39: 2n = 12, so n = $6.

16. Decimal elimination

Answer: C) 5
Subtract the second equation from the first: 0.3y = 1.5, so y = 5. Substitution gives 0.3x + 1 = 2.4, confirming x = 14/3.
04 · CHALLENGE PROBLEMS

17. Fraction coefficients

Answer: A) (6, 3)
Add the equations: x = 6. Substitute into (1/2)x + (1/3)y = 4: 3 + y/3 = 4, so y = 3. Both original equations are satisfied.

18. Same-line parameter

Answer: C) 4
For the equations to represent the same line, the second must be exactly twice the first. Twice 3x + 2y = 7 is 6x + 4y = 14, so k = 4.
