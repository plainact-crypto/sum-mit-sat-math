Compound Inequalities
Algebra
01 · LESSON OBJECTIVE

Solve compound inequalities and distinguish AND from OR.

A compound inequality combines two inequality conditions. With AND, a value must satisfy both conditions at the same time. With OR, a value may satisfy either condition.

2 < 3x−4 ≤ 17→2 < x ≤ 7
02 · THE TWO LOGIC WORDS

AND means overlap. OR means combine.

ANDBoth must be trueKeep only values shared by both solution sets.
ORAt least one is trueKeep every value that satisfies either solution set.
Key questionOverlap or union?That choice determines the final solution set.
03 · CORE RULE

Treat each condition correctly, then combine the solution sets using the stated logic.

AND → INTERSECTION   ·   OR → UNION
04 · WORKED EXAMPLE 1 — THREE-PART AND

Solve 2 < 3x−4 ≤ 17.

  1. Add 4 to all three parts.6 < 3x ≤ 21
  2. Divide all three parts by positive 3.2 < x ≤ 7
  3. Read both boundaries.2 is excluded because the sign is strict; 7 is included because the sign allows equality.
Checkx=3 gives 2<5≤17, true. x=7 gives 2<17≤17, true. x=2 gives 2<2≤17, false.
05 · WORKED EXAMPLE 2 — ANOTHER AND

Solve −5 ≤ 2x+1 < 9.

−6 ≤ 2x < 8−3 ≤ x < 4

Same operation, all three parts: subtract 1, then divide by positive 2.

Checkx=−3 gives −5≤−5<9, true. x=4 gives −5≤9<9, false.
06 · WORKED EXAMPLE 3 — OR

Solve 4x+1 < −7 OR 3x−5 ≥ 7.

4x < −8 → x < −23x ≥ 12 → x ≥ 4x < −2 OR x ≥ 4

Why two pieces? Values below −2 satisfy the first inequality; values from 4 upward satisfy the second.

Checkx=−3 works in the first inequality. x=4 works in the second. x=0 satisfies neither, so it is not in the union.
07 · NEGATIVE MULTIPLIER INSIDE A COMPOUND INEQUALITY

Solve −12 ≤ −3x < 6.

Dividing every part by −3 reverses both inequality signs.

4 ≥ x > −2−2 < x ≤ 4
Checkx=0 gives −12≤0<6, true. x=4 gives −12≤−12<6, true. x=−2 gives −12≤6<6, false.
08 · SPECIAL CASES

Some compound inequalities collapse to nothing or everything.

No overlapx>5 AND x≤2No real number satisfies both, so the solution set is empty.
Covers all valuesx≤3 OR x>3Every real number satisfies at least one condition.
09 · EXAM-STYLE CONTEXT

A storage room must stay above 18°C and at or below 24°C. Write the allowable temperature range T.

T > 18T ≤ 2418 < T ≤ 24

Interpretation: Both restrictions must hold, so this is an AND condition.

Units check19°C is allowed; 18°C is not; 24°C is allowed; 25°C is not.
10 · A RELIABLE DECISION ROUTINE

Separate algebra from logic.

Step 1Identify AND or ORKnow whether you need overlap or union.
Step 2Solve carefullyFor a three-part inequality, perform the same operation on every part.
Step 3Combine and verifyTest boundaries and representative values.
11 · COMMON MISTAKES
Treating AND like OR

AND keeps only the overlap, not every value from either inequality.

Operating on only two parts

In a chain such as 2<3x−4≤17, add, subtract, multiply, or divide all three expressions.

Forgetting sign reversal

If you multiply or divide a compound inequality by a negative number, reverse every affected inequality sign.

Ignoring endpoint type

< and > exclude equality; ≤ and ≥ include it.

12 · EXAM STRATEGY

Translate the logic word before doing arithmetic.

In school and exam-style questions, mark AND = overlap or OR = union first. Then solve each inequality. This prevents a correct algebra solution from being combined with the wrong logic.

14 · LESSON RECAP

Logic tells you how to combine correct algebra.

  1. AND means values must satisfy both conditions.
  2. OR means values may satisfy either condition.
  3. Apply the same operation to every part of a chained inequality.
  4. Reverse inequality signs when multiplying or dividing by a negative number.
  5. Check boundaries and representative values in the original conditions.
