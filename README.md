# SUMMIT SAT MATH

Production source for the SUMMIT SAT MATH website.

- 298 curriculum leaf lessons
- 5 independent routes per leaf
- 1,490 lesson routes total
- 894 scheduled non-video pages
- 596 independent video routes
- Global schedule starts 2026-09-03 22:00 Africa/Cairo and advances by 12 minutes per Explanation/Problems/Answers page

`npm run build` generates the deployable static site into `dist/` and fails if counts or route uniqueness do not match the expected curriculum.
