Finding X-Intercept
Algebra
01 · LESSON OBJECTIVE

Find where a line crosses the x-axis.

By the end of this lesson, you should be able to find the x-intercept of a linear equation in standard form, slope-intercept form, or a word-problem context.

2x + 3y = 12→ y = 0 →x = 6
02 · WHAT YOU NEED TO KNOW

Every point on the x-axis has y = 0.

The x-intercept is the point where a graph crosses the x-axis. Because the point lies on the x-axis, its y-coordinate must be zero.

X-intercept conditiony = 0Substitute zero for y.
Coordinate form(a, 0)The x-intercept is a point.
Standard formAx + By = CSet y = 0, then solve Ax = C.
Slope-intercepty = mx + bSet 0 = mx + b and solve for x.
03 · KEY DEFINITIONS

X-Intercept

The point where a graph crosses the x-axis.

(x, 0)

Intercept

A point where a graph crosses an axis.

X-Axis

The horizontal coordinate axis.

y = 0
04 · CORE RULE

To find the x-intercept, set y equal to zero and solve for x.

X-INTERCEPT → SET y = 0
05 · HOW IT WORKS

Use the same three-step process every time

01
Set y = 0.This forces the point onto the x-axis.
02
Solve the remaining equation for x.Simplify carefully and keep track of signs.
03
Write the intercept as a point.If x = a, the x-intercept is (a, 0).
04
Check.Substitute the point into the original equation.
06 · WORKED EXAMPLE 1 — STANDARD FORM

Find the x-intercept of 3x + 2y = 18.

  1. Set y = 0.3x + 2(0) = 18
  2. Solve for x.3x = 18x = 6
  3. Write the point.(6, 0)
Check3(6) + 2(0) = 18 ✓
07 · WORKED EXAMPLE 2 — NEGATIVE INTERCEPT

Find the x-intercept of 4x − y = −20.

4x − 0 = −204x = −20x = −5x-intercept = (−5, 0)

Remember: An x-intercept can be negative. The graph then crosses the x-axis to the left of the origin.

08 · WORKED EXAMPLE 3 — SLOPE-INTERCEPT FORM

Find the x-intercept of y = 2x − 10.

0 = 2x − 1010 = 2xx = 5x-intercept = (5, 0)
Check0 = 2(5) − 10 ✓
09 · WORKED EXAMPLE 4 — FRACTION INTERCEPT

Find the x-intercept of 6x + 4y = 9.

6x + 4(0) = 96x = 9x = 9/6 = 3/2x-intercept = (3/2, 0)
10 · WORKED EXAMPLE 5 — SAT STYLE

A line is represented by 5x + 2y = 40. What is the x-coordinate of its x-intercept?

5x + 2(0) = 405x = 40x = 8
SAT connection

If the question asks only for the x-coordinate, your final answer is 8. If it asks for the x-intercept as a point, write (8, 0).

11 · SPECIAL CASES

Not every line has exactly one x-intercept.

Horizontal line above/below axisy = c, c ≠ 0No x-intercept.
The x-axis itselfy = 0Every point on the line is an x-intercept.
Vertical linex = aOne x-intercept: (a, 0).
12 · COMMON MISTAKES
Setting x = 0

That finds the y-intercept, not the x-intercept. For the x-intercept, set y = 0.

Giving only x when a point is requested

If x = 6, the x-intercept is (6, 0).

Dropping a negative sign

Keep the original signs when substituting y = 0 and solving.

Assuming every line crosses the x-axis once

A horizontal line y = c with c ≠ 0 never crosses the x-axis.

13 · SAT STRATEGY

Do not convert forms unless you need to.

For an equation such as 7x + 3y = 21, the fastest route is to set y = 0 immediately. Converting to slope-intercept form first adds unnecessary algebra.

7x + 3y = 21→ y = 0 →x = 3

15 · LESSON RECAP

One substitution reveals the x-intercept.

  1. The x-intercept lies on the x-axis.
  2. Every point on the x-axis has y = 0.
  3. Substitute y = 0 into the equation.
  4. Solve for x.
  5. Write the point as (x, 0) when a coordinate is requested.
  6. Check by substituting the point into the original equation.
