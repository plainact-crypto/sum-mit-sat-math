Solving by Square Roots
Advanced Math
01 · LESSON OBJECTIVE

Solve quadratic equations by isolating a square and taking square roots.

This method is especially efficient when the equation can be written as u² = k. Remember that a positive square can come from two real numbers: one positive and one negative.

x² = 49→x = ±7
02 · CORE RULE

If u² = k, then u = ±√k when k ≥ 0.

  1. Isolate the squared expression.
  2. Take the square root of both sides.
  3. Write both signs: ±.
  4. Solve for the variable if the squared expression contains more than just x.
  5. Substitute the solutions into the original equation.
Real-number noteIf k<0, there is no real solution because the square of a real number cannot be negative.
03 · WORKED EXAMPLE 1 — BASIC

Solve: x² = 49

x = ±√49x = ±7
Math cross-check7²=49 and (−7)²=49, so both values satisfy the equation.
04 · WORKED EXAMPLE 2 — ISOLATE THE SQUARE

Solve: 3x² − 12 = 0

3x²=12x²=4x=±2
Math cross-checkFor x=2 or x=−2, 3x²−12=3(4)−12=0.
05 · WORKED EXAMPLE 3 — SQUARED BINOMIAL

Solve: (x − 3)² = 20

x−3=±√20x−3=±2√5x=3±2√5
Math cross-checkFor either x=3±2√5, x−3=±2√5, and (x−3)²=20.
06 · WORKED EXAMPLE 4 — SOLVE AFTER THE ROOT

Solve: (2x + 1)² = 25

2x+1=±52x+1=5 → x=22x+1=−5 → x=−3
Math cross-checkAt x=2, (2x+1)²=5²=25. At x=−3, (2x+1)²=(−5)²=25.
07 · WORKED EXAMPLE 5 — NO REAL SOLUTION

Solve over the real numbers: x² + 9 = 0

x²=−9No real solution

Why: every real square is nonnegative, so no real x can make x² equal −9.

08 · COMMON MISTAKES
Forgetting ±

From x²=36, the solutions are x=6 and x=−6, not only x=6.

Taking a square root before isolating the square

For 2x²+5=23, first reach x²=9; then take square roots.

Applying ± to only part of an expression

From (x−4)²=11, write x−4=±√11, then add 4 to both branches.

Inventing a real root of a negative number

Over the real numbers, u² cannot equal a negative value.

09 · EXAM STRATEGY

Look for a squared expression that can be isolated quickly.

If the equation has no linear x-term after simplification, or it already contains a squared binomial, the square-root method can be faster than factoring. Keep exact radicals unless the question asks for a decimal approximation.

11 · LESSON RECAP
  1. Isolate the squared expression.
  2. Take square roots of both sides.
  3. Use ± when the isolated square equals a positive number.
  4. Simplify exact radicals when possible.
  5. Solve the remaining linear equations.
  6. Check each result in the original equation.
