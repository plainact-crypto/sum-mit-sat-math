01 · SKILL CHECK

1. Intersection of two lines

Answer: B) (2, 3)
Set the two y-values equal: x + 1 = −x + 5, so 2x = 4 and x = 2. Then y = 3. The point (2, 3) lies on both lines.

2. Read the common point

Answer: B) (3, 5)
At an intersection, 2x − 1 = x + 2. Thus x = 3 and y = 5. Substitution gives 2(3) − 1 = 5 and 3 + 2 = 5.

3. Fractional slope intersection

Answer: B) (2, 2)
Solve −x + 4 = 0.5x + 1. Then 3 = 1.5x, so x = 2 and y = 2. Both equations give y = 2.
02 · CORE PRACTICE

4. Opposite-direction lines

Answer: B) (3, 5)
Set 3x − 4 = −x + 8. Then 4x = 12, so x = 3 and y = 5.

5. Decimal slope

Answer: C) (4, 4)
Solve 0.5x + 2 = −x + 8. This gives 1.5x = 6, so x = 4 and y = 4.

6. Shared graphical solution

Answer: B) (3, 1)
Set −2x + 7 = x − 2. Then 9 = 3x, so x = 3. Substitution gives y = 1.

7. Exact fractional slopes

Answer: C) (3, 3)
Set x/3 + 2 = −2x/3 + 5. Adding 2x/3 gives x + 2 = 5, so x = 3 and y = 3.

8. Parallel lines

Answer: A) No solutions
Both lines have slope 4 but different y-intercepts, 1 and −6. Distinct parallel lines never intersect, so the system has no solution.

9. Same line

Answer: C) The same line, so infinitely many solutions
Divide 2y = 6x + 4 by 2 to get y = 3x + 2, exactly the second equation. Their graphs coincide at every point.

10. Standard form and slope form

Answer: B) (2, 4)
Substitute y = 2x into x + y = 6: 3x = 6, so x = 2 and y = 4.

11. Two standard-form equations

Answer: B) (3, 5)
Add 2x − y = 1 and x + y = 8 to get 3x = 9, so x = 3. Then y = 5. Both original equations are satisfied.
03 · EXAM-STYLE PRACTICE

12. Study-room cost models

Answer: C) 6 hours
At the graph intersection the costs are equal: 15 + 4h = 27 + 2h. Then 2h = 12, so h = 6. Each model gives a cost of 39.

13. Measured relationships

Answer: C) 6
Set 1.5x + 3 = 0.5x + 9. Subtract 0.5x and 3 to get x = 6. Both lines then give y = 12.

14. Meaning of an intersection

Answer: C) The unique solution is (5, −2)
A point where both graphs meet satisfies both equations. Because there is exactly one intersection, (5, −2) is the system's unique ordered-pair solution.

15. Test-style graphical system

Answer: C) (8, 5)
Set −0.25x + 7 = 0.5x + 1. Then 6 = 0.75x, so x = 8. Substitution gives y = 5 in both equations.

16. Compare slopes before graphing

Answer: B) They are parallel and have no solution
The second line has slope (5 − (−1))/(3 − 0) = 2 and y-intercept −1, so its equation is y = 2x − 1. The first is y = 2x + 5. Equal slopes and different intercepts mean no intersection.
04 · CHALLENGE PROBLEMS

17. Exact-fraction intersection

Answer: C) (4, 1)
Set (3/4)x − 2 = −(1/2)x + 3. Then (5/4)x = 5, so x = 4. Substitution gives y = 1 in both equations.

18. Parameter from a known intersection

Answer: C) 1
The point (2, 6) must satisfy y = kx + 4. Substitute it: 6 = 2k + 4, so 2k = 2 and k = 1. The other line also checks: −2(2) + 10 = 6.
