Y-Intercept as Initial Value

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. What is the y-intercept of y = 3x + 7?

Answer: B) 7
The equation is already in y = mx + b form. The y-intercept is b = 7. Check by setting x = 0: y = 3(0) + 7 = 7.

2. Which point represents a y-intercept of −4?

Answer: B) (0, −4)
A y-intercept lies on the y-axis, so its x-coordinate must be 0. A y-intercept of −4 is therefore the point (0, −4).

3. For a linear function f, f(0) = 12. What is the initial value?

Answer: B) 12
The initial value is the function value when the input is 0. Since f(0) = 12, the initial value is 12.
02 · CORE PRACTICE

4. A linear function is given by y = −2x − 9. What is its y-intercept?

Answer: A) −9
In y = mx + b, the y-intercept is b. Here b = −9. Substituting x = 0 gives y = −9.

5. A line passes through (0, 6). What is the line's y-intercept?

Answer: B) 6
The point (0, 6) lies on the y-axis because x = 0. Therefore the line crosses the y-axis at y = 6.

6. The model C = 18 + 4h gives a cost C after h hours. What is the initial cost?

Answer: C) $18
The initial cost occurs at h = 0: C = 18 + 4(0) = 18. So the starting cost is $18.

7. What is the y-intercept of 4x + 2y = 10?

Answer: C) 5
At the y-intercept, x = 0. Then 4(0) + 2y = 10, so 2y = 10 and y = 5.

8. For f(x) = 7 − 3x, what is f(0)?

Answer: D) 7
Substitute x = 0: f(0) = 7 − 3(0) = 7.

9. A table contains the points (−2, 5), (0, −1), and (3, −10). What is the y-intercept?

Answer: C) −1
The y-intercept is the output paired with x = 0. The table includes (0, −1), so the y-intercept is −1.

10. The temperature model T = 22 − 1.5t gives T degrees after t hours. What temperature does the model give at t = 0?

Answer: C) 22°
Set t = 0: T = 22 − 1.5(0) = 22. The model starts at 22°.

11. Which statement correctly describes the y-intercept of a linear graph?

Answer: A) It is where x = 0.
Every point on the y-axis has x-coordinate 0. Therefore a graph's y-intercept occurs where x = 0.
03 · EXAM-STYLE PRACTICE

12. A savings account is modeled by A = 120 + 35w, where w is the number of weeks. What does 120 represent?

Answer: C) The starting amount
At w = 0, A = 120 + 35(0) = 120. So 120 is the amount in the account before any weeks have passed.

13. What is the y-intercept of 3x − y = 8?

Answer: A) −8
Set x = 0: 3(0) − y = 8, so −y = 8 and y = −8. Substitution checks: 0 − (−8) = 8.

14. A line crosses the y-axis at (0, −3). What is its initial value?

Answer: A) −3
The initial value is the y-value when x = 0. The given y-intercept is (0, −3), so the initial value is −3.

15. A taxi fare is modeled by F = 2.50m + 6.75, where m is miles traveled. What is the fare before any miles are traveled?

Answer: C) $6.75
Before any miles are traveled, m = 0. Then F = 2.50(0) + 6.75 = 6.75, so the initial fare is $6.75.

16. Which linear equation has y-intercept 4?

Answer: B) y = −5x + 4
In slope-intercept form y = mx + b, the y-intercept is b. Only y = −5x + 4 has b = 4.
04 · CHALLENGE PROBLEMS

17. For a linear function, f(0) = 2a − 3. If the initial value is 11, what is a?

Answer: B) 7
Set the initial-value expression equal to 11: 2a − 3 = 11. Add 3 to get 2a = 14, then divide by 2: a = 7. Check: 2(7) − 3 = 11.

18. The line 5x + 4y = 28 has what y-intercept?

Answer: C) 7
At the y-intercept, x = 0. Then 5(0) + 4y = 28, so 4y = 28 and y = 7.
