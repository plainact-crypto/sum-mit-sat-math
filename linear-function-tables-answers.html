01 · SKILL CHECK

1. Rate of change from (0, 2) and (2, 8)

Answer: A) 3
m = (8 − 2)/(2 − 0) = 6/2 = 3.

2. Decide whether the table is linear

Answer: A) Yes, because the slope is −2 in both intervals.
From (1, 5) to (3, 1), m = (1 − 5)/(3 − 1) = −4/2 = −2. From (3, 1) to (6, −5), m = (−5 − 1)/(6 − 3) = −6/3 = −2. The constant slope shows a linear function.

3. Equation through (0, −4) and (2, 2)

Answer: A) y = 3x − 4
The slope is (2 − (−4))/(2 − 0) = 6/2 = 3. Since x = 0 gives y = −4, the y-intercept is −4, so y = 3x − 4.
02 · CORE PRACTICE

4. Equation through (2, 7) and (5, 16)

Answer: A) y = 3x + 1
m = (16 − 7)/(5 − 2) = 9/3 = 3. Using (2, 7), 7 = 3(2) + b, so b = 1.

5. Slope from (−1, 6), (2, 0), and (5, −6)

Answer: A) −2
m = (0 − 6)/(2 − (−1)) = −6/3 = −2. Checking the next interval gives (−6 − 0)/(5 − 2) = −6/3 = −2.

6. Missing output k

Answer: A) 19
From (0, 5) to (4, 13), m = (13 − 5)/4 = 2. Moving from x = 4 to x = 7 increases x by 3, so y increases by 2(3) = 6. Thus k = 13 + 6 = 19.

7. Check whether the table is linear

Answer: A) It is not linear because the interval slopes are 2 and 7/3.
The first slope is (5 − 1)/(2 − 0) = 4/2 = 2. The second is (12 − 5)/(5 − 2) = 7/3. Because the slopes differ, the function is not linear.

8. Rate of change from the table

Answer: A) 2
Using (1, 2) and (4, 8), m = (8 − 2)/(4 − 1) = 6/3 = 2. The next interval gives (20 − 8)/(10 − 4) = 12/6 = 2, confirming the rate.

9. Equation through (−2, 9) and (2, 1)

Answer: A) y = −2x + 5
m = (1 − 9)/(2 − (−2)) = −8/4 = −2. Using (2, 1), 1 = −4 + b, so b = 5.

10. Find the y-intercept

Answer: A) 4
Use y = (1/2)x + b with (6, 7): 7 = (1/2)(6) + b = 3 + b, so b = 4.

11. Output when x = 10

Answer: A) 20
The slope from (3, −1) to (7, 11) is 12/4 = 3. Increasing x from 7 to 10 adds 3, so y increases by 3(3) = 9. Therefore y = 11 + 9 = 20.
03 · EXAM-STYLE PRACTICE

12. Linear service charge for 8 units

Answer: A) $42
The rate is (27 − 12)/(5 − 2) = 15/3 = $5 per unit. From 5 to 8 units is 3 more units, adding $15. The charge is $27 + $15 = $42.

13. Liters remaining at 7 minutes

Answer: A) 48 liters
The rate is (66 − 84)/(4 − 1) = −18/3 = −6 liters per minute. From minute 4 to minute 7 is 3 minutes, so the amount decreases by 18 liters: 66 − 18 = 48 liters.

14. Find the x-intercept

Answer: A) 15/2
The slope is (3 − 11)/(6 − 2) = −8/4 = −2. Using (2, 11), y = −2x + 15. At the x-intercept, y = 0, so 0 = −2x + 15 and x = 15/2.

15. Compare the rates of change

Answer: A) The two functions have the same rate of change, 2.
Table A has slope (10 − 4)/(3 − 0) = 6/3 = 2. Table B has slope (7 − (−1))/(5 − 1) = 8/4 = 2.

16. Missing input k

Answer: A) 7
From (1, 3) to (4, 12), the slope is 9/3 = 3. To reach y = 21 from y = 12 requires an increase of 9, which at rate 3 requires an x-increase of 3. Thus k = 4 + 3 = 7.
04 · CHALLENGE PROBLEMS

17. Hidden input a

Answer: A) 0
From (2, 10) to (6, 22), m = 12/4 = 3. The line is y = 3x + 4. Setting y = 4 gives 4 = 3a + 4, so a = 0.

18. Hidden input p

Answer: A) −2
From (2, 4) to (5, 13), m = 9/3 = 3. The line is y = 3x − 2. Setting y = −8 gives −8 = 3p − 2, so 3p = −6 and p = −2.
