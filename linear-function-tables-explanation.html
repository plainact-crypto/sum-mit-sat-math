Linear Function Tables
Algebra
01 · LESSON OBJECTIVE

Read a table as a linear rule.

By the end of this lesson, you should be able to recognize when a table represents a linear function, calculate its rate of change, find an equation, and use that equation to predict missing values.

constant Δy / Δx→linear function
02 · WHAT YOU NEED TO KNOW

A linear table changes at a constant rate.

When equal changes in x always produce equal changes in y, the ratio Δy/Δx is constant. That constant ratio is the slope. Once the slope is known, one ordered pair is enough to determine the full linear equation.

Input changeΔxHow much x changes between rows.
Output changeΔyHow much y changes between the same rows.
Rate of changem = Δy/ΔxThe slope of the linear function.
Equationy = mx + bUse a table point to find b.
03 · KEY DEFINITIONS

Ordered Pair

A matching input and output from one row of the table.

(x, y)

Constant Rate of Change

The same ratio of output change to input change across the table.

Δy/Δx = constant

Linear Function

A function whose graph is a straight line and whose slope is constant.

y = mx + b
04 · CORE RULE / FORMULA

Compare changes, not just the y-values.

m = (y₂ − y₁) / (x₂ − x₁)

If this slope is the same for every pair of rows, the table is linear. The x-values do not need to increase by 1; the ratio of the changes is what matters.

05 · HOW IT WORKS

Use a four-step process.

01
Choose two rowsTreat them as ordered pairs (x₁, y₁) and (x₂, y₂).
02
Find the slopeCalculate Δy/Δx using the same row order in numerator and denominator.
03
Check another intervalConfirm that the rate stays constant if the question asks whether the table is linear.
04
Find the ruleSubstitute the slope and one table point into y = mx + b to determine b.
06 · WORKED EXAMPLE 1 — CONSTANT STEP SIZE

A table contains (0, 3), (1, 7), (2, 11), and (3, 15). Is it linear, and what is the slope?

Δx = 1 each timeΔy = 4 each timem = 4/1 = 4

Yes. Equal input changes produce equal output changes, so the function is linear with slope 4.

07 · WORKED EXAMPLE 2 — UNEQUAL INPUT GAPS

Use the points (1, 5), (4, 11), and (10, 23). Show that the table is linear.

from x = 1 to x = 4: m = (11 − 5)/(4 − 1) = 6/3 = 2from x = 4 to x = 10: m = (23 − 11)/(10 − 4) = 12/6 = 2

The x-gaps are different, but the slope is 2 in both intervals. Therefore the table represents a linear function.

08 · WORKED EXAMPLE 3 — FIND THE EQUATION

A linear table contains (2, 9) and (5, 18). Find its equation.

m = (18 − 9)/(5 − 2) = 9/3 = 3y = 3x + b9 = 3(2) + b9 = 6 + b → b = 3y = 3x + 3
CheckAt x = 5, y = 3(5) + 3 = 18.
09 · WORKED EXAMPLE 4 — NEGATIVE RATE

A table contains (−2, 10), (1, 4), and (5, −4). Find the linear rule.

m = (4 − 10)/(1 − (−2)) = −6/3 = −2check: (−4 − 4)/(5 − 1) = −8/4 = −24 = −2(1) + b → b = 6y = −2x + 6
10 · WORKED EXAMPLE 5 — FIND A MISSING VALUE

A linear table contains (0, −1), (3, 5), and (7, k). Find k.

m = (5 − (−1))/(3 − 0) = 6/3 = 2because x = 0 gives y = −1, b = −1y = 2x − 1k = 2(7) − 1 = 13

The missing output is 13.

11 · WORKED EXAMPLE 6 — EXAM STYLE

A tank contains 68 liters at 2 minutes and 56 liters at 5 minutes. The amount changes linearly. How much is in the tank at 9 minutes?

m = (56 − 68)/(5 − 2) = −12/3 = −4 liters per minuteA = −4t + b68 = −4(2) + b → b = 76A(9) = −4(9) + 76 = 40
Exam connectionThe table values describe a rate. Keep the units attached to the slope: liters per minute.
12 · COMMON MISTAKES
Looking only at consecutive y-differences

Equal y-differences prove a constant rate only when the corresponding x-differences are also equal. Use Δy/Δx.

Mixing row order

If you calculate y₂ − y₁ in the numerator, use x₂ − x₁ in the denominator.

Assuming every table is linear

Check more than one interval when enough rows are provided.

Reading b from the wrong row

The y-intercept is the output when x = 0. If x = 0 is missing, calculate b from a known point.

13 · EXAM STRATEGY

Use the table to expose the rate first.

Start with two rows that make the arithmetic simple. Find the slope, verify it when needed, then decide whether the question asks for an equation, a missing value, or an interpretation of the rate.

table→slope → rule → requested value

15 · LESSON RECAP

A linear table is a straight-line rule written in rows.

  1. Pair each x-value with its matching y-value.
  2. Calculate slope using Δy/Δx.
  3. Check that the rate stays constant when needed.
  4. Use y = mx + b and one row to find the equation.
  5. Substitute into the equation to find missing or predicted values.
m = Δy/Δxy = mx + bb = y − mx
