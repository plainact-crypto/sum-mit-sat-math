Solving Graphically
Algebra
01 · LESSON OBJECTIVE

Find a system’s solution by locating where its graphs meet.

When two linear equations are graphed on the same coordinate plane, a point that lies on both lines satisfies both equations. For a system with one solution, that shared point is the intersection.

y = 2x + 1 and y = −x + 7→(2, 5)
02 · WHAT YOU NEED TO KNOW

A graphical solution is a common ordered pair.

Each line represents every ordered pair that satisfies one equation. The system asks for the ordered pair or pairs that satisfy both equations at the same time.

One intersectionone solutionThe lines cross once.
No intersectionno solutionDistinct parallel lines never meet.
Same lineinfinitely manyEvery point on the line satisfies both equations.
Always verifysubstituteCheck the coordinates in both original equations.
03 · KEY DEFINITIONS

System of Equations

Two or more equations considered together.

Intersection

A point shared by two graphs.

System Solution

An ordered pair that makes every equation in the system true.

04 · CORE RULE

The intersection is the solution because it belongs to both lines.

GRAPH BOTH → LOCATE THE INTERSECTION → READ (x, y) → VERIFY
05 · HOW IT WORKS

Use a reliable four-step routine.

01
Put both equations in graphable form.Solve for y when useful, or identify points and intercepts directly.
02
Graph both equations accurately.Use exact points whenever possible rather than estimating from a sketch.
03
Locate the shared point.Read x first, then y.
04
Verify the ordered pair.Substitute it into both original equations.
06 · WORKED EXAMPLE 1 — ONE INTERSECTION

Solve y = 2x + 1 and y = −x + 7 graphically.

The first line passes through (0,1), (1,3), and (2,5). The second passes through (0,7), (2,5), and (4,3). The shared point is (2,5).

Check5 = 2(2)+1 and 5 = −2+7, so (2,5) satisfies both equations.
07 · WORKED EXAMPLE 2 — STANDARD FORM TO GRAPH

Solve x + y = 6 and y = 2x.

x + y = 6 → y = −x + 6y = 2xshared point: (2, 4)
Check2+4=6 and 4=2(2).
08 · WORKED EXAMPLE 3 — NO SOLUTION

What do y = 4x + 1 and y = 4x − 6 show?

The lines have the same slope, 4, but different y-intercepts. They are distinct parallel lines, so they never intersect.

same slope + different intercepts→no solution
09 · WORKED EXAMPLE 4 — INFINITELY MANY SOLUTIONS

What do 2y = 6x + 4 and y = 3x + 2 show?

2y = 6x + 4y = 3x + 2

After dividing the first equation by 2, both equations are identical. Their graphs lie on top of each other, so every point on the line is a solution.

10 · WORKED EXAMPLE 5 — EXAM-STYLE MODEL

Two plans cost C = 15 + 4h and C = 27 + 2h. When are the costs equal?

On a graph of cost versus hours, equality occurs at the intersection. The two lines meet when h = 6, giving C = 39.

Verify the model15+4(6)=39 and 27+2(6)=39, so the intersection is (6,39).
11 · READING GRAPHS ACCURATELY

Do not let a rough picture replace exact mathematics.

If an intersection appears between grid marks, use the equations to confirm its exact coordinates. A graph is excellent for identifying and interpreting the solution, but the coordinates still must satisfy both equations.

Precision ruleNever round an intersection unless the question explicitly asks for an approximation.
12 · COMMON MISTAKES
Reading y before x

Ordered pairs are written (x, y). Read the horizontal coordinate first.

Using a point on only one line

A system solution must lie on both graphs.

Assuming every system has one solution

Parallel lines give no solution; coincident lines give infinitely many.

Trusting a rough sketch

Verify the coordinates in both original equations.

13 · EXAM STRATEGY

Use the graph for meaning; use algebra for exactness when needed.

If the equations graph cleanly, the intersection can be the fastest route. If the graph gives a hard-to-read fractional intersection, solve algebraically or use Desmos to identify the exact common point, then verify it.

15 · LESSON RECAP

Graphs turn a system into a question about shared points.

  1. Graph both equations on the same axes.
  2. Find the point or pattern they share.
  3. One crossing means one solution; no crossing means no solution; the same line means infinitely many solutions.
  4. Read coordinates in (x, y) order.
  5. Verify exact coordinates in both equations.
