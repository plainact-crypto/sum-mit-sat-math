Literal Equations

01 · LESSON OBJECTIVE

Rearrange a formula to isolate the variable you need.

By the end of this lesson, you should be able to solve literal equations for a specified variable by treating every other letter as a known quantity and using the same inverse-operation rules you use in ordinary linear equations.

A = lw→ solve for w →w = A / l
02 · WHAT YOU NEED TO KNOW

More letters do not mean new algebra.

A literal equation contains two or more variables, usually because it represents a general relationship or formula. When a problem asks you to solve for one variable, that variable becomes the target. Treat the remaining letters exactly like constants and undo operations until the target stands alone.

TargetChoose one variableKnow exactly which letter must be isolated.
Other lettersTreat as constantsDo not try to solve for every variable.
BalanceSame operationApply equivalent operations to both sides.
GoalVariable aloneThe final expression should isolate the requested variable.
03 · KEY DEFINITIONS

Literal Equation

An equation involving two or more variables.

A = lw

Formula

A literal equation describing a relationship between quantities.

d = rt

Target Variable

The variable the problem asks you to isolate.

solve A = lw for w

Equivalent Equation

An equation with the same relationship written in a different form.

d = rt ↔ t = d/r
04 · CORE RULE

Move everything away from the target variable using inverse operations.

IDENTIFY TARGET → UNDO OPERATIONS → ISOLATE
05 · HOW IT WORKS

A reliable four-step process

01
Identify the target variable.Circle or mentally mark the letter you need to isolate.
02
Read the operations around it.Notice multiplication, division, addition, subtraction, or grouping.
03
Undo in reverse order.Use inverse operations while preserving equality.
04
Check the structure.Substitute the rearranged expression back into the original formula when useful.
06 · WORKED EXAMPLE 1 — BASIC

Solve A = lw for w.

  1. Target w.w is multiplied by l.
  2. Divide both sides by l.A / l = w
  3. Write the target first.w = A / l
Structure checkl(A/l) = A ✓
07 · WORKED EXAMPLE 2 — TWO TERMS

Solve P = 2l + 2w for w.

P − 2l = 2w(P − 2l) / 2 = ww = (P − 2l) / 2

Order matters: Remove the term not containing w first, then undo the multiplication by 2.

08 · WORKED EXAMPLE 3 — VARIABLE IN A LINEAR FORMULA

Solve y = mx + b for m.

y − b = mx(y − b) / x = mm = (y − b) / x

Condition: This rearrangement requires x ≠ 0 because division by zero is undefined.

09 · WORKED EXAMPLE 4 — FRACTION COEFFICIENT

Solve C = (5/9)(F − 32) for F.

(9/5)C = F − 32(9/5)C + 32 = FF = (9/5)C + 32
Check the reversalSubtract 32, then multiply by 5/9 to return to C ✓
10 · WORKED EXAMPLE 5 — EXAM STYLE

The volume of a rectangular prism is V = lwh. Solve the formula for height h.

V = lwhV / (lw) = hh = V / (lw)
Exam connectionSchool and exam problems often give a familiar formula and then ask for a different quantity. Rearranging symbolically first can make the substitution step much cleaner.
11 · RECOGNIZE GROUPS BEFORE DISTRIBUTING

Do not expand unless expansion helps.

If the target variable sits inside a grouped expression, it is often faster to undo the outside operation first. In C = (5/9)(F − 32), multiplying by 9/5 immediately isolates the group F − 32. Unnecessary distribution creates extra arithmetic and more chances for sign errors.

C = (5/9)(F − 32)→(9/5)C = F − 32

12 · COMMON MISTAKES
Solving for the wrong variable

Literal equations may contain many letters. Keep the requested target variable in view.

Moving terms without equivalent operations

Do not simply “move” a term. Use addition, subtraction, multiplication, or division on both sides.

Dividing only part of an expression

From P − 2l = 2w, divide the entire left side by 2: w = (P − 2l)/2.

Ignoring restrictions

If your rearrangement divides by a variable expression, that denominator cannot equal zero.

13 · EXAM STRATEGY

Rearrange first when the same formula will be reused.

If values are messy, isolate the target symbolically before substituting numbers. This separates algebra from arithmetic, exposes the structure, and often reduces calculator mistakes.

d = rt→ solve for t →t = d / r

15 · LESSON RECAP

Literal equations use the same balancing rules as ordinary equations.

  1. Identify the variable you must isolate.
  2. Treat every other letter as a constant.
  3. Undo operations around the target in a sensible order.
  4. Keep grouped expressions intact when that makes the algebra cleaner.
  5. Watch for denominators that cannot equal zero.
  6. Check that substituting your rearranged expression preserves the original formula.
