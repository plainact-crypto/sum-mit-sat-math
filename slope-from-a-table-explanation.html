Slope from a Table
Algebra
01 · LESSON OBJECTIVE

Find slope from values in a table.

By the end of this lesson, you should be able to choose two points from a table, calculate the changes in y and x, find the slope, and interpret what that slope means.

change in y ÷ change in x→m = Δy/Δx
02 · WHAT YOU NEED TO KNOW

Each row of an x-y table represents a point.

If a table shows x and y values for a linear relationship, use any two different rows. Subtract the y-values in the same order that you subtract the x-values. The ratio of those changes is the slope.

First row(x₁, y₁)One point on the line.
Second row(x₂, y₂)A different point on the line.
Vertical changeΔy = y₂ − y₁Change in output.
Horizontal changeΔx = x₂ − x₁Change in input.
03 · KEY DEFINITIONS

Slope

The rate at which y changes compared with x.

m = Δy/Δx

Rate of Change

How much one quantity changes for each unit of another quantity.

change in output / change in input

Constant Slope

A linear relationship has the same slope between every pair of points.

same Δy/Δx
04 · CORE RULE / FORMULA

Subtract in matching order.

m = (y₂ − y₁) / (x₂ − x₁)

If you calculate y₂ − y₁ in the numerator, you must calculate x₂ − x₁ in the denominator. Reversing both differences gives the same slope.

05 · HOW IT WORKS

Use a four-step table method.

01
Choose two rowsTreat them as two points, (x₁, y₁) and (x₂, y₂).
02
Find ΔySubtract the y-values.
03
Find ΔxSubtract the matching x-values in the same order.
04
Divide and simplifyCompute Δy/Δx and reduce the fraction if needed.
06 · WORKED EXAMPLE 1 — BASIC

Find the slope from the table.

x: 1, 2, 3y: 4, 7, 10Δy = 7 − 4 = 3Δx = 2 − 1 = 1m = 3/1 = 3
Check another pair(10 − 7)/(3 − 2) = 3 ✓
07 · WORKED EXAMPLE 2 — NON-UNIT X CHANGES

Find the slope when x increases by more than 1.

x: 0, 4, 8y: 10, 18, 26Δy = 18 − 10 = 8Δx = 4 − 0 = 4m = 8/4 = 2

Important: Do not use only the change in y. Slope compares the change in y with the change in x.

08 · WORKED EXAMPLE 3 — NEGATIVE SLOPE

Find the slope of the relationship.

x: −2, 1, 4y: 11, 5, −1Δy = 5 − 11 = −6Δx = 1 − (−2) = 3m = −6/3 = −2

A negative slope means y decreases as x increases.

09 · WORKED EXAMPLE 4 — FRACTIONAL SLOPE

Find and simplify the slope.

x: 2, 6, 10y: 7, 5, 3Δy = 5 − 7 = −2Δx = 6 − 2 = 4m = −2/4 = −1/2
Check(3 − 5)/(10 − 6) = −2/4 = −1/2 ✓
10 · WORKED EXAMPLE 5 — EXAM STYLE

A table shows the distance remaining on a trip.

time (hours): 0, 3, 6distance remaining (km): 42, 30, 18Δdistance = 30 − 42 = −12 kmΔtime = 3 − 0 = 3 hm = −12/3 = −4 km/h
InterpretationThe distance remaining decreases by 4 kilometers for each hour.
11 · WORKED EXAMPLE 6 — CHECKING CONSTANT SLOPE

Does this table show a constant slope?

x: 0, 2, 4, 6y: 1, 5, 9, 14first slope = (5 − 1)/(2 − 0) = 2next slope = (9 − 5)/(4 − 2) = 2last slope = (14 − 9)/(6 − 4) = 5/2

Conclusion: The slopes are not all equal, so the table does not represent one linear relationship with constant slope.

12 · COMMON MISTAKES
Using y-change only

Slope is not just Δy. Always divide by the matching Δx.

Subtracting in opposite orders

If the numerator uses y₂ − y₁, the denominator must use x₂ − x₁.

Assuming consecutive rows mean Δx = 1

Read the x-values. They may increase by 2, 4, 0.5, or another amount.

Dropping a negative sign

If y decreases while x increases, the slope is negative.

13 · EXAM STRATEGY

Choose the cleanest pair of rows.

You do not have to use the first two rows. For a linear table, any two distinct points give the same slope. Pick values that make the subtraction easy, keep the subtraction order consistent, and simplify the final ratio.

Δy = −9, Δx = 3→m = −3

15 · LESSON RECAP

A table gives you the two changes needed for slope.

  1. Each row is an ordered pair (x, y).
  2. Choose two different rows.
  3. Calculate Δy and Δx in matching order.
  4. Divide: m = Δy/Δx.
  5. For a linear relationship, the slope stays constant across the table.
Δy = y₂ − y₁Δx = x₂ − x₁m = Δy/Δx
