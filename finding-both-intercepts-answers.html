Finding Both Intercepts

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. What are the x- and y-intercepts of x + y = 10?

Answer: A) (10, 0) and (0, 10)
For the x-intercept, set y = 0: x = 10. For the y-intercept, set x = 0: y = 10.

2. What are the intercepts of 2x + 3y = 12?

Answer: B) (6, 0) and (0, 4)
Set y = 0: 2x = 12, so x = 6. Set x = 0: 3y = 12, so y = 4.

3. For y = −3x + 9, what are the intercepts?

Answer: B) (3, 0) and (0, 9)
Set y = 0: 0 = −3x + 9, so x = 3. Set x = 0: y = 9.
02 · CORE PRACTICE

4. Find both intercepts of 4x + 5y = 20.

Answer: B) (5, 0) and (0, 4)
With y = 0, 4x = 20 so x = 5. With x = 0, 5y = 20 so y = 4.

5. Find both intercepts of 3x − 2y = 18.

Answer: A) (6, 0) and (0, −9)
Set y = 0: 3x = 18, so x = 6. Set x = 0: −2y = 18, so y = −9.

6. Find both intercepts of y = (1/2)x − 4.

Answer: B) (8, 0) and (0, −4)
Set y = 0: (1/2)x = 4, so x = 8. Set x = 0: y = −4.

7. Find both intercepts of 6x + 8y = 24.

Answer: B) (4, 0) and (0, 3)
Set y = 0: 6x = 24, so x = 4. Set x = 0: 8y = 24, so y = 3.

8. Find both intercepts of 10x − 4y = 15.

Answer: A) (3/2, 0) and (0, −15/4)
Set y = 0: 10x = 15, so x = 3/2. Set x = 0: −4y = 15, so y = −15/4.

9. Which statement is true for the horizontal line y = 7?

Answer: B) It has no x-intercept and y-intercept (0, 7)
The line stays at y = 7, so it never reaches y = 0. At x = 0 it passes through (0, 7).

10. Which statement is true for the vertical line x = −5?

Answer: A) It has x-intercept (−5, 0) and no y-intercept
The line includes (−5, 0), so that is its x-intercept. Because x is always −5, it never reaches the y-axis x = 0.

11. For the line y = 2x, what are the x- and y-intercepts?

Answer: B) Both are (0, 0)
Setting y = 0 gives x = 0, and setting x = 0 gives y = 0. Both axes are crossed at the origin.
03 · SAT-STYLE PRACTICE

12. The line 5x + 4y = 40 represents combinations of two item types that use all available resources. What are its intercepts?

Answer: A) (8, 0) and (0, 10)
Set y = 0: 5x = 40, so x = 8. Set x = 0: 4y = 40, so y = 10.

13. A budget model is 6x + 3y = 54. If the intercepts represent buying only one item type at a time, what are they?

Answer: B) (9, 0) and (0, 18)
With y = 0, 6x = 54 so x = 9. With x = 0, 3y = 54 so y = 18.

14. The equation 2y = 16 − 4x represents a line. What are its intercepts?

Answer: A) (4, 0) and (0, 8)
Set y = 0: 0 = 16 − 4x, so x = 4. Set x = 0: 2y = 16, so y = 8.

15. A line is modeled by Ax + 6y = 30, where A = 3. What are its intercepts?

Answer: B) (10, 0) and (0, 5)
Substitute A = 3 to get 3x + 6y = 30. Then y = 0 gives x = 10, while x = 0 gives y = 5.

16. A company model is 12x + 8y = 48. Which pair gives the maximum x-value when y = 0 and the maximum y-value when x = 0?

Answer: B) x = 4, y = 6
At y = 0, 12x = 48 so x = 4. At x = 0, 8y = 48 so y = 6.
04 · CHALLENGE PROBLEMS

17. The line kx + 4y = 24 has x-intercept (3, 0) and y-intercept (0, 6). What is k?

Answer: C) 8
Use the x-intercept (3, 0): 3k + 4(0) = 24, so 3k = 24 and k = 8. The y-intercept also checks: 4(6) = 24.

18. A line has intercepts (−6, 0) and (0, 3). Which equation represents the line?

Answer: A) x − 2y = −6
Check both given points. At (−6, 0), −6 − 0 = −6. At (0, 3), 0 − 6 = −6. Both satisfy the equation.
