Collinear Points
Algebra
01 · LESSON OBJECTIVE

Determine whether points lie on one straight line.

By the end of this lesson, you should be able to test whether three or more points are collinear by comparing slopes, using a linear equation, or recognizing a constant rate of change.

(1, 3), (3, 7), (5, 11)→same line
02 · WHAT YOU NEED TO KNOW

Collinear points share one straight line.

If three points lie on the same nonvertical line, the slope between any pair of consecutive points is the same. For a vertical line, every point has the same x-coordinate.

Nonvertical testm₁ = m₂Equal pairwise slopes indicate one line.
Slope formula(y₂−y₁)/(x₂−x₁)Keep subtraction order consistent.
Vertical casex = constantSame x-coordinate means the points are vertically aligned.
Equation testSubstituteEvery point must satisfy the same linear equation.
03 · KEY DEFINITIONS

Collinear

Points that lie on the same straight line.

one line

Slope

The change in y divided by the change in x.

m = Δy/Δx

Linear Equation

An equation whose graph is a straight line.

y = mx + b
04 · CORE RULE / FORMULA

Compare slopes using the same subtraction order.

m_AB = m_BC

For points A, B, and C with nonvertical pairwise segments, equal slopes confirm collinearity.

05 · HOW IT WORKS

Use a four-step process.

01
Choose two pairsFor three points, AB and BC are usually convenient.
02
Calculate each slopeUse the same order in numerator and denominator.
03
Compare exactlySimplify fractions before deciding.
04
Handle vertical lines separatelyIf all x-values are equal, the points are collinear.
06 · WORKED EXAMPLE 1 — EQUAL SLOPES

Are (1, 3), (3, 7), and (5, 11) collinear?

m₁ = (7−3)/(3−1) = 4/2 = 2m₂ = (11−7)/(5−3) = 4/2 = 2m₁ = m₂

Yes. The slopes are equal, so the three points lie on one straight line.

07 · WORKED EXAMPLE 2 — NOT COLLINEAR

Are (0, 2), (2, 6), and (5, 9) collinear?

m₁ = (6−2)/(2−0) = 4/2 = 2m₂ = (9−6)/(5−2) = 3/3 = 12 ≠ 1

No. Different slopes mean the direction changes.

08 · WORKED EXAMPLE 3 — FRACTIONAL SLOPE

Are (−2, 5), (1, 3), and (4, 1) collinear?

m₁ = (3−5)/(1−(−2)) = −2/3m₂ = (1−3)/(4−1) = −2/3m₁ = m₂ = −2/3

Yes. Exact fraction comparison confirms the points are collinear.

09 · WORKED EXAMPLE 4 — VERTICAL LINE

Are (4, −3), (4, 2), and (4, 10) collinear?

x = 4 for every pointall three points lie on x = 4

Yes. Their slopes are undefined, but all three points lie on the same vertical line.

10 · WORKED EXAMPLE 5 — USE AN EQUATION

Do (1, 4), (2, 7), and (5, 16) lie on y = 3x + 1?

3(1)+1 = 43(2)+1 = 73(5)+1 = 16

Yes. Every point satisfies the same linear equation, so the points are collinear.

11 · WORKED EXAMPLE 6 — EXAM STYLE

Points A(2, 5), B(6, 13), and C(k, 21) are collinear. Find k.

m_AB = (13−5)/(6−2) = 8/4 = 2m_BC = (21−13)/(k−6) = 8/(k−6)8/(k−6) = 28 = 2k − 1220 = 2k → k = 10
CheckFrom B(6,13) to C(10,21), slope = 8/4 = 2.
12 · COMMON MISTAKES
Reversing only one subtraction

If you write y₂−y₁, also write x₂−x₁ in the denominator.

Comparing unsimplified values carelessly

Fractions such as 2/3 and 4/6 are equal after simplification.

Declaring vertical points impossible

Undefined slope does not mean noncollinear; equal x-values can form one vertical line.

Checking only two of three points

Any two points define a line. The additional point is what must be verified.

13 · EXAM STRATEGY

Use the shortest reliable test.

If coordinates are given, compare two slopes. If a line equation is already provided, substitution can be faster. For a vertical pattern, compare x-coordinates directly.

same line?→same slope or same x

15 · LESSON RECAP

One straight line means one consistent direction.

  1. Use two pairwise slopes for nonvertical points.
  2. Keep subtraction order consistent.
  3. Simplify fractions exactly before comparing.
  4. For vertical lines, check for one common x-coordinate.
  5. You can also verify that every point satisfies one linear equation.
m = (y₂−y₁)/(x₂−x₁)m_AB = m_BCx = constant
