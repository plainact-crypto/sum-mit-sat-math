Graphing Systems of Inequalities
Algebra
01 · LESSON OBJECTIVE

Graph every inequality, then keep only the overlap.

By the end of this lesson, you should be able to graph a system of two linear inequalities, choose the correct boundary style for each one, shade each solution half-plane, and identify the common region that satisfies both inequalities.

solution to inequality 1∩solution to inequality 2 = system solution
02 · CORE IDEA

A system means every condition must be true at the same time.

Each linear inequality describes a half-plane. When two inequalities form a system, the answer is not both shaded regions separately. The solution set is their intersection: the region where the shading overlaps.

Step 1Graph each boundaryReplace each inequality symbol with =.
Step 2Choose solid or dashedUse solid for ≤ or ≥ and dashed for < or >.
Step 3Shade each inequalityUse the solved form or a test point to choose the correct side.
Step 4Keep the overlapOnly points satisfying every inequality belong to the system.
03 · BOUNDARY RULES

Line style tells you whether equality is allowed.

Inclusive boundary

For ≤ or ≥, points on the boundary are solutions.

solid line

Strict boundary

For < or >, points on the boundary are excluded.

dashed line

Overlap

The set of ordered pairs that make all inequalities true.

solution region
04 · WORKED EXAMPLE — TWO SOLID BOUNDARIES

Graph the system: y ≥ x − 1 and y ≤ −x + 5.

  1. Graph the first boundary.Use y = x − 1. Because ≥ includes equality, draw a solid line and shade above it.
  2. Graph the second boundary.Use y = −x + 5. Because ≤ includes equality, draw a solid line and shade below it.
  3. Find the common region.The system solution is where those two shaded half-planes overlap.
  4. Check an overlap point.At (0,0): 0 ≥ −1 and 0 ≤ 5, so (0,0) belongs to the solution region.
Boundary intersectionSet x − 1 = −x + 5. Then 2x = 6, so x = 3 and y = 2. The point (3,2) lies on both solid boundaries and is included in the system.
05 · STRICT BOUNDARIES

What changes for y > 2x − 3 and y < −x + 6?

Both boundaries are dashed because neither inequality includes equality. Shade above y = 2x − 3 and below y = −x + 6. The overlap between those regions is the solution set, but points on either boundary are excluded.

Quick verificationThe point (1,1) works because 1>−1 and 1<5. A point on either boundary does not satisfy the corresponding strict inequality.
06 · TESTING A CANDIDATE POINT

A point is a solution only if it passes every inequality.

For the system y ≥ x − 1 and y ≤ −x + 5, test (2,2): 2 ≥ 1 and 2 ≤ 3, so it is a solution. Test (4,0): the first inequality becomes 0 ≥ 3, which is false, so (4,0) is not a solution even though it satisfies the second inequality.

07 · WHEN THERE IS NO OVERLAP

Some systems have no solution region.

Consider y > x + 3 and y < x − 1. The first requires points above a line that is always 4 units higher than the second line, while the second requires points below the lower line. No point can do both, so the system has no solution.

08 · READING THE GRAPH

Use the overlap to answer test-style questions efficiently.

If a question asks whether a point is in the system, you may read the graph first and then substitute to verify. If it asks for the entire solution set, describe or select the common shaded region and pay attention to whether each boundary is included.

09 · COMMON MISTAKES
Keeping both shaded regions instead of their overlap

A system uses AND: every inequality must be true.

Using the wrong boundary style

Strict inequalities use dashed lines; inclusive inequalities use solid lines.

Shading the same side automatically

Each inequality must be handled independently before you look for the overlap.

Testing a point against only one inequality

A candidate point must satisfy all inequalities in the system.

10 · EXAM STRATEGY

Graph cleanly, then verify one point in the overlap.

On an exam-style graphing question, convert each inequality to a clear boundary form, mark solid or dashed before shading, and use one easy test point when the shading direction is uncertain. After both inequalities are graphed, ignore every singly shaded area and keep only the common region.

boundary → line style → shade→overlap → verify

12 · LESSON RECAP

The system solution is the common shaded region.

  1. Turn each inequality into its boundary equation.
  2. Use solid for ≤ or ≥ and dashed for < or >.
  3. Shade the solution side of each inequality.
  4. Keep only the region where all shadings overlap.
  5. Verify important points by substitution.
