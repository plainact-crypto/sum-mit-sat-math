## Independent math cross-check

The visual/tool example uses the equivalent equations `2x + y = 7` and `y = -2x + 7`.

Three required linear substitutions were checked independently:
- `x = 0` gives `y = 7`; standard form check: `2(0) + 7 = 7`.
- `x = 1` gives `y = 5`; standard form check: `2(1) + 5 = 7`.
- `x = 2` gives `y = 3`; standard form check: `2(2) + 3 = 7`.

Therefore both forms contain the verified points `(0,7)`, `(1,5)`, `(2,3)` and describe the same line with slope `-2` and y-intercept `7`.

Additional lesson examples checked:
- `3x + 2y = 14` rearranges to `y = -(3/2)x + 7`.
- `y = 4x - 9` is equivalent to `4x - y = 9`.
- `y - 5 = 2(x - 3)` rearranges to `y = 2x - 1`, and `(3,5)` satisfies it.
- `2x + y = 8` through `(2,4)` has slope `-2`, so `y - 4 = -2(x - 2)`.
- `6x + 3y = 24` rearranges to `y = -2x + 8`, so the slope is `-2`.
