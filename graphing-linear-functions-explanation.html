Graphing Linear Functions
Algebra
01 · LESSON OBJECTIVE

Turn a linear rule into a straight-line graph.

By the end of this lesson, you should be able to graph a linear function from an equation, identify the slope and y-intercept, generate reliable points, and check whether a plotted line matches the rule.

y = mx + b→start at b, move by m
02 · WHAT YOU NEED TO KNOW

A linear graph is built from a starting value and a constant rate.

In slope-intercept form, y = mx + b, the y-intercept b tells you where the line crosses the y-axis. The slope m tells you how y changes when x changes. Because the rate is constant, every point generated by the equation lies on one straight line.

SlopemRise divided by run.
Y-interceptbThe point (0, b).
Positive slopem > 0The line rises left to right.
Negative slopem < 0The line falls left to right.
03 · KEY DEFINITIONS

Slope

The constant rate of change of y with respect to x.

m = Δy / Δx

Y-Intercept

The point where the graph crosses the y-axis.

(0, b)

Linear Function

A function whose graph is a straight line.

y = mx + b
04 · CORE RULE / FORMULA

Plot the intercept, then use the slope as a movement.

slope = rise / run

For m = 3/2, move right 2 and up 3. For m = −3/2, move right 2 and down 3. Any equivalent rise/run pair produces another point on the same line.

05 · HOW IT WORKS

Use a four-step graphing process.

01
Write or recognize y = mx + bIdentify m and b before plotting.
02
Plot the y-interceptMark (0, b) on the y-axis.
03
Use the slopeFrom the intercept, move by rise/run to locate a second point.
04
Draw and verifyDraw the straight line and substitute a plotted point into the equation if needed.
06 · WORKED EXAMPLE 1 — INTEGER SLOPE

Graph y = 2x + 1.

b = 1 → plot (0, 1)m = 2 = 2/1 → right 1, up 2second point: (1, 3)third point: (2, 5)
CheckAt x = 2, y = 2(2) + 1 = 5, so (2, 5) is on the line.
07 · WORKED EXAMPLE 2 — NEGATIVE SLOPE

Graph y = −3x + 4.

b = 4 → plot (0, 4)m = −3 = −3/1 → right 1, down 3second point: (1, 1)third point: (2, −2)

The line falls from left to right because the slope is negative.

08 · WORKED EXAMPLE 3 — FRACTIONAL SLOPE

Graph y = (2/3)x − 2.

b = −2 → plot (0, −2)m = 2/3 → right 3, up 2second point: (3, 0)third point: (6, 2)

Using a run of 3 keeps the plotted coordinates as integers.

09 · WORKED EXAMPLE 4 — EQUATION NOT YET SOLVED FOR y

Graph 2x + y = 6.

y = −2x + 6b = 6 → plot (0, 6)m = −2 → right 1, down 2another point: (1, 4)

Rewrite the equation first so the slope and y-intercept are visible.

12 · COMMON MISTAKES
Plotting b on the x-axis

The y-intercept is always on the y-axis because x = 0 there.

Reversing rise and run

For m = 2/3, change y by 2 while x changes by 3, not the other way around.

Ignoring the sign of the slope

A negative slope can be shown by moving right and down, or left and up.

Using only one point

One point does not determine a unique line. Plot at least two reliable points before drawing.

13 · EXAM STRATEGY

Read the equation before you read the graph.

Identify the sign and size of the slope and locate the y-intercept first. This lets you reject impossible graphs quickly. Then test one additional point or use the rise/run pattern to confirm the correct line.

equation→intercept + direction + steepness

15 · LESSON RECAP

A linear equation gives you everything needed to draw its line.

  1. Put the equation in a useful form such as y = mx + b.
  2. Plot the y-intercept (0, b).
  3. Interpret slope as rise/run.
  4. Plot at least one more point.
  5. Draw the straight line and verify a point when needed.
