Perpendicular Lines

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Perpendicular to y = 3x − 4

Answer: A) −1/3
The given slope is 3. A perpendicular nonvertical line has the negative reciprocal slope, so m = −1/3.

2. Perpendicular to 2x + 5y = 10

Answer: A) 5x − 2y = 7
Rewrite the given line as y = −(2/5)x + 2, so its slope is −2/5. The perpendicular slope is 5/2. Rewriting 5x − 2y = 7 gives y = (5/2)x − 7/2.

3. Perpendicular point-pair line

Answer: A) (0, 3) and (4, 1)
The slope through (1, 2) and (4, 8) is (8 − 2)/(4 − 1) = 6/3 = 2. A perpendicular slope is −1/2. The slope through (0, 3) and (4, 1) is (1 − 3)/(4 − 0) = −2/4 = −1/2.
02 · CORE PRACTICE

4. Perpendicular to y = −4x + 7 through (2, 1)

Answer: A) y = (1/4)x + 1/2
The perpendicular slope to −4 is 1/4. Using y = (1/4)x + b and (2, 1): 1 = 1/2 + b, so b = 1/2.

5. Perpendicular to 3x − 2y = 8 through (−2, 5)

Answer: A) 2x + 3y = 11
The given line has slope 3/2, so a perpendicular line has slope −2/3. Using point-slope form through (−2, 5) gives y − 5 = −(2/3)(x + 2), which simplifies to 2x + 3y = 11.

6. Compare y = (1/3)x + 2 and 3x + y = 9

Answer: A) Yes, their slopes are negative reciprocals.
The first slope is 1/3. Rewriting 3x + y = 9 gives y = −3x + 9, so the second slope is −3. Their product is −1.

7. Find k for perpendicular point-pair lines

Answer: A) 1
The first slope is (9 − 1)/(4 − 0) = 8/4 = 2. A perpendicular slope is −1/2. Thus (k − 3)/(6 − 2) = −1/2, so k − 3 = −2 and k = 1.

8. Find p for a line perpendicular to 5x + y = 7

Answer: A) 22/5
The line 5x + y = 7 has slope −5, so the perpendicular slope is 1/5. Then (p − 4)/(3 − 1) = 1/5, so p − 4 = 2/5 and p = 22/5.

9. Perpendicular to the horizontal line y = 6

Answer: A) x = 4
A line perpendicular to a horizontal line is vertical. The vertical line through (4, −2) is x = 4.

10. Perpendicular to the vertical line x = 3

Answer: A) y = 7
A line perpendicular to a vertical line is horizontal. The horizontal line through (−5, 7) is y = 7.

11. Perpendicular to 2x + 4y = 12

Answer: A) y = 2x − 3
Rewrite the given line as y = −(1/2)x + 3. Its perpendicular slope is 2, and only y = 2x − 3 has slope 2.
03 · EXAM-STYLE PRACTICE

12. Perpendicular delivery-cost model

Answer: A) C = −0.4d + 16.6
The original slope is 2.5 = 5/2, so the perpendicular slope is −2/5 = −0.4. Use C = −0.4d + b and (4, 15): 15 = −1.6 + b, so b = 16.6.

13. Perpendicular path through (1, 6)

Answer: A) y = 2x + 4
The first path has slope (−2 − 2)/(5 − (−3)) = −4/8 = −1/2. The perpendicular slope is 2. Through (1, 6), y = 2x + b gives 6 = 2 + b, so b = 4.

14. Find k for perpendicular standard-form lines

Answer: A) 8/3
The slopes are −k/4 and 3/2. Perpendicular slopes multiply to −1: (−k/4)(3/2) = −1. Therefore 3k/8 = 1 and k = 8/3.

15. Point pair perpendicular to Line A

Answer: A) (0, 5) and (7, 3)
Line A has slope (11 − 4)/(2 − 0) = 7/2. Its perpendicular slope is −2/7. The slope from (0, 5) to (7, 3) is (3 − 5)/(7 − 0) = −2/7.

16. Find a in y = (a − 1)x + 4

Answer: A) 4/5
A line perpendicular to slope 5 has slope −1/5. Set a − 1 = −1/5, so a = 1 − 1/5 = 4/5.
04 · CHALLENGE PROBLEMS

17. Hidden coordinate a

Answer: A) 50/3
A line perpendicular to slope 4/3 has slope −3/4. For (a, 2) and (6, 10), 8/(6 − a) = −3/4. Cross-multiplying gives 32 = −18 + 3a, so 3a = 50 and a = 50/3.

18. Find q for perpendicular standard-form lines

Answer: A) −2
The first line has slope −3/6 = −1/2. The second has slope −4/q. Their product must be −1: (−1/2)(−4/q) = −1. Thus 2/q = −1, so q = −2.
