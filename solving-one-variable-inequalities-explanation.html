Solving One-Variable Inequalities
Algebra
01 · LESSON OBJECTIVE

Solve inequalities and describe every value that makes them true.

An equation usually asks for one exact value. An inequality often describes a whole set of values. The algebra looks familiar, but the final answer is a range rather than a single number.

3x + 5 < 20→x < 5
02 · WHAT YOU NEED TO KNOW

Use inverse operations while keeping equivalent solution sets.

Add or subtract the same number on both sides exactly as you would in an equation. Multiply or divide by a positive number without changing the inequality direction. A separate lesson covers the special sign-reversal rule for negative multiplication or division.

Less thanx < aValues smaller than a.
Greater thanx > aValues larger than a.
At mostx ≤ aa is included.
At leastx ≥ aa is included.
03 · KEY IDEA

A solution to an inequality is any value that makes the comparison true.

For x < 5, values such as 4, 0, and −100 work. The value 5 does not work because the inequality is strict, and 6 does not work because it is too large.

Boundary checkFor x < 5, substituting x=5 gives 5<5, which is false. For x≤5, substituting x=5 gives 5≤5, which is true.
04 · CORE RULE

Isolate the variable and preserve the truth of the comparison.

SAME OPERATION ON BOTH SIDES
05 · WORKED EXAMPLE 1 — TWO STEPS

Solve 3x + 5 < 20.

  1. Subtract 5 from both sides.3x < 15
  2. Divide both sides by positive 3.x < 5
  3. Check a value from the solution set.Use x=4: 3(4)+5=17, and 17<20 is true.
Boundary checkAt x=5, the original statement becomes 20<20, which is false, so 5 is not included.
06 · WORKED EXAMPLE 2 — VARIABLE ON BOTH SIDES

Solve 5x + 2 ≥ 2x + 14.

5x + 2 ≥ 2x + 143x + 2 ≥ 143x ≥ 12x ≥ 4
Checkx=4 gives 22≥22, true. x=3 gives 17≥20, false, confirming the boundary.
07 · WORKED EXAMPLE 3 — DISTRIBUTION

Solve 2(x + 3) ≤ 18.

2x + 6 ≤ 182x ≤ 12x ≤ 6

Efficiency: You could also divide both sides by 2 first to get x+3≤9, then subtract 3.

08 · WORKED EXAMPLE 4 — FRACTION COEFFICIENT

Solve x/4 − 3 > 2.

x/4 > 5x > 20
Checkx=24 gives 24/4−3=3, and 3>2 is true. The boundary x=20 gives 2>2, false.
09 · WORKED EXAMPLE 5 — EXAM-STYLE CONTEXT

A student has $48 and wants to spend at most $6 per notebook while keeping at least $12. What is the greatest number n of notebooks they can buy?

48 − 6n ≥ 12−6n ≥ −36n ≤ 6

Important: The last step divides by a negative number, so the inequality reverses. That rule is covered in detail in the next lesson.

Context checkAt n=6, $48−$36=$12 remains. At n=7, only $6 remains, so 7 is too many.

11 · COMMON MISTAKES
Treating the answer like one number

x<5 means infinitely many values, not just x=4.

Dropping the equality bar

≤ and ≥ include the boundary; < and > do not.

Changing only one side

Equivalent inequalities require balanced operations on both sides.

Forgetting the negative-division rule

Multiplying or dividing by a negative reverses the inequality sign. Apply that rule whenever it appears.

12 · EXAM STRATEGY

Translate boundary words before doing algebra.

Words such as at most, no more than, and maximum usually point to ≤. Words such as at least, minimum, and no less than usually point to ≥. Then solve and check whether the context requires whole-number values.

14 · LESSON RECAP

Solve, interpret, and verify.

  1. Use inverse operations to isolate the variable.
  2. Keep track of whether the boundary is included.
  3. Remember that a solution is usually a set of values.
  4. Check the boundary and a sample value in the original inequality.
  5. Reverse the sign whenever you multiply or divide by a negative number.
