Boundary Lines

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Boundary for y > 2x − 3

Answer: A) y = 2x − 3, dashed
Replace the inequality sign with equality to get the boundary. Because > is strict, points on the boundary are excluded, so the line is dashed.

2. Boundary for 3x + y ≤ 9

Answer: B) 3x + y = 9, solid
The boundary is 3x+y=9. The symbol ≤ includes equality, so the boundary itself belongs to the solution and is solid.

3. Boundary for x < −4

Answer: C) x = −4, dashed
An equation x=constant is a vertical line. Since x<−4 is strict, x=−4 is drawn dashed.
02 · CORE PRACTICE

4. Boundary for y ≥ −(1/2)x + 5

Answer: A) y = −(1/2)x + 5, solid
Use equality for the boundary. Because ≥ includes equality, draw the line solid.

5. Boundary for 2x − 3y > 12

Answer: B) The boundary is 2x − 3y = 12 and is dashed.
Changing > to = gives the boundary equation. A strict inequality excludes the boundary, so it is dashed.

6. Boundary for y < 4

Answer: C) y = 4, dashed
The boundary y=4 is horizontal. The strict symbol < means the line is not included and must be dashed.

7. Boundary for x ≥ 2

Answer: A) x = 2, solid
The boundary x=2 is vertical. Equality is included by ≥, so the line is solid.

8. Equivalent boundary for 4x + 2y ≤ 8

Answer: B) y = −2x + 4, solid
For the boundary, 4x+2y=8. Then 2y=8−4x, so y=−2x+4. The original ≤ includes equality, so the line is solid.

9. x-intercept of y = −3x + 6

Answer: C) (2, 0)
At the x-intercept, y=0. Solve 0=−3x+6 to get x=2, giving (2,0).

10. y-intercept and style for 5x + 2y > 10

Answer: B) (0, 5), dashed
Set x=0 in the boundary equation: 2y=10, so y=5. Because > is strict, the boundary is dashed.

11. Boundary through (0, −1) and (3, 5), included with solution below

Answer: A) y ≤ 2x − 1
The slope is (5−(−1))/(3−0)=6/3=2, and the y-intercept is −1, so the boundary is y=2x−1. “Includes the line” requires equality, and “on or below” gives ≤.
03 · EXAM-STYLE PRACTICE

12. Intercepts and style for y < x + 4

Answer: A) (0, 4) and (−4, 0), dashed
For y=x+4, x=0 gives (0,4), while y=0 gives x=−4 and therefore (−4,0). The strict inequality makes the boundary dashed.

13. Boundary form and style for 3x − 2y ≥ 6

Answer: C) y = (3/2)x − 3, solid
For the boundary, 3x−2y=6. Then −2y=6−3x, so y=(3/2)x−3. The ≥ symbol includes equality, so the boundary is solid.

14. Boundary for x + y < 7

Answer: B) It is dashed through (0, 7) and (7, 0).
The boundary x+y=7 has intercepts (0,7) and (7,0). Since < is strict, draw it dashed.

15. Capacity rule 2x + y ≤ 10

Answer: B) 2x + y = 10, solid
The boundary comes from replacing ≤ with equality. Since equality is included, the boundary line is solid.

16. Solid boundary y = −2x + 3 with solution above

Answer: C) y ≥ −2x + 3
“Above” means y-values greater than the line, and a solid boundary means equality is included. Together these give y≥−2x+3.
04 · CHALLENGE PROBLEMS

17. Strict boundary through (−2, 5) and (4, −1)

Answer: A) y = −x + 3, dashed
The slope is (−1−5)/(4−(−2))=−6/6=−1. Using (−2,5), 5=−(−2)+b gives b=3, so y=−x+3. A strict inequality uses a dashed boundary.

18. Boundary for −3x + 6y > 12

Answer: A) y = (1/2)x + 2, dashed, with intercepts (−4, 0) and (0, 2)
For the boundary, −3x+6y=12, so 6y=3x+12 and y=(1/2)x+2. Setting y=0 gives x=−4; setting x=0 gives y=2. The strict > means the boundary is dashed.
