Solving One-Variable Inequalities

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Solve x + 7 < 12

Answer: A) x < 5
Subtract 7 from both sides: x < 5.

2. Solve 4x ≥ 28

Answer: A) x ≥ 7
Divide both sides by positive 4, so the inequality direction stays the same: x ≥ 7.

3. Solve x/5 − 2 ≤ 4

Answer: C) x ≤ 30
Add 2: x/5 ≤ 6. Multiply by positive 5: x ≤ 30.
02 · CORE PRACTICE

4. Solve 3x + 5 < 20

Answer: B) x < 5
Subtract 5 and divide by 3: 3x < 15, so x < 5.

5. Solve 5x + 2 ≥ 2x + 14

Answer: A) x ≥ 4
Subtract 2x and 2: 3x ≥ 12. Divide by 3: x ≥ 4.

6. Solve 2(x + 3) ≤ 18

Answer: A) x ≤ 6
Divide by 2: x + 3 ≤ 9. Subtract 3: x ≤ 6.

7. Solve x/4 − 3 > 2

Answer: C) x > 20
Add 3: x/4 > 5. Multiply by positive 4: x > 20.

8. Solve 7x − 5 > 2x + 10

Answer: B) x > 3
Subtract 2x and add 5: 5x > 15. Divide by 5: x > 3.

9. Solve 9 + 2x ≤ 21

Answer: B) x ≤ 6
Subtract 9: 2x ≤ 12. Divide by 2: x ≤ 6.

10. Solve (x + 5)/3 ≥ 4

Answer: A) x ≥ 7
Multiply by positive 3: x + 5 ≥ 12. Subtract 5: x ≥ 7.

11. Solve 4(x − 2) + 3 < 19

Answer: C) x < 6
Expand: 4x − 5 < 19. Add 5 and divide by 4: 4x < 24, so x < 6.
03 · EXAM-STYLE PRACTICE

12. Notebook budget

Answer: B) 6
Keeping at least $12 gives 60 − 8n ≥ 12. Then −8n ≥ −48. Dividing by −8 reverses the inequality: n ≤ 6, so the greatest whole number is 6.

13. Team points

Answer: A) x ≥ 46
The requirement is 74 + x ≥ 120. Subtract 74: x ≥ 46.

14. Ride budget

Answer: C) 12 miles
Use 5 + 3m ≤ 41. Then 3m ≤ 36, so m ≤ 12. The greatest whole number is 12 miles; the cost is exactly $41.

15. Fundraising goal

Answer: B) 5
Use 125 + 15b ≥ 200. Then 15b ≥ 75, so b ≥ 5. The minimum whole number is 5 batches.

16. Shelf capacity

Answer: C) 12
Use 82 + 14b ≤ 250. Then 14b ≤ 168, so b ≤ 12. Twelve boxes give 250 kg exactly.
04 · CHALLENGE PROBLEMS

17. Solve 3(2x + 1) ≤ 5x + 11

Answer: A) x ≤ 8
Expand: 6x + 3 ≤ 5x + 11. Subtract 5x and 3: x ≤ 8.

18. Book budget with money kept

Answer: C) 10
Keeping at least $21 gives 96 − 7.50b ≥ 21. Then −7.50b ≥ −75. Divide by −7.50 and reverse the inequality: b ≤ 10. Ten books cost $75 and leave $21.
