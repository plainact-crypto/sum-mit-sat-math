Systems with Parameters
Algebra
01 · LESSON OBJECTIVE

Use parameter values to control how many solutions a system has.

A parameter is a letter that stands for a number whose value can change. In a system of linear equations, changing a parameter can make the two equations represent intersecting lines, parallel lines, or the same line.

2x + y = 7
kx + 2y = c→compare k and c
02 · WHAT YOU NEED TO KNOW

Compare equivalent coefficient patterns before solving.

Start with one equation and scale it so a variable coefficient matches the other equation. Then compare all coefficients and constants. This often reveals the solution count without solving for x and y.

Different slopesone solutionThe lines intersect once.
Same slope, different interceptsno solutionThe lines are distinct and parallel.
Same equation after scalinginfinitely manyEvery point on one line is also on the other.
Parameterchanges the relationshipFind the value that creates the requested case.
03 · KEY DEFINITIONS

Parameter

A letter representing a value that can vary, such as k or c.

Coefficient

A numerical factor multiplying a variable.

Equivalent equations

Equations with exactly the same solution set, often created by multiplying every term by the same nonzero number.

04 · CORE RULE

Match the variable coefficients, then compare the constants.

PROPORTIONAL COEFFICIENTS + PROPORTIONAL CONSTANT = SAME LINE
05 · MASTER EXAMPLE

Analyze the system 2x + y = 7 and kx + 2y = c.

Multiply the first equation by 2:

2(2x + y = 7)4x + 2y = 14Compare with kx + 2y = c

Now the y-coefficients already match, so k and c determine the relationship.

If k = 4 and c = 14infinitely many solutionsThe second equation is exactly the doubled first equation.
If k = 4 and c ≠ 14no solutionThe left sides match but the constants conflict.
If k ≠ 4one solutionThe coefficient ratios are not all proportional.
06 · WORKED EXAMPLE 1 — INFINITELY MANY

Find c if k = 4 and the system must have infinitely many solutions.

First equation doubled: 4x + 2y = 14Second equation: 4x + 2y = cFor the equations to be identical, c = 14.
CheckWith c=14, both equations reduce to the same line, so every solution of one is a solution of the other.
07 · WORKED EXAMPLE 2 — NO SOLUTION

Let k = 4 and c = 10. How many solutions are there?

4x + 2y = 144x + 2y = 10Subtract: 0 = −4
ConclusionThe contradiction means no ordered pair can satisfy both equations.
08 · WORKED EXAMPLE 3 — ONE SOLUTION

Let k = 6 and c = 14. Solve the system.

2x + y = 7 → 4x + 2y = 146x + 2y = 14Subtract: 2x = 0 → x = 02(0) + y = 7 → y = 7Solution: (0, 7)
Substitution check2(0)+7=7 and 6(0)+2(7)=14, so (0,7) satisfies both equations.
09 · WORKED EXAMPLE 4 — FIND THE PARAMETER

For what value of a does the system have no solution?

3x + 2y = 86x + ay = 20To make the variable coefficients proportional, double the first equation: 6x + 4y = 16.So a = 4 creates equal variable coefficients but unequal constants: 16 ≠ 20.
Answera = 4
10 · WORKED EXAMPLE 5 — EXAM-STYLE

A system has equations 5x − y = 9 and 15x − 3y = m. What value of m gives infinitely many solutions?

Multiply 5x − y = 9 by 3.15x − 3y = 27Therefore m = 27.

Exam strategy: Do not solve for x and y when the question only asks for the parameter that controls the solution count.

11 · A GENERAL COEFFICIENT TEST

For A₁x + B₁y = C₁ and A₂x + B₂y = C₂, compare ratios carefully.

One solutionA₁/A₂ ≠ B₁/B₂The variable coefficients are not proportional.
No solutionA₁/A₂ = B₁/B₂ ≠ C₁/C₂Same slope, different line.
Infinitely manyA₁/A₂ = B₁/B₂ = C₁/C₂All corresponding terms are proportional.

Safer method: When a coefficient can be zero or fractions are awkward, scale one equation directly instead of dividing by a possibly zero coefficient.

12 · COMMON MISTAKES
Comparing only one coefficient

For no or infinitely many solutions, both variable coefficients must have the same proportional relationship.

Forgetting the constant

Matching variable coefficients gives either no solution or infinitely many; the constant tells you which one.

Solving before checking structure

Parameter questions are often faster by coefficient comparison.

Dividing by an unknown parameter

If the parameter might be zero, direct scaling or elimination is safer than dividing by it.

14 · LESSON RECAP

Parameters change the relationship between the two equations.

  1. Scale an equation so corresponding variable coefficients are easy to compare.
  2. Nonproportional variable coefficients give one solution.
  3. Proportional variable coefficients with conflicting constants give no solution.
  4. Proportional coefficients and constants give infinitely many solutions.
  5. Use the requested solution count to solve for the parameter.
