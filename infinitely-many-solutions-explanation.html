01 · LESSON OBJECTIVE

Recognize when two equations describe the same line.

Learn to identify dependent systems from equations, graphs, and algebra, then explain why every point on the shared line satisfies both equations.

same line→infinitely many solutions
02 · WHAT YOU NEED TO KNOW

A system can contain two equivalent equations.

If one equation is a nonzero constant multiple or equivalent rearrangement of the other, both equations represent exactly the same line. Every point on that line is a common solution.

Graphsame lineThe graphs overlap completely.
Slope cluesame slopeEquivalent nonvertical lines have equal slopes.
Intercept cluesame interceptMatching slope and intercept means the same line.
Algebra cluetrue identityElimination may end with 0 = 0.
03 · KEY DEFINITIONS

Dependent System

A system whose equations represent the same line.

Equivalent Equations

Equations with exactly the same solution set.

Identity

A statement such as 0 = 0 that is true for all relevant values.

04 · CORE RULE

Same slope and same y-intercept means infinitely many solutions.

m₁ = m₂ and b₁ = b₂ → INFINITELY MANY SOLUTIONS
05 · HOW IT WORKS

Check whether the equations reduce to the same relationship.

01
Rewrite or simplify.Put both equations in comparable form.
02
Compare the full equations.Matching slope alone is not enough; the intercept must match too.
03
Use elimination if needed.If every variable term and constant cancels, the equations are dependent.
04
Interpret the result.The solution set is every point on the common line, not one ordered pair.

10 · VISUAL MEANING

Equivalent equations lie on top of each other.

For y = 2x + 1 and 2y = 4x + 2, the second equation simplifies to y = 2x + 1. At x = 0 both give y = 1; at x = 1 both give y = 3; at x = 2 both give y = 5. The graphs coincide, so every point on the line is shared.

11 · COMMON MISTAKES
Thinking 0 = 0 means x = 0

An identity means the equations did not produce a unique value because they are equivalent.

Checking only the slopes

Equal slopes with different intercepts means no solution, not infinitely many solutions.

Giving one point as the answer

A dependent system has infinitely many common points along the same line.

12 · EXAM STRATEGY

Look for proportional equations before doing long algebra.

If every coefficient and the constant in one equation are multiplied by the same nonzero factor to get the other equation, the system has infinitely many solutions. When that is not obvious, simplify both equations or use elimination.

14 · LESSON RECAP

Same line means infinitely many solutions.

  1. Equivalent equations have the same solution set.
  2. For nonvertical lines, matching slope and intercept means the same line.
  3. A constant multiple of an equation represents the same line.
  4. Elimination can reveal an identity such as 0 = 0.
  5. Every point on the common line satisfies both equations.
