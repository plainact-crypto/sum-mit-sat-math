01 · SKILL CHECK

1. Parallel lines with different intercepts

Answer: B) No solution
Both equations have slope 4, but their y-intercepts are 1 and −5. Equal slopes with different intercepts means the lines are parallel and never meet.

2. Equivalent equations

Answer: C) Infinitely many solutions
Rewrite 2x + y = 3 as y = −2x + 3. It is exactly the same line as the first equation, so every point on the line satisfies both equations.

3. Proportional left sides, inconsistent constants

Answer: B) No solution
Doubling 3x − y = 7 gives 6x − 2y = 14, not 20. The left sides are proportional but the constants are not, so the equations represent distinct parallel lines.
02 · CORE PRACTICE

4. Match slopes for no solution

Answer: C) 5
For y = 5x + 2 and y = kx − 6 to have no solution, the slopes must match while the intercepts remain different. Therefore k = 5.

5. Make two equations identical

Answer: B) 18
Doubling 2x + 3y = 9 gives 4x + 6y = 18. Thus c = 18 makes the second equation exactly equivalent to the first, giving infinitely many solutions.

6. Classify an equivalent system

Answer: C) Infinitely many solutions
Doubling x − 2y = 4 gives 2x − 4y = 8, which is exactly the second equation. The equations describe the same line.

7. Detect inconsistent multiples

Answer: B) No solution
Doubling 3x + y = 8 gives 6x + 2y = 16, but the second equation has 15 on the right. The lines are parallel and distinct.

8. Recognize the same line in different forms

Answer: C) Infinitely many solutions
From x + 2y = 14, divide by 2 after isolating y: 2y = −x + 14, so y = −0.5x + 7. This matches the first equation exactly.

9. Compare proportional equations

Answer: B) No solution
Dividing 4x − 2y = 10 by 2 gives 2x − y = 5, while the second equation is 2x − y = 8. Same left side with different constants means no solution.

10. Substitute to test consistency

Answer: A) No solution
Substitute y = 3x + 2 into 6x − 2y = 10: 6x − 2(3x + 2) = 10, which simplifies to −4 = 10. This contradiction shows there is no solution.

11. Identify exact multiples

Answer: C) Infinitely many solutions
Doubling 5x + 2y = 12 gives 10x + 4y = 24, exactly the second equation. Both equations describe the same line.
03 · EXAM-STYLE PRACTICE

12. Compare two cost models

Answer: B) No solution
Set the costs equal: 12 + 4n = 20 + 4n. Subtracting 4n from both sides gives 12 = 20, which is impossible. The plans increase at the same rate but start $8 apart.

13. Parameter for parallel distinct lines

Answer: B) 3
To make the coefficient ratios match, doubling 2x + ky gives 4x + 2ky. Matching 4x + 6y requires 2k = 6, so k = 3. Doubling the first constant would give 12, not 15, so the lines are distinct and parallel.

14. Match slopes using a parameter

Answer: C) 5
The slopes are p − 1 and 4. Set p − 1 = 4 to get p = 5. The intercepts are 8 and −3, so the lines are parallel but not identical.

15. Parameter in standard form

Answer: B) 3
The y-coefficient ratio from the first equation to the second is 2. Therefore 2a must equal 6, so a = 3. Doubling the first equation would give a right side of 14, not 20, so the system has no solution.

16. Compare slopes from two pairs of points

Answer: B) No solution
Line A has slope (6 − 2)/(2 − 0) = 2. Line B has slope (5 − (−1))/(3 − 0) = 2. Their y-intercepts are 2 and −1, so they are distinct parallel lines.
04 · CHALLENGE PROBLEMS

17. Recover a hidden coefficient condition

Answer: C) 4
To match the coefficient ratio set by 3y and 6y, the second equation must be twice the first on the left. Thus 2(a − 2) = 4, so a = 4. Doubling the first constant gives 18, not 25, so the lines remain distinct and parallel.

18. Make two point-defined lines parallel and distinct

Answer: B) −1
Line 1 has slope (12 − 4)/(5 − 1) = 2. Line 2 has slope (7 − q)/(2 − (−2)) = (7 − q)/4. Set (7 − q)/4 = 2 to get 7 − q = 8, so q = −1. Line 1 is y = 2x + 2, while Line 2 then has y-intercept 3, so they are parallel and distinct.
