Graphing Systems of Inequalities

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Test a point

Answer: A) (0, 0)
0≥−1 and 0≤5, so both inequalities are true.

2. Boundary styles

Answer: C) First dashed, second solid
A strict inequality uses a dashed boundary; ≤ includes equality, so its boundary is solid.

3. Boundary intersection

Answer: B) (3, 2)
Set x−1=−x+5. Then 2x=6, so x=3 and y=2.
02 · CORE PRACTICE

4. Check both conditions

Answer: A) (2, 3)
3>2 and 3≤4.

5. Included boundaries

Answer: C) The first is solid and the second is dashed
≥ includes the boundary; < excludes it.

6. Verify a solution

Answer: B) (3, 2)
3+2=5≤6 and 2≥2. Each other choice fails at least one condition.

7. Solve the boundary system

Answer: B) (3, 3)
2x−3=−x+6 gives 3x=9, so x=3 and y=3.

8. Test-point shading

Answer: A) (0,0), because 0 < 4
At the origin, y<−x+4 becomes 0<4, so shade the side containing the origin.

9. Choose the matching system

Answer: B) y ≥ x and y ≤ x + 2
At (1,2), 2≥1 and 2≤3.

10. Describe the overlap

Answer: B) above both lines
Both inequalities use ≥, so a solution must lie on or above each boundary.

11. Meaning of overlap

Answer: C) It is not a solution to the system
A solution to a system must satisfy every inequality simultaneously.
03 · EXAM-STYLE PRACTICE

12. Vertical and horizontal restrictions

Answer: C) (2, 0)
2≤3 and 0>−1.

13. Feasible region

Answer: C) (3, 5)
Both coordinates are nonnegative and 3+5=8≤8.

14. Find an intersection

Answer: B) (4, 3)
0.5x+1=−x+7 gives 1.5x=6, so x=4 and y=3.

15. Parallel boundaries with no overlap

Answer: A) y > 2x + 3 and y < 2x + 1
2x+3 is always 2 units above 2x+1, so no y can be above the first and below the second.

16. School order constraints

Answer: C) (20, 20)
20+20=40≤40 and 2(20)+20=60≤60, with both quantities nonnegative.
04 · CHALLENGE PROBLEMS

17. Find the overlap point

Answer: C) (3, 3)
3>−2(3)+6=0 and 3≤3.

18. Region between parallel lines

Answer: B) All points between and on two parallel lines
The compound condition 2x−4≤y≤2x+1 is exactly the closed strip between the two parallel boundaries.

19. Greatest allowed x-value

Answer: B) 2
For some y to satisfy both, x+2≤−2x+8, so 3x≤6 and x≤2.
