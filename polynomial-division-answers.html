Polynomial Division

Solutions correspond exactly to Practice Questions 1–18.

1. 12x³ ÷ 3x

12÷3=4 and x³÷x=x².
Answer: A) 4x²

2. -20y⁵ ÷ 5y²

-20÷5=-4 and y⁵÷y²=y³.
Answer: A) -4y³

3. (15a⁴ + 10a²) ÷ 5a²

Divide each term: 15a⁴÷5a²=3a² and 10a²÷5a²=2.
Answer: A) 3a² + 2

4. (x² + 5x + 6) ÷ (x + 2)

x²+5x+6=(x+2)(x+3), so the quotient is x+3.
Answer: A) x + 3

5. (x² - 9) ÷ (x - 3)

x²-9=(x-3)(x+3).
Answer: A) x + 3

6. (2x² + 7x + 3) ÷ (x + 3)

2x²+7x+3=(x+3)(2x+1).
Answer: A) 2x + 1

7. (3x³ - 6x² + 9x) ÷ 3x

Term-by-term division gives x² - 2x + 3.
Answer: A) x² - 2x + 3

8. (x³ + 4x² + x - 6) ÷ (x + 2)

(x+2)(x²+2x-3)=x³+4x²+x-6.
Answer: A) x² + 2x - 3

9. Remainder of x² + 2x + 5 divided by x + 1

By the Remainder Theorem, evaluate at x=-1: 1-2+5=4.
Answer: A) 4

10. (4m³ - 8m² + 12m) ÷ 4m

Term-by-term division gives m² - 2m + 3.
Answer: A) m² - 2m + 3

11. (6p⁴ + 9p³ - 3p²) ÷ 3p²

Divide each term by 3p² to get 2p² + 3p - 1.
Answer: A) 2p² + 3p - 1

12. (x² - x - 12) ÷ (x - 4)

x²-x-12=(x-4)(x+3).
Answer: A) x + 3

13. Rectangle area x² + 7x + 12; length x + 3

x²+7x+12=(x+3)(x+4), so width = area ÷ length = x+4 meters.
Answer: A) x + 4 m

14. P(x)=2x³+5x²-3x divided by x

Divide each term by x: 2x² + 5x - 3.
Answer: A) 2x² + 5x - 3

15. x³ - 2x² + kx + 6 divided by x - 2 has remainder 8

f(2)=8-8+2k+6=6+2k. Set 6+2k=8, so k=1.
Answer: A) 1

16. Quotient x² - 3x + 4, divisor x + 2, remainder 5

Original = (x+2)(x²-3x+4)+5 = x³-x²-2x+13.
Answer: A) x³ - x² - 2x + 13

17. (x⁴ - 5x² + 4) ÷ (x² - 1)

x⁴-5x²+4=(x²-1)(x²-4), so the division is exact.
Answer: A) x² - 4

18. x³ + ax² - 5x + 6 is divisible by x - 2

Divisibility requires f(2)=0: 8+4a-10+6=4+4a=0, so a=-1.
Answer: A) -1
