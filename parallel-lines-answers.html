Parallel Lines

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Parallel to y = 3x − 4

Answer: A) 3
Parallel nonvertical lines have equal slopes. The given line has slope 3, so any parallel line also has slope 3.

2. Parallel to 2x + 5y = 10

Answer: A) 2x + 5y = 7
Writing 2x + 5y = 10 as y = −(2/5)x + 2 shows slope −2/5. The equation 2x + 5y = 7 has the same x- and y-coefficients, so it has the same slope.

3. Match the slope through (1, 2) and (4, 8)

Answer: A) (0, −1) and (3, 5)
The given slope is (8 − 2)/(4 − 1) = 6/3 = 2. For (0, −1) and (3, 5), the slope is (5 − (−1))/(3 − 0) = 6/3 = 2.
02 · CORE PRACTICE

4. Parallel to y = −4x + 7 through (2, 1)

Answer: A) y = −4x + 9
Use slope −4: y = −4x + b. Substituting (2, 1) gives 1 = −8 + b, so b = 9.

5. Parallel to 3x − 2y = 8 through (−2, 5)

Answer: A) 3x − 2y = −16
A parallel line keeps the same x- and y-coefficients. Substituting (−2, 5) into 3x − 2y gives 3(−2) − 2(5) = −6 − 10 = −16.

6. Compare y = (1/3)x + 2 and 2x − 6y = 9

Answer: A) Yes, both slopes are 1/3.
Rearrange 2x − 6y = 9: −6y = −2x + 9, so y = (1/3)x − 3/2. Both lines have slope 1/3.

7. Find k for parallel point-pair lines

Answer: C) 11
The first line has slope (9 − 1)/(4 − 0) = 8/4 = 2. For the second line, (k − 3)/(6 − 2) = 2, so k − 3 = 8 and k = 11.

8. Find p for a line parallel to 5x + y = 7

Answer: B) −6
The equation 5x + y = 7 has slope −5. Thus (p − 4)/(3 − 1) = −5, so p − 4 = −10 and p = −6.

9. Horizontal parallel line through (4, −2)

Answer: A) y = −2
The line y = 6 is horizontal. Every horizontal line has slope 0, and the horizontal line through (4, −2) is y = −2.

10. Vertical parallel line through (−5, 7)

Answer: A) x = −5
The line x = 3 is vertical. Every vertical line is parallel to every other vertical line, and the one through (−5, 7) is x = −5.

11. Parallel to 2x + 4y = 12

Answer: A) y = −(1/2)x + 6
Solve for y: 4y = −2x + 12, so y = −(1/2)x + 3. A parallel line must also have slope −1/2.
03 · EXAM-STYLE PRACTICE

12. Parallel delivery-cost graph through (4, 15)

Answer: A) C = 2.5d + 5
A parallel graph keeps slope 2.5. Write C = 2.5d + b and substitute (4, 15): 15 = 2.5(4) + b = 10 + b, so b = 5.

13. Parallel path through (1, 6)

Answer: A) y = −(1/2)x + 13/2
The slope through (−3, 2) and (5, −2) is (−2 − 2)/(5 − (−3)) = −4/8 = −1/2. Using (1, 6): 6 = −1/2 + b, so b = 13/2.

14. Find k so kx + 4y = 7 is parallel to 3x + 2y = 5

Answer: C) 6
The slopes are −k/4 and −3/2. Set −k/4 = −3/2. Then k/4 = 3/2, giving k = 6.

15. Point pair parallel to Line A

Answer: A) (1, 0) and (3, 7)
Line A has slope (11 − 4)/(2 − 0) = 7/2. Option A has slope (7 − 0)/(3 − 1) = 7/2, so it is parallel.

16. Find a in y = (a − 1)x + 4

Answer: C) 6
Parallel lines must have equal slopes, so a − 1 = 5. Therefore a = 6.
04 · CHALLENGE PROBLEMS

17. Hidden coordinate a

Answer: B) 0
The required slope is 4/3. For (a, 2) and (6, 10), 8/(6 − a) = 4/3. Cross-multiplying gives 24 = 24 − 4a, so a = 0.

18. Find q for parallel standard-form lines

Answer: B) 8
For 3x + 6y = 9, the slope is −3/6 = −1/2. For 4x + qy = 3, the slope is −4/q. Set −4/q = −1/2, giving q = 8.
