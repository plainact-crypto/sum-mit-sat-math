Boundary Lines
Algebra
01 · LESSON OBJECTIVE

Turn a two-variable inequality into the line that separates its two regions.

By the end of this lesson, you should be able to find the boundary line of a linear inequality, graph it accurately, and decide whether that boundary is solid or dashed.

y > −x + 2→boundary: y = −x + 2
02 · CORE IDEA

Replace the inequality sign with an equals sign.

The boundary line is the line where the two sides are exactly equal. It divides the coordinate plane into the two half-planes that you will later test or shade.

< or >Dashed boundaryEquality is not allowed, so points on the line are not solutions.
≤ or ≥Solid boundaryEquality is allowed, so points on the line are included.
03 · WORKED EXAMPLE 1

Find the boundary line for y > −x + 2.

  1. Replace > with =.The boundary equation is y = −x + 2.
  2. Read the slope and intercept.Slope = −1 and y-intercept = 2.
  3. Choose the line style.The original symbol is >, so the boundary is dashed.
VISUAL GRAPH

The dashed line is generated from y = −x + 2.

The plotted points come directly from the boundary equation. Because the original inequality is strict, the line is dashed.

Math cross-checkSubstitution verifies all three labels: for x=−2, y=−(−2)+2=4; for x=0, y=2; for x=2, y=0. The slope between consecutive labeled points is −2/2=−1, matching the equation.
04 · WORKED EXAMPLE 2

Find the boundary line for 2x + 3y ≤ 12.

2x + 3y = 123y = −2x + 12y = −(2/3)x + 4

The original symbol is ≤, so the boundary is solid. Two easy boundary points are (0,4) and (6,0).

Check2(0)+3(4)=12 and 2(6)+3(0)=12, so both points lie on the boundary.
05 · VERTICAL BOUNDARIES

Not every boundary is written as y = mx + b.

For x < 3, the boundary is the vertical line x = 3. It is dashed because the original inequality is strict. For x ≥ −2, the boundary is x = −2 and it is solid.

DESMOS STRATEGY

Use Desmos to verify the boundary before shading.

Enter

y > -x + 2

Look for

A dashed boundary on y = -x + 2, passing through (0,2) and (2,0).

Use it to answer

Confirm the boundary equation, its line style, and key intercepts before deciding which region satisfies the inequality.

Why it works

The edge of the graphed solution region occurs exactly where y = -x + 2; strict inequality excludes that edge.

Faster or not?

Useful for checking a graph or awkward coefficients. For a simple slope-intercept inequality, identifying the boundary by hand is usually faster.

Independent verificationThe boundary has y-intercept 2 because x=0 gives y=2, and x-intercept 2 because y=0 gives x=2. Point (0,3) satisfies 3>2, while (0,1) does not, confirming the boundary separates the two regions.
06 · COMMON MISTAKES
Graphing the inequality sign itself

First replace the inequality symbol with = to get the boundary equation.

Using a solid line for < or >

Strict inequalities exclude equality, so their boundaries are dashed.

Using a dashed line for ≤ or ≥

Those symbols include equality, so their boundaries are solid.

Changing the equation while finding the boundary

The boundary keeps the same expressions; only the inequality symbol becomes =.

07 · EXAM STRATEGY

Separate boundary work from shading work.

On a test-style graphing question, first write the equality, graph that line, and decide solid versus dashed. Only then move on to testing a point or choosing a shaded region.
