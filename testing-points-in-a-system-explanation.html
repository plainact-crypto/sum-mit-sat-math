Testing Points in a System
Algebra
01 · LESSON OBJECTIVE

Decide whether one ordered pair satisfies an entire system.

A point is a solution of a system of inequalities only when its x- and y-values make every inequality true at the same time.

(2, 4)→test in every condition
02 · CORE IDEA

One failed inequality means the point is not a system solution.

Substitute the point’s x-coordinate for x and y-coordinate for y. Evaluate each inequality separately. Keep the point only if every comparison is true.

Step 1SubstituteUse the exact ordered pair.
Step 2EvaluateSimplify both sides.
Step 3CompareCheck <, >, ≤, or ≥ carefully.
Step 4DecideAll true = system solution.
03 · WORKED EXAMPLE

Does (2, 4) satisfy y ≥ x + 1 and y ≤ −x + 7?

  1. Test the first inequality.4 ≥ 2 + 1 → 4 ≥ 3 ✓
  2. Test the second inequality.4 ≤ −2 + 7 → 4 ≤ 5 ✓
  3. Make the system decision.Both statements are true, so (2, 4) is a solution of the system.
04 · WHEN ONE CONDITION FAILS

Test (4, 4) in the same system.

4 ≥ 4 + 1 → 4 ≥ 5 ✗4 ≤ −4 + 7 → 4 ≤ 3 ✗

The point is not a solution. You can stop as soon as one required inequality is false, although checking both is useful while learning.

05 · STRICT VS INCLUSIVE BOUNDARIES

Equality matters.

If a point lies exactly on a boundary, it satisfies an inequality with ≤ or ≥, but it does not satisfy the corresponding strict inequality < or >.

At y = x + 1→y ≥ x + 1 ✓ · y > x + 1 ✗
06 · EXAM STRATEGY

Use a tiny truth checklist.

For each candidate point, write T or F beside every inequality. Eliminate a choice immediately after the first false result. This is especially efficient in multiple-choice and constraint questions.

07 · COMMON MISTAKES
Testing only one inequality

A system uses AND unless stated otherwise: every condition must hold.

Swapping coordinates

For (2, 4), substitute x=2 and y=4, not the reverse.

Ignoring equality

Boundary points count for ≤ and ≥ but not for < and >.

Changing an inequality sign during substitution

Substitution does not reverse a sign. Reversal happens only when solving by multiplying or dividing by a negative number.

08 · QUICK CHECK

Test before revealing.

1(0,0): y ≥ x−1, y ≤ 2
2(3,1): y > x−2, y ≤ 4
3(2,3): x+y ≤ 5, y ≥ x
Show answers

1) Yes: 0≥−1 and 0≤2. 2) No: 1>1 is false because the inequality is strict. 3) Yes: 5≤5 and 3≥2.
