Finding X-Intercept

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. What is the x-intercept of 2x + 3y = 18?

Answer: B) (9, 0)
At the x-intercept, y = 0. Then 2x = 18, so x = 9.

2. What is the x-intercept of y = −4x + 12?

Answer: C) (3, 0)
Set y = 0: 0 = −4x + 12, so 4x = 12 and x = 3.

3. What is the x-coordinate of the x-intercept of x − 2y = −7?

Answer: B) −7
Set y = 0: x = −7.
02 · CORE PRACTICE

4. Find the x-intercept of 5x + 2y = 30.

Answer: B) (6, 0)
Set y = 0: 5x = 30, so x = 6.

5. Find the x-intercept of 3x − y = −15.

Answer: A) (−5, 0)
Set y = 0: 3x = −15, so x = −5.

6. Find the x-intercept of y = (1/2)x − 4.

Answer: C) (8, 0)
Set y = 0: (1/2)x − 4 = 0, so (1/2)x = 4 and x = 8.

7. Find the x-intercept of y = −3x − 9.

Answer: A) (−3, 0)
Set y = 0: −3x − 9 = 0, so −3x = 9 and x = −3.

8. Find the x-intercept of 8x + 6y = 7.

Answer: A) (7/8, 0)
Set y = 0: 8x = 7, so x = 7/8.

9. What is the x-intercept of the vertical line x = 4?

Answer: C) (4, 0)
The vertical line x = 4 crosses the x-axis where y = 0, at (4, 0).

10. How many x-intercepts does the horizontal line y = 5 have?

Answer: A) 0
Every point on y = 5 has y-coordinate 5, so the line never reaches y = 0.

11. How many x-intercepts does the line y = 0 have?

Answer: D) Infinitely many
The line y = 0 is the x-axis itself, so every point on it is an x-intercept point.
03 · SAT-STYLE PRACTICE

12. The line 4x + 5y = 60 crosses the x-axis at (a, 0). What is a?

Answer: B) 15
Set y = 0: 4a = 60, so a = 15.

13. A quantity is modeled by y = −2x + 18. At what x-value does the model reach zero?

Answer: C) 9
Set y = 0: −2x + 18 = 0, so x = 9.

14. The equation 3y = 12 − 6x represents a line. What is its x-intercept?

Answer: B) (2, 0)
Set y = 0: 0 = 12 − 6x, so 6x = 12 and x = 2.

15. A tank contains y = 120 − 8x liters after x minutes. According to the model, after how many minutes is the tank empty?

Answer: C) 15
Empty means y = 0. Solve 120 − 8x = 0: 8x = 120, so x = 15 minutes.

16. For the line 7x + By = −21, where B is a nonzero constant, what is the x-coordinate of the x-intercept?

Answer: B) −3
Set y = 0: 7x = −21, so x = −3. The value of B does not affect the x-intercept.
04 · CHALLENGE PROBLEMS

17. The line kx + 4y = 24 has x-intercept (6, 0). What is k?

Answer: B) 4
Substitute (6, 0): 6k + 4(0) = 24, so 6k = 24 and k = 4.

18. A line has y-intercept (0, 6) and x-intercept (−2, 0). If its equation is y = mx + 6, what is m?

Answer: D) 3
Use the x-intercept (−2, 0): 0 = m(−2) + 6. Then −2m = −6, so m = 3.
