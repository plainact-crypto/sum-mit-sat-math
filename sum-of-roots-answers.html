Sum of Roots

Exact 1-to-1 answers for the 18 current Practice Problems.

SKILL CHECK

1. A — 8. For ax²+bx+c=0, the root sum is −b/a, so −(−8)/1=8.
2. A — −5. −10/2=−5.
3. A — −b/a. This is the sum-of-roots relationship for a quadratic.

CORE PRACTICE

4. A — 5. −(−15)/3=5.
5. A — −7/4. −b/a=−7/4.
6. A — 20. −k/5=−4, so k=20.
7. A — 12. Here b=−m, so the root sum is m/2=6; therefore m=12.
8. A — 4. Standard form is 3x²−12x+8=0, giving 12/3=4.
9. A — 9/2. −9/(−2)=9/2.
10. A — The root sum is 1/6. −(−1)/6=1/6.
11. A — 3. −18/p=−6, so p=3.

EXAM-STYLE PRACTICE

12. A — 14. −(q−2)/4=−3, so q−2=12 and q=14.
13. A — 7/2. 2(x²−3x)+5=x becomes 2x²−7x+5=0, so the root sum is 7/2.
14. A — 3. r+s=−(−21)/7=3.
15. A — 3. −(−12)/t=12/t=4, so t=3.
16. A — −8. −(2n+1)/3=5, so 2n+1=−15 and n=−8.

CHALLENGE PROBLEMS

17. A — 7. −(k+5)/(k−1)=−2 gives k+5=2(k−1), hence k=7. Since k−1=6≠0, the equation remains quadratic.
18. A — 1. The root sum is p+2. Set p+2=3p to get p=1.
