Building an Equation from Two Points

Solutions correspond exactly to Practice Questions 1–18.

01 · SKILL CHECK

1. Through (1, 3) and (4, 9)

Answer: A) y = 2x + 1
The slope is (9 − 3)/(4 − 1) = 6/3 = 2. Using (1, 3), 3 = 2(1) + b, so b = 1. Therefore y = 2x + 1.

2. Through (−2, 5) and (2, −3)

Answer: A) y = −2x + 1
The slope is (−3 − 5)/(2 − (−2)) = −8/4 = −2. Using (2, −3), −3 = −2(2) + b, so b = 1. Thus y = −2x + 1.

3. Through (0, −4) and (6, −1)

Answer: A) y = (1/2)x − 4
The slope is (−1 − (−4))/(6 − 0) = 3/6 = 1/2. Since x = 0 gives y = −4, the y-intercept is −4. Therefore y = (1/2)x − 4.
02 · CORE PRACTICE

4. Through (2, 7) and (5, 7)

Answer: A) y = 7
The y-values are equal, so the slope is 0. The line is horizontal at y = 7.

5. Through (−3, −2) and (1, 10)

Answer: A) y = 3x + 7
The slope is (10 − (−2))/(1 − (−3)) = 12/4 = 3. Using (1, 10), 10 = 3 + b, so b = 7.

6. Through (4, 5) and (10, −1)

Answer: A) y = −x + 9
The slope is (−1 − 5)/(10 − 4) = −6/6 = −1. Using (4, 5), 5 = −4 + b, so b = 9.

7. Through (−4, 1) and (2, 4)

Answer: A) y = (1/2)x + 3
The slope is (4 − 1)/(2 − (−4)) = 3/6 = 1/2. Using (2, 4), 4 = 1 + b, so b = 3.

8. Through (2, −5) and (8, −8)

Answer: A) y = −(1/2)x − 4
The slope is (−8 − (−5))/(8 − 2) = −3/6 = −1/2. Using (2, −5), −5 = −1 + b, so b = −4.

9. Through (2, 4) and (6, 10)

Answer: A) y = 1.5x + 1
The slope is (10 − 4)/(6 − 2) = 6/4 = 1.5. Using (2, 4), 4 = 1.5(2) + b = 3 + b, so b = 1.

10. Values 14 at x = 2 and 29 at x = 5

Answer: A) y = 5x + 4
The slope is (29 − 14)/(5 − 2) = 15/3 = 5. Using (2, 14), 14 = 10 + b, so b = 4.

11. Cost $41 for 3 items and $69 for 7 items

Answer: A) C = 7x + 20
The slope is (69 − 41)/(7 − 3) = 28/4 = 7 dollars per item. Using (3, 41), 41 = 7(3) + b, so b = 20.
03 · EXAM-STYLE PRACTICE

12. Through (−1, 2) and (3, 14); find y when x = 6

Answer: C) 23
The slope is (14 − 2)/(3 − (−1)) = 12/4 = 3. Using (−1, 2), 2 = −3 + b, so b = 5. Then y = 3(6) + 5 = 23.

13. Temperature 30°C at t = 2 and 20°C at t = 6

Answer: A) T = −2.5t + 35
The slope is (20 − 30)/(6 − 2) = −10/4 = −2.5 °C per hour. Using (2, 30), 30 = −2.5(2) + b, so b = 35.

14. Cost $58 for 4 units and $108 for 9 units

Answer: A) C = 10x + 18
The slope is (108 − 58)/(9 − 4) = 50/5 = 10 dollars per unit. Using (4, 58), 58 = 40 + b, so b = 18.

15. Through (2, 9) and (8, 0); find the y-intercept

Answer: C) 12
The slope is (0 − 9)/(8 − 2) = −9/6 = −3/2. Using (2, 9), 9 = (−3/2)(2) + b = −3 + b, so b = 12.

16. Standard form through (1, 4) and (5, 12)

Answer: A) 2x − y = −2
The slope is (12 − 4)/(5 − 1) = 8/4 = 2. Using (1, 4), 4 = 2 + b, so b = 2. Thus y = 2x + 2, which rearranges to 2x − y = −2.
04 · CHALLENGE PROBLEMS

17. Through (2, k) and (6, 15) with y-intercept 3

Answer: B) 7
Using (6, 15) and the intercept point (0, 3), the slope is (15 − 3)/(6 − 0) = 12/6 = 2. The line is y = 2x + 3. At x = 2, k = 2(2) + 3 = 7.

18. Through (a, 5) and (6, −1) with slope −3/2

Answer: C) 2
Use the slope formula: (−1 − 5)/(6 − a) = −6/(6 − a) = −3/2. Cross-multiplying gives −12 = −18 + 3a, so 3a = 6 and a = 2.
